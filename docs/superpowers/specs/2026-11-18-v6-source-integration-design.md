# v6 소스 통합 설계

## 목적

플레이 중인 v6 계열 앱을 `D:\01_Works\onepiece_life`의 독립적인 개발 폴더로 복사하고, 실제 앱 코드가 `src/v5`에 중첩된 구조를 정리한다. 원본 폴더는 그대로 둔다.

## 기준과 범위

- Git 이력은 유지하고, 원본의 `bf53ba5` 커밋과 이후의 강자 소문 수정 3개 파일을 포함한다.
- 현재 게임의 `src/v5/{app,core,data,ui}`를 `src/{app,core,data,ui}`로 옮긴다.
- 현재도 쓰이는 이전 전투·기술·출생 기반 코드는 `src/shared/{core,data}`로 옮긴다. 픽셀 그림·스타일·사운드와 음악은 각자의 기존 역할에 맞게 남긴다.
- 테스트는 `tests/game`으로 모으고, 도구와 테스트의 소스 참조를 새 경로로 바꾼다.
- 과거 v2·v3 HTML과 루트의 옛 기획서·그림은 새 작업 트리에서 제외한다. 원본 폴더와 Git 이력에서는 계속 찾을 수 있다.
- v7 기획 초안, `.claude/worktrees`, `inbox`, `dist`, `node_modules`는 새 작업 트리에 넣지 않는다.

## 구조 선택

현재 게임을 `src` 바로 아래에 놓고 이전 코드를 `src/shared`로 구분한다. 이름이 충돌하는 `core/types.ts`와 `data/balance.ts`를 별도로 보존하면서 기존 전투 엔진을 계속 사용할 수 있다. 이전 코드와 새 코드를 같은 폴더에 섞으면 어느 파일이 현재 게임의 중심인지 다시 모호해진다.

## 검증

상대 경로 import와 초상화 glob을 재작성한 뒤 `src/v5` 참조가 남지 않았는지 확인한다. `npm run build`, `npm test`, 시뮬레이터 실행으로 현재 플레이 흐름을 확인한다. 새 폴더에서만 Git 커밋을 만든다.
