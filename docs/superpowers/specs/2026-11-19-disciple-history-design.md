# 제자의 이름과 생애 인과관계

사용자가 지적한 문제는 은퇴 이벤트가 과거에 없던 검술 제자를 만들어 내는 것이다. 실제 주력이 체술에서 사격으로 바뀐 삶에서도 검을 가르쳤다고 서술했다. 후속 요구에 따라 제자는 여러 명일 수 있고 각자 이름을 갖는다.

문구만 무예로 바꾸거나 검술 조건만 추가하면 실제 사제 관계가 없는 문제는 남는다. 따라서 인물 ID와 수련 이력을 기록하는 방식으로 수정한다. 기존 인물 목록을 함께 사용하고, 별도의 제자 목록에 처음 가르친 유파·주인공 나이·장소·후속 수련·출항·재회 결과를 저장한다. 제자 이름은 기존 NPC 작명 방식을 사용하되 인생 안에서 중복을 피한다.

현재 주력 유파를 실제로 두 번째 경지까지 익혔을 때 제자 제안이 열린다. 받아들인 선택만 기록하며, 거절이나 한 번의 지도는 사제 관계가 되지 않는다. 세 해 이상 수련 뒤 첫 실전을 되짚고, 그로부터 두 해 이상 지나 출항을 선택할 수 있다. 출항을 미루면 실제 출항 기록은 남지 않는다. 출항 후 여덟 해 이상 지나고 스승이 55세 이상의 은퇴자일 때 옛 제자가 도전한다. 각 장면의 인물을 대기 창에 고정해 여러 제자의 진행을 섞지 않는다.

가르친 유파는 과거의 사실로 보존한다. 스승이 다른 유파로 전향하면 재회 문장에서 현재의 길과 제자가 배운 길을 함께 언급한다. 21개 유파별로 구체적인 첫 가르침을 둔다. 선택 결과는 동일한 인물의 관계를 바꾸며 새 제자를 생성하지 않는다.

옛 저장의 근거 없는 제자 재회·출항 대기 창은 닫는다. 기존 생애와 다른 저장 데이터는 유지하고, 과거의 사제 관계를 역으로 만들어 넣지 않는다. 새 기록은 저장·불러오기 이후에도 유지한다.

검증은 선행 사건 없는 재회 차단, 21개 유파, 여러 제자의 고유 이름과 결과 분리, 최소 시간, 출항 연기, 사망한 제자 제외, 기존 저장과 새 저장의 복원에 집중한다.
