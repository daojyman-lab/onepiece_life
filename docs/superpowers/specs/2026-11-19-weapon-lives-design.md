# 인연으로 선택하는 체술·무기술

## 요청과 범위
2026-11-19 요청: 검술은 무기술 아래에 놓는다. 창·둔기를 검술로 취급하지 않는다. 문서의 세부 유파를 실제 주력·장비·성장·전투에 연결하고, 사람과 직업에서 무기를 선택하는 사건을 만든다. 카이도의 이야기를 듣고 자기 몽둥이를 제작하는 길, 조선공이 작업 해머를 무기로 발전시키는 길을 포함한다.

## 구조와 선택
- 상위 계통은 체술 / 무기술 / 악마의 열매 / 패기. 무기술의 성장 갈래는 도검(sword), 장병기(polearm), 둔기(blunt), 사격(gun). sword와 gun 키는 기존 저장 호환용으로 유지하지만 서로 동등한 무기술 하위 갈래다.
- 기존 sword에 창·둔기 태그만 붙이는 방안은 요청과 충돌한다. 모든 저장을 통째로 바꾸는 방안 대신, 장병기·둔기 갈래를 추가하고 저장 정규화에서 확장한다.
- 21개 유파를 독립 누적 숙련으로 관리한다. 체술 6종, 도검 4종, 장병기 3종, 둔기 3종, 사격 5종. 계통 숙련은 해당 유파의 합산 표시이며 별도로 보상을 중복 지급하지 않는다.
- 한 인물의 실제 주력 유파는 하나다. 배운 유파로 전향할 수 있고 이전 숙련·무기·인연은 보존한다. 같은 갈래의 다른 유파를 골라도 이전 유파의 숙련으로 고급 기술을 빌려 쓰지 못한다.
- 전투 기술은 주력 유파에 맞는 것과 보유한 패기·열매를 사용한다. 창으로 검을 휘두르거나 둔기로 참격을 날리지 않는다. 무기의 배율도 같은 성장 갈래에만 적용한다.

## 사건 흐름
유파마다 만남 → 실제 생활에서 연습/제작 → 무기를 물려받거나 완성하고 주력으로 선택 → 경지에 따른 재회/후속 수련을 둔다. 입문 선택만으로 완성 무기와 높은 단계를 지급하지 않는다.

- 창: 물길을 지키던 창잡이와 수련하고, 그가 손에 맞춰 다듬은 창을 받는다.
- 몽둥이: 카이도의 이야기를 전하는 생존자와 장인에게 무게 중심을 배우고, 스스로 철심 몽둥이를 제작한다. 카이도와 직접 만났거나 그의 기술·패기를 전수받았다고 기록하지 않는다.
- 해머: 조선공의 작업과 사수의 가르침에서 작업 해머를 전투 무기로 발전시킨다.
- 다른 유파도 각각 스승, 생업, 지역 인연과 구체적인 기술·무기를 가진다. 지역·직업·나이 조건과 거절 선택지를 둔다.

연습은 실제 토막의 train/work/roam만 센다. 같은 선택창을 다시 고르거나 저장을 재정규화하여 보상을 복제할 수 없다. 추가 과도한 능력치 보상은 주지 않는다.

## 화면과 저장
기존 인물 패널에 상위 계통, 주력 유파, 유파별 숙련·경지, 배운 무기 전환, 인연·연습 진행도를 표시한다. 기존 검·총·체술 저장은 일도류·권총 사격·권법으로 1회 이관한다. 기존 강철창은 장병기로 이관하되 검술 성장치를 복제하지 않는다.

## 검증
주력 변경, 창/둔기 기술, 독립 숙련, 인연 진행의 실제 토막 조건, 직업/지역 제한, 거절, 재진입 중복 방지, 저장 왕복, 옛 창 저장, UI 자료, 자동 생애 진행을 검증한다. 기존 작업 중 변경은 보존한다. 이번 범위는 세부 무술·무기와 그 인생 사건이며 패기·열매 확률 개편 전체의 완료를 주장하지 않는다.


## 검증 중 정한 세부 규칙
- 입문은 무스승 상한 3을 유지한다. 유파 3단계, 시련 40 이상 또는 승리 5회, 같은 섬의 살아 있는 인연과 재회하여 고급 가르침을 받아야 상한 6을 연다. 기존 유료 스승 상한과 다른 유파의 숙련을 우회하지 않는다.
- 지역 연습 약속 동안 자동 출항을 미루어, 플레이어가 제어하지 못하는 연간 항해가 첫 세 토막을 잘라 버리지 않게 한다. 이야기의 명시적 이동까지 봉쇄하지 않는다.
- 기능적 입문과 전향에 특정 가치관을 강요하지 않는다. 정점에 서겠다는 별도 다짐 등 실제 의도가 있는 문만 가치관을 변경한다.
