# 생애 통합 보강: 로그타운 검객 첫 코스

근거: `docs/01_기획/v06_기획과_현행_플레이_통합_보강_제안서.md`. 사용자의 구현 요청에 따라 제안서의 첫 개발 범위를 적용한다.

## 범위와 접근

전투 수치부터 바꾸거나 모든 섬의 대사를 늘리는 대신, 기존 전환점·전투·알라바스타 장편을 한 생애의 인과관계로 연결한다. 전체 섬 달력 개편, 모든 출생/직업 확장은 후속 작업이다. 노화 50세, 기존 상대 전력, 기존 장면 ID와 schema 5는 유지한다.

구현 판단: 새 게임의 로그타운 출생자는 여덟 살에 위조 지도 피해를 본 기록꾼 페니와 약속한다. 열 살 이후 호위/결투 검술을 골라 검객의 꿈을 품고, 열여섯 살에 소개장으로 알라바스타행 상선 또는 해군 호송에 합류할 수 있다. 뭍에 남거나 다른 길을 택하는 문도 둔다. 기존 저장의 성인에게 유년기 약속을 소급 부여하지 않는다.

## 상태와 진행

- 선택 결과는 optional `lifeStory`에 일회성 사건 ID, 선택 당시 나이/토막/섬, 관련 인물 ID로 저장한다. 사건 기록과 보상을 분리해 중복 기록을 막는다.
- 실제 토막이 진행된 횟수 `elapsed`를 센다. 전성기의 두 바퀴도 각각 센다. 선택창을 열거나 전투를 재생하는 것은 시간을 진행하지 않는다.
- 조사 대기는 한 토막 뒤 열리며 세 토막까지 유효하다. 섬을 떠나거나 기한을 넘기면 다른 결과로 닫힌다. 보통의 성장/회복을 한 번만 적용하고, 대기 자체는 보너스 성장을 지급하지 않는다. 사망하면 후속을 열지 않는다.
- 즉시 후속 큐와 장기 재회를 분리한다. 준비·출항·재회·전수는 적절한 시기에 우선 제시하되 이미 진행 중인 장편 큐와 대기창을 침범하지 않는다.

## 플레이 연결

1. 유년기: 페니에게 사람을 지키겠다고 약속하거나, 위조 지도를 직접 검증할 실력을 쌓겠다고 결심한다. 페니는 한 사람으로 유지한다.
2. 수련: 호위는 검으로 막는 법, 결투는 틈을 읽는 법을 배운다. 검술 입문/스승/선호도와 꿈을 연결한다. 현재 경지, 몸 상태, 준비 조건과 다음 기회를 인물 칸에 표시한다.
3. 출항: 민간 호송/해군 호송/남기 중 선택. 목적지, 소개받을 사람, 위험과 얻을 기회를 적는다. 군인이 이미 된 경우 신분을 임의로 민간인으로 바꾸지 않는다.
4. 알라바스타: 기존 가뭄 장편의 마지막 수레 준비 뒤에 호위/증거 조사/정면 대치를 연결한다. 호위는 배운 방어 검술 또는 활동 가능한 지원 인력이 필요하다. 정면 대치는 검술·몸 조건을 검사하고 기존 하잠의 고정 전력으로 싸운다. 증거는 실제 대기 후 확보한다. 승리/패배/후퇴/이탈은 서로 다른 사건·비용·관계 결과를 남긴다. 기존 우물 후일담으로 합류한다.
5. 재회: 결판으로부터 최소 두 실제 해 뒤 페니의 편지/기록을 통해 구한 사람 또는 남긴 빚이 돌아온다. 죽은 인물을 되살리지 않는다. 스승의 인정은 호위/증거의 성과 또는 결투 승리와 연결되고, 전성기는 25세 이상에서 본인의 동의를 얻는다.
6. 황혼기: 41세 이후 실제 배운 기술과 성과를 전하거나 기록으로 남긴다. 꿈의 마지막 대답은 첫 약속, 수련, 알라바스타 결과와 전수를 회수한다. 코스 밖의 인생은 기존 엔딩을 사용한다.

## 검증

일반 `newLife5`부터 강제 상태 변경 없이 동일 시드의 두 정책을 실행해 서로 다른 수련·해결·엔딩을 확인한다. 별도 상태 단위 검증에서는 무장 불가/중상/지원 인력 부상, 패배·후퇴, 대기 중 이탈/사망, 옛 저장, 전투 전후 JSON 왕복, 일회성 보상, 전성기 시계를 확인한다. 기존 콘텐츠 검사와 전체 테스트/빌드를 실행한다. 실제 브라우저 플레이 여부는 검증 기록에 사실대로 남긴다.
