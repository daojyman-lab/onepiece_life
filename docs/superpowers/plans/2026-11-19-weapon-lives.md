# 무기술과 인연 사건 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 인연과 직업에서 시작한 21개 세부 유파를 실제 무기·숙련·주력·전투·꿈에 연결한다.
**Architecture:** 독립 장병기/둔기 갈래와 데이터 중심 유파, 인연 상태, 실제 토막 연습, 장비/기술 연결을 추가한다. 저장은 정규화에서 확장한다.
**Tech Stack:** TypeScript, Preact, Vitest, Vite.
**Spec:** ../specs/2026-11-19-weapon-lives-design.md

## Global Constraints
- 기존 미커밋 생애 이야기 변경을 덮어쓰지 않는다.
- 창/둔기를 sword에 연결하지 않는다. 무기술 공통 숙련은 하위 유파 합산이다.
- 실제로 배운 유파만 전향 가능. 저장 이관은 반복 호출해도 중복 지급하지 않는다.

## Review Focus
기존 최고 검술 경지가 새 창술의 전투력으로 복제되는 문제, 다른 유파 장비의 배율 유출, 사건 선택 반복으로 보상 복제, 사망한 스승 재회, 옛 저장을 두 번 읽었을 때 이중 숙련을 확인한다.

## 진행 기록
- 시작 시 다른 작업의 미커밋 파일을 확인했다. 현재 작업 폴더에서 해당 변경을 보존하고 진행한다.
- 기준 테스트 실행에서 기존 life-story 4건, ending 1건, flow 1건 실패가 이미 관찰됐다. 최종 검증에서 재확인한다.

- 21개 유파/63개 전환점/126개 전투 기술을 구현했다. 저장 이관, 독립 숙련, 실제 토막 연습, 실전 보상과 중복 방지를 연결했다.
- 리뷰에서 찾은 상한 우회, 새 유파의 전투 숙련 차용, 손상된 인연 저장, 비주력 보상의 숙련 감소, 연속 구입 무기 유실, 검객 꿈의 잘못된 달성을 회귀 테스트로 고쳤다.
- 기준 전체 검증에서 창의 구분을 검술로 기대하던 테스트 1건을 새 장병기 규칙으로 갱신했다. 대량 균형 검사에서 드러난 입문 빈도와 일괄 평온 보상 편향을 동일 시드 A/B로 확인했다. 만남 가중치를 2→0.35로 조정하고 단순 거절에 점수를 억지로 붙이지 않는다.
- 100명씩 A/B에서 야망/평온 평균 최고 단계 3.10/2.56→3.96/2.13, 넉넉한집/빈곤·고아 극의 도달 23/20→31/35명. 40명 무작위 인생 예상 길이 45.27→43.76분. 이 표본은 최종 600명 검증을 대체하지 않는다.
- 빌드와 타입 검사 통과. Chrome 데스크톱/모바일 500px 화면에서 유파 전향 및 localStorage 반영 PASS, 스크린샷으로 배치 확인.


## 최종 확인과 통합 경계
- 기본 입문은 3단계 상한을 유지하며, 실제 유파 3단계와 시련 40 또는 승리 5회 후 인연의 고급 가르침으로 그 유파의 상한 6을 연다. 실제 창술 재회 사건으로 병기가 꿈까지 연결되는 테스트를 포함한다.
- 연습 약속 중 자동 출항을 미루며, 몸이 그 유파를 더는 다룰 수 없으면 자동 출항을 영구 봉쇄하지 않는다.
- 동일 폴더의 별도 main 배포 통합이 진행되어 이전 전체 검사 스냅샷은 최신 통합 코드의 통과 근거로 사용하지 않는다. 통합 후 `styles`, `growth`, `load`, `content` 4개 파일 64개 테스트가 통과했다.
- 통합 후 최신 `npm run build` 통과 (162 modules). 전체 통합 항해·전투·밸런스 회귀는 별도 배포 통합 작업에서도 진행 중이며 전체 통과로 표시하지 않는다.
- 이전 전체 검사에서는 시뮬레이션의 선택 수/반복/성향 분포와 병행 실행에 따른 시간 제한 실패를 관찰했다. 이후 사건 값·반복 상한·빈도 조정과 main 통합이 있었으므로 이전 수치를 최신 수치로 재사용하지 않는다.
