# v5 3단계: 로그타운의 사건 완성 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로그타운(이스트 블루)에서 태어난 인생이 처음부터 끝까지 사건이 모자라지 않고, 같은 일이 되풀이되지 않고, 앞뒤가 맞고, 가치관이 한쪽으로 쏠리지 않게 한다.

**Architecture:** 먼저 코어에 "앞뒤가 맞게 하는 장치"(필요한 것 `needs`, 마을 조건, 되풀이 막기, 가족과 원작 인물의 나이)를 넣고 시뮬레이터에 새 지표를 더한다. 그다음 v4의 사건 177개를 다시 나눈 목록을 만들고, 그 목록에 따라 인생의 시기와 길마다 사건을 쓴다. 마지막에 가치관 표시와 수치를 시뮬레이터 기준에 맞추고, 브라우저에서 끝까지 플레이해 확인한다.

**Tech Stack:** TypeScript 7, Vite 8, Preact 11, Vitest 5. v4의 사건 데이터는 이 가지에서 지워졌으므로 `git show v4.0.16:src/data/<파일>`로 읽는다.

**Spec:** `docs/superpowers/specs/2026-11-15-v5-갈래-인생-설계.md` (5.1, 5.2, 5.2a, 5.2b, 5.3, 5.4, 5.5, 5.6, 5.9, 7장)

## Global Constraints

- 작업 가지는 `v5-life`. `main`과 태그 `v4.0.16`은 건드리지 않는다. 푸시하지 않는다.
- `src/v5/core/`는 DOM, 타이머, `localStorage`, `Math.random`, `Date`를 쓰지 않는다. 난수는 `rngOf(s.rng)`만 쓴다. 상태에는 값만 둔다.
- 규칙에 쓰는 수치는 모두 `src/v5/data/balance.ts`의 `V`에 둔다.
- 상태(`Life5`)에 칸을 더하면 `emptyLife`와 `normalizeLife5`가 옛 저장의 빈 칸을 기본값으로 채우게 하고, 그 테스트를 `tests/v5/load.test.ts`에 더한다.
- 화면이 코어에 보내는 명령은 `step`과 `answer`뿐이다. 가치관 점수(숫자)는 어디에도 내지 않는다.
- **사건을 쓰는 규칙** (모든 내용 과제에 적용):
  - 전환점의 문은 2~3개. 가치관이 깊어야 열리는 특별한 문은 많아야 하나 더.
  - 문의 `label`은 하는 일, `hint`는 상황과 예상되는 결과. 가치관의 이름을 쓰지 않는다.
  - 가치관 점수는 `V.value.door`(큰 계기는 `V.value.moment`)만 쓴다.
  - 물러서거나 거절하는 문에 평온을 붙이는 것은 그 물러섬이 "조용한 삶을 고른다"는 뜻일 때뿐이다. 가족 곁에 남으려는 거절은 헌신이나 의리, 옳지 않아서 하는 거절은 정의, 매이기 싫어서 하는 거절은 자유다. 뜻이 없는 물러섬에는 가치관을 붙이지 않는다.
  - 한 파일에서 평온이 붙은 문은 가치관이 붙은 문의 18%를 넘지 않는다.
  - 사건의 글이 동료, 배우자, 자식, 형제, 헤엄, 칼, 총, 배를 전제로 하면 `needs`에 적는다(과제 2). 적지 않으면 `tests/v5/content.test.ts`가 잡는다.
  - 제안을 거절하는 문에는 `closes: true`를 붙인다(거절한 제안은 그 인생에서 다시 오지 않는다).
  - 원작 인물과 장소는 원작의 이스트 블루와 어긋나지 않게 쓴다. 대사는 새로 쓴다(원작의 대사를 옮겨 적지 않는다).
  - 글은 기록체("~했다")로, 주인공을 "너"라고 부르지 않는다. 이름이 들어갈 자리는 `{name}`, 조사는 `(이)가`·`을(를)` 꼴로 적어 `josa`에 맡긴다.
  - 새 전환점은 아래 "File Structure"의 파일에 넣는다. 한 파일이 500줄을 넘으면 같은 폴더에 `-2`를 붙인 파일로 나눈다.
- 균형을 맞출 때 테스트의 기준(숫자)을 고치지 않는다. 기준에 닿지 않으면 무엇이 필요한지 보고한다.
- 테스트: `npx vitest run tests/v5`. 전체 확인: `npm run typecheck && npm test && npm run build`.
- 커밋 메시지는 한국어로 쓰고 끝에 하니스가 준 `Co-Authored-By` 줄을 붙인다.

1. **전제가 없는 사건** — 열매를 먹은 사람에게 바다에 뛰어드는 문, 동료가 없는 사람에게 "동료들을 먼저 보내고", 형제가 없는 사람에게 "동생들의 밥". `needs`로 막고, 글의 낱말로 빠뜨린 것을 잡는 테스트를 둔다. (과제 2, 그리고 모든 내용 과제의 `content.test.ts`)

5. **약한 채로 강한 바다에 간 사람** — 어려서 위대한 항로나 신세계로 끌려간 인물에게 숨기 · 달아나기 · 협상의 문이 열린다(싸움뿐이면 안 된다). (과제 10)

**Interfaces:**
- Produces:

```ts
// types.ts
export type Need = 'crew' | 'spouse' | 'child' | 'sibling' | 'parent' | 'swim' | 'sword' | 'gun' | 'fist' | 'arms' | 'ship';
// Cond에 더한다
| { c: 'town'; is: string[] }                 // 태어난 마을 (hero.town)
| { c: 'standingYears'; min: number }         // 지금의 처지가 된 지 몇 해
// Turning, Door에 더한다
needs?: Need[];
// Turning에 더한다
max?: number;                                 // 한 인생에 많아야 이만큼. 없으면 once는 1, 되풀이는 V.turning.maxRepeat
// Door에 더한다
closes?: boolean;                             // 이 문을 고르면 이 전환점은 그 인생에서 다시 오지 않는다
// Life5에 더한다
seenCount: Record<string, number>;            // 전환점 id → 이번 인생에 열린 횟수
closed: string[];                             // closes 문으로 닫힌 전환점 id
standingSince: number;                        // 지금의 처지가 된 나이

// needs.ts
export function needOk(s: Life5, n: Need): boolean;
export function needsOk(s: Life5, ns?: Need[]): boolean;
export function whyNeed(s: Life5, ns?: Need[]): string | null;   // 처음 걸리는 것의 까닭. 예: '함께할 동료가 없다'
```

- 사람의 관계(`Person.relation`)는 지금 자유로운 글이다(`'자식'`, `'동료'`, `'어릴 적 동무'` …). 관계의 갈래를 `src/v5/data/words.ts`의 `RELATION_KIND: Record<'spouse' | 'child' | 'sibling' | 'parent', string[]>`에 모은다(배우자: `배우자`·`아내`·`남편` / 자식: `자식`·`아들`·`딸` / 형제: `형`·`누나`·`오빠`·`언니`·`남동생`·`여동생` / 부모: `아버지`·`어머니`). 사건 데이터가 이 갈래의 사람을 만들 때는 이 낱말만 쓴다(`content.test.ts`가 확인한다).
- `needOk`의 뜻: `crew` 살아 있고 함께 싸우는 동료(`Person.crew`가 있는 사람)가 하나 이상 · `spouse` `child` `sibling` `parent` 그 갈래의 살아 있는 사람이 있다 · `swim` 열매를 먹지 않았다 · `sword` `gun` `fist` 그 갈래의 단계가 1 이상 · `arms` 두 팔 가운데 하나 이상을 쓸 수 있다(멀쩡하거나 단 것) · `ship` `flags`에 `ship`이 있다.
- 전환점의 `needs`가 안 맞으면 그 전환점은 뽑히지 않는다. 문의 `needs`가 안 맞으면 그 문은 잠기고 까닭이 `whyNeed`의 말로 보인다.
- `V.turning = { maxRepeat: 3 }`. `seenCount`가 `max`에 닿은 전환점과 `closed`에 든 전환점은 뽑히지 않고, 줄에 서 있어도 열리지 않고 버려진다.
- 처지가 바뀌면(`standing` 효과) `standingSince`를 그때의 나이로 적는다.
- **"전에 골라 본 문" 표시는 지난 인생의 것만이다.** `ResolvedDoor.tried`는 `s.known`에 있을 때만 참이다(이번 인생에 고른 것은 표시하지 않는다).

import { describe, expect, it } from 'vitest';
import { needOk, whyNeed } from '../../src/v5/core/needs';
import { newLife5 } from '../../src/v5/core/state';
import { resolveDoors, openTurning, pickTurning, answerDoor } from '../../src/v5/core/turning';
import { normalizeLife5 } from '../../src/v5/core/load';
import { rngOf } from '../../src/core/rng';
import { V } from '../../src/v5/data/balance';
import type { Life5, Turning } from '../../src/v5/core/types';

const adult = (seed = 1): Life5 => { const s = newLife5(seed); s.pending = null; s.age = 25; s.hero.standing = 'pirate'; s.people = []; return s; };
const T = (over: Partial<Turning>): Turning => ({ id: 'x', kind: 'door', when: [], weight: 5, repeat: { years: 1 }, speaker: 'hero', title: '제목', body: '본문',
  doors: [{ label: '받는다', hint: '', fx: [] }, { label: '거절한다', hint: '', fx: [], closes: true }], ...over });

describe('필요한 것', () => {
  it('열매를 먹으면 헤엄칠 수 없다', () => {
    const s = adult(); expect(needOk(s, 'swim')).toBe(true);
    s.hero.fruit = { id: 'f', eatenAt: 20 }; expect(needOk(s, 'swim')).toBe(false);
    expect(whyNeed(s, ['swim'])).toMatch(/헤엄/);
  });
  it('동료, 배우자, 형제는 살아 있는 사람이 있어야 한다', () => {
    const s = adult();
    for (const n of ['crew', 'spouse', 'child', 'sibling', 'parent'] as const) expect(needOk(s, n)).toBe(false);
  });
  it('두 팔을 다 잃으면 팔이 필요한 일을 못 한다', () => {
    const s = adult(); expect(needOk(s, 'arms')).toBe(true);
    s.hero.limbs.armL = 'lost'; expect(needOk(s, 'arms')).toBe(true);
    s.hero.limbs.armR = 'lost'; expect(needOk(s, 'arms')).toBe(false);
    s.hero.limbs.armR = 'basic'; expect(needOk(s, 'arms')).toBe(true);
  });
  it('문의 필요가 안 맞으면 까닭과 함께 잠긴다', () => {
    const s = adult(); s.hero.fruit = { id: 'f', eatenAt: 20 };
    const t = T({ doors: [{ label: '바다에 뛰어든다', hint: '', fx: [], needs: ['swim'] }, { label: '버틴다', hint: '', fx: [] }] });
    const d = resolveDoors(s, t);
    expect(d[0].locked).toMatch(/헤엄/); expect(d[1].locked).toBeNull();
  });
  it('전환점의 필요가 안 맞으면 열리지 않는다', () => {
    expect(openTurning(adult(), T({ needs: ['crew'] }))).toBe(false);
  });
});

describe('되풀이 막기', () => {
  it('거절한 제안은 그 인생에서 다시 열리지 않는다', () => {
    const s = adult(); const t = T({});
    expect(openTurning(s, t)).toBe(true);
    answerDoor(s, 1);                                   // closes 문
    expect(s.closed).toContain('x');
    s.age += 10; expect(openTurning(s, t)).toBe(false);
  });
