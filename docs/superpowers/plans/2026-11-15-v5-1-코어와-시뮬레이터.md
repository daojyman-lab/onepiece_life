# v5 1단계: 코어와 시뮬레이터 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 화면 없이 v5의 한 인생(출생 → 가치관이 쌓이는 선택 → 자동으로 흐르는 해 → 싸움과 신체 손실 → 기연 → 죽음 → 엔딩 자료)이 끝까지 흐르고, 시뮬레이터가 설계의 균형 지표를 뽑아 준다.

**Architecture:** v5 코어를 `src/v5/` 아래에 새로 짠다. v4 코어(`src/core/`)와 화면은 손대지 않아 앱은 계속 빌드된다. v4에서 그대로 쓸 수 있는 것(시드 난수, 조사 처리, 전투 엔진의 `startBattle`/`runBattle`/`enemyUnit`, 열매 · 기술 · 재능 · 성씨 데이터)은 복사하지 않고 가져다 쓴다. 상태는 값만 갖고, 화면은 명령(`step`, `answer`)만 보낸다. 대기 중인 일(`pending`)이 있으면 흐르지 않는다.

**Tech Stack:** TypeScript 7, Vitest 5, vite-node (시뮬레이터). 새 의존성 없음.

**Spec:** [docs/superpowers/specs/2026-11-15-v5-갈래-인생-설계.md](../specs/2026-11-15-v5-갈래-인생-설계.md)

**이 계획의 범위.** 설계는 네 단계로 나눠 만든다. 이 문서는 1단계다.

| 단계 | 내용 | 계획 문서 |
|---|---|---|
| 1 | 코어와 시뮬레이터, 로그타운 최소 사건 | 이 문서 |
| 2 | 화면 (기록 흐름, 문 고르기, 전투 팝업, 프로필, 엔딩). 끝에 `src/v5/`를 `src/core/` · `src/data/`로 옮기고 v4 코어를 지운다 | 1단계가 끝난 뒤 쓴다 |
| 3 | 로그타운 사건 완성 (v4 사건 147개 재분류)과 균형 | 2단계가 끝난 뒤 쓴다 |
| 4 | 나머지 다섯 고향. 끝나면 main과 사이트에 올린다 | 3단계가 끝난 뒤 쓴다 |

## Global Constraints

- 작업 가지는 `v5-life`. `main`과 태그 `v4.0.16`은 건드리지 않는다.
- `src/core/`, `src/data/`, `src/ui/`, `src/app/`의 기존 파일은 고치지 않는다. 가져다 쓰기만 한다.
- `src/v5/core/`는 DOM, 타이머, `localStorage`, `Math.random`, `Date`를 쓰지 않는다. 난수는 `src/core/rng.ts`의 `rngOf(s.rng)`만 쓴다.
- 상태에는 값만 둔다. 함수를 넣지 않는다. `JSON.parse(JSON.stringify(s))`로 되살린 상태는 같은 명령에 같은 결과를 낸다.
- 수치는 모두 `src/v5/data/balance.ts`의 `V`에 둔다. 규칙 코드에 숫자를 직접 쓰지 않는다.
- 플레이어가 보내는 명령은 `step`과 `answer` 둘뿐이다. 상점, 수련, 편성 명령을 만들지 않는다.
- 가치관 점수(숫자)는 기록 문장, `pending`의 선택지, 엔딩 자료 어디에도 넣지 않는다. 말로만 드러낸다.
- 화면에 나가는 한국어 문장은 `src/core/josa.ts`의 `josa()`를 거친다.
- 가치관 아홉 가지의 id와 이름: `justice` 정의, `devotion` 헌신, `ambition` 야망, `romance` 낭만, `inquiry` 탐구, `loyalty` 의리, `freedom` 자유, `dominion` 패도, `peace` 평온.
- 고향 여섯 곳의 id: `loguetown`, `water7`, `wano`, `fishman`, `sky`, `zou`. 이 단계에서 사건을 채우는 곳은 `loguetown`뿐이다. 나머지 다섯 곳은 출생 주사위에서 뽑히지 않게 가중치 0으로 둔다.
- 테스트 실행: `npx vitest run tests/v5`. 전체 확인: `npm run typecheck && npm test`.
- 커밋 메시지는 한국어로 쓰고 끝에 다음 줄을 붙인다: `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`

## Review Focus

설계가 요구하지만 과제별 테스트가 놓치기 쉬운 것들. 각 줄의 테스트는 표시한 과제에 넣었다.

1. **팔 둘, 다리 둘, 눈 둘을 모두 잃은 인물.** 인생이 멈추거나 능력치가 0 이하 · NaN이 되면 안 된다. 끝까지 흘러 죽음에 이른다. (과제 10)
2. **모든 문이 잠긴 전환점.** 출생과 가치관 조건 때문에 고를 문이 하나도 없으면 안 된다. 열린 문이 없는 전환점은 뜨지 않는다. (과제 6)
3. **대기 중에 저장했다 불러온 인생.** 문 고르기나 싸움 물음이 떠 있는 상태를 JSON으로 되살려도 같은 답에 같은 결과가 나온다. (과제 4)
4. **성을 모르는 고아의 이름.** 기록, 문 본문, 엔딩 자료 어디에도 `undefined`나 빈 성씨가 찍히지 않는다. (과제 2, 과제 12)
5. **조건이 맞는 사건이 하나도 없는 해.** 뜰 사건이 없어도 해는 넘어간다. 멈추지 않는다. (과제 4)

const avg = (f: (s: Life5) => number, xs = lives) => xs.reduce((a, s) => a + f(s), 0) / xs.length;
const topTier = (s: Life5) => Math.max(...Object.values(s.growth.tier));
const rate = (xs: Life5[], f: (s: Life5) => boolean) => xs.filter(f).length / Math.max(1, xs.length);

describe('시뮬레이터 (설계 7장)', () => {
  it('멈추는 인생도, 불변 조건을 어기는 인생도 없다', () => {

  });
  it('멈춤은 한 인생에 50~110번이다', () => {

    expect(a).toBeGreaterThanOrEqual(50); expect(a).toBeLessThanOrEqual(110);
  });
  it('큰 기연은 평균 0.3~2번이고, 한 번도 없는 인생이 20% 이상이다', () => {
    const a = avg((s) => s.stats.fortunes);
    expect(a).toBeGreaterThanOrEqual(0.3); expect(a).toBeLessThanOrEqual(2);
    expect(rate(lives, (s) => s.stats.fortunes === 0)).toBeGreaterThanOrEqual(0.2);
  });
  it('아홉 가지 가치관 모두 가장 높은 가치관이 되는 인생이 나온다', () => {

  });

    for (const s of lives) by[s.hero.standing] = (by[s.hero.standing] ?? 0) + 1;
    expect(Object.keys(by).length).toBeGreaterThanOrEqual(6);
    expect(Math.max(...Object.values(by)) / N).toBeLessThanOrEqual(0.5);
  });
  it('가치관이 다르면 같은 출생이라도 도달한 힘이 달라진다', () => {
    const a = Array.from({ length: 150 }, (_, i) => autoplay5(9000 + i, { value: 'ambition' }).s);

  });
  it('중간 단계(4단계)는 넉넉한 집이, 최상위(6단계)는 가난한 집과 고아가 더 자주 닿는다', () => {

    const poor = Array.from({ length: 400 }, (_, i) => autoplay5(20000 + i, { value: 'ambition' }, { wealth: 'poor', lineage: 'orphan' }).s);
    expect(rate(rich, (s) => topTier(s) >= 4)).toBeGreaterThan(rate(poor, (s) => topTier(s) >= 4));
    expect(rate(poor, (s) => topTier(s) >= 6)).toBeGreaterThan(rate(rich, (s) => topTier(s) >= 6));
  });
  it('신체를 잃는 인생은 절반 이하이고, 잃은 뒤에도 열 해 넘게 사는 인생이 그중 절반 이상이다', () => {

    expect(after.length / Math.max(1, lost.length)).toBeGreaterThanOrEqual(0.5);
  });
