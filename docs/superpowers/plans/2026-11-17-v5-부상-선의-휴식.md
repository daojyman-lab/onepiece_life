# 부상·병·선의·휴식 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 전투 손상이 실제 부상으로 남고 현실 병명, 선의의 치료, 직접 휴식을 플레이에 반영한다.

**Architecture:** 기존 Life5와 전투 결과 경로를 유지하면서 상처 정보와 선의의 의료 능력을 추가한다. 치료와 회복은 공통 코어에서 한 토막마다 처리하고, UI는 상태와 수동 휴식 명령을 보여 준다.

**Tech Stack:** TypeScript, Preact, Vitest

**Spec:** docs/superpowers/specs/2026-11-17-v5-부상-선의-휴식-설계.md

## Global Constraints

- 기존 저장의 부위 없는 상처와 `cough` 병 기록을 읽는다.
- 원작 병은 무작위 질환으로 사용하지 않는다.
- 사용자 작업 내용이 많은 현재 `v5-life` 브랜치에서 관련 파일만 수정한다.

## Review Focus

- 전투 화면에서 주인공 HP가 0인 패배 뒤 살아남으면 무거운 상처와 체력 감소가 남는가.
- 선의가 없는 경우와 의료 능력이 높은 선의가 있는 경우 회복 차이가 있는가.
- 질환의 이름과 치료 경과가 화면과 기록에 일치하는가.
- 저장된 옛 상처와 병이 새 화면을 깨지 않는가.
- 휴식 명령이 시간을 한 토막만 진행하고 대기 중인 선택을 건너뛰지 않는가.
