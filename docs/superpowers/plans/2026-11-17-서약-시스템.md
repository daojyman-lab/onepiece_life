# 서약 시스템 구현 계획

**목표:** v6.8 장편에서 신념에 근거해 미리 서약하고, 여러 장면의 선택과 결과를 통과했을 때 큰 성장을 얻는다.

**구조:** 저장 상태에 활성 서약과 완료 기록을 둔다. `data/vows.ts`에 서약별 자격·단계·종료 장면을 정의하고 `core/vow.ts`가 모든 장면 선택과 시간 진행을 받아 진행·만료·결산한다. 첫 적용 장편은 하늘섬 원작 전 「번개 아래의 장부」로, 티카와의 인연·피난 준비·결전·피난처 완성을 모두 확인한다. 기존 저장은 서약이 없는 상태로 읽는다.

**기술:** TypeScript, Vitest, Preact. 기존 `schema: 5` 유지.

**제약:** 신념 점수는 표시하지 않는다. 서약 자체는 전투력을 높이지 않는다. 패배에 성장 보상을 주지 않는다. 같은 서약의 보상은 한 인생에 한 번이다.

## 작업 1: 상태와 판정

- [x] `tests/v5/vow.test.ts`에 시작 자격, 중복, 실패, 성공, 보상, 저장 호환성 검증을 먼저 작성하고 실패를 확인한다.
- [x] `src/v5/data/vows.ts`, `src/v5/core/vow.ts`에 서약 정의와 공통 시작·진행·만료·결산을 구현한다.
- [x] `src/v5/core/types.ts`, `state.ts`, `fx.ts`, `load.ts`, `turning.ts`, `year.ts`에 저장 상태·선택·시간 진행을 연결한다.
- [x] 집중 테스트를 통과시킨다.

## 작업 2: 장편과 화면

## 첫 적용 범위

서약 규칙과 저장 구조는 다른 신념에도 재사용할 수 있게 만든다. 콘텐츠는 의리 서약 한 건을 끝까지 플레이 가능한 형태로 적용한다. 나머지 신념의 개별 장편은 별도 콘텐츠 작성이 필요하다.
