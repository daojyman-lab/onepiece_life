# 성향 이동과 주·부성향 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 여러 선택이 누적되어 3×3 성향표에서 한 칸씩 이동하고, 행을 주성향·칸을 부성향으로 보여 준다.

**Architecture:** 현재의 아홉 가치관 점수는 이야기 잠금과 복합 성향 판단을 위해 유지한다. 별도의 성향 위치와 두 축의 누적 방향을 저장하고, 실제 문 선택 때만 이동을 계산한다. 옛 저장은 기존 점수 중 가장 높은 가치관의 위치에서 시작한다.

**Tech Stack:** TypeScript, Preact, Vitest.

**Spec:** 이 대화에서 승인된 마음(정의·의리·평온), 진취(탐구·낭만·자유), 야망(성취·탐욕·패도) 계열과 ‘여러 선택 후 한 칸 이동’ 규칙.

## Global Constraints

- 한 선택으로는 위치가 바뀌지 않는다. 세 선택의 같은 방향이 쌓여야 한 칸 이동한다.
- 반대 방향 선택은 누적 방향을 상쇄한다. 복합 가치관 선택은 각 방향을 합성하되 한 선택의 힘은 축마다 최대 1이다.
- 기존 가치관 점수와 깊이 판정은 유지한다. 진행 중인 사용자 수정은 보존한다.
- 전투 습관과 기연은 기존 가치관 점수를 계속 따른다. 현재 칸을 여기에 연결하면 시뮬레이션 분포가 바뀌므로, 현재 칸은 인물 표시·호칭·엔딩에 적용한다.
- 화면에서는 주성향과 부성향을 분리한다. 기존 세부 ‘야망’은 화면에서 ‘성취’로 쓴다.
- 배치 결정: 야망 행은 성취·패도·탐욕 순서로 둔다. 성취와 패도를 함께 택한 결과가 탐욕 칸이 되는 것을 막기 위해서다.

## Review Focus

- 초기 선택이 세 번 미만일 때 성향을 성급하게 확정하지 않는다.
- 방향이 서로 상쇄되어 초기 칸에 남았으면, 현재 칸을 충분히 선택하기 전까지 성향을 확정하지 않는다.
- 상반된 선택이 섞이면 이동이 상쇄된다.
- 복합 가치관 선택도 한 번으로 한 칸을 옮기지 않는다.
- 옛 저장을 읽을 때 기존 점수와 이야기 접근성을 보존한다.
- 깊이가 두 가지인 인물의 이야기 잠금과 엔딩은 계속 작동한다.
- 기존 상세 ‘야망’의 모든 화면 문구가 ‘성취’로 일치한다.
