| # | 마일스톤 | 상태 |
|---|---|---|
| M1 | 핵심 루프: 유년기 → 수련기 → 출항 → 임무 · 보스 → 다음 해역 → 결산. 자동 전투 · 준비 · 집단전, 열매 도박, 도감, 저장 | 완료 (v4.0.0) |
| M2 | 콘텐츠 채우기: 열매 100여 종, 선택 132개, 스승 · 보스 · 임무를 해역 단계별로, 21개 항구 이야기 재배치 (05 설계 문서 먼저) | 다음 |
| M3 | 밸런스: 대량 시뮬레이션 지표로 사망 나이 · 해역 도달률 · 빌드별 승률 · 열매 유무 차이 맞추기 | |
| M4 | 연출 · 마감: 섬별 배경, 전투 연출, 아이콘, 효과음, GitHub Pages 배포 | |

## 마일스톤 초안 (v3.3.3 기준, 대체됨)

| # | 마일스톤 | 플레이 가능한 범위 |
|---|---|---|
| 1 | 뼈대 | 새 인생 생성 → 시간이 흐르고 로그가 쌓임 → 저장·불러오기 |
| 2 | 유년기 | 1~15세. 유년기 사건, 부모 사건, 라이벌 대련, 전투 화면 |
| 3 | 항로 | 16세 출항 → 항구 이야기 3단계 → 목적지 선택 → 항해 → 입항. 21개 항구 |
| 4 | 경력 | 소속, 진급, 정기 임무, 인생 과업, 은퇴 |
| 5 | 관리와 생존 | 훈련, 투자, 치료, 필수 위기, 질병, 사망 |
| 6 | 결산 | 사망·은퇴 시 인생 결산 화면, 명예의 전당 |
| 7 | 마감 | 모바일 화면, 뉴스·랭킹, 효과음, 밸런스 조정 |

## 완료 조건

- 모든 작업에 완료 기준이 있다.
- 기획서의 기능이 빠짐없이 어느 작업에 들어 있다.
- 마일스톤마다 검증 방법이 정해져 있다.
