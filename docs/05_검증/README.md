### 밸런스 과제 (M3)

- 강적전 사망이 너무 많다. 특히 무작위로 고르면 대부분 20대에 강적에게 죽는다. 임무 강적의 힘, 치명 판정, 물러나기 기본값을 본다.
- 열매를 먹은 인생과 안 먹은 인생의 차이가 크다 (해역 평균 2단계 차). 기획은 "먹지 않으면 무술 · 패기를 더 깊이" — 열매가 없을 때의 보상이 아직 없다.
- 2단계 보스(스모커, 자연계)가 벽이다. 무장색을 늦게 여는 인생은 여기서 오래 막힌다. 의도한 벽이지만 무장색 눈뜸 경로를 더 둘지 본다.
- smart 정책이 해군을 고르지 않아 해군 길의 지표가 없다. 정책을 길별로 나눠 다시 잰다.
- 이 아래의 "확인할 것" 중 v3.3.3 결함 재발 항목은 v4 구조(pending 하나)로 대체되었다.

## 확인할 것

### 규칙 (자동 테스트)

- 전투력과 승률 계산이 기획서의 공식과 같다.
- 나이대별 진행 단위와 분기·연간 정산이 맞다.
- 해군·혁명군 진급 조건이 맞다.
- 사건이 정해진 나이·조건에서 발생한다.
- 인생 과업의 화면 조건과 실제 판정이 일치한다.

### 생애 시뮬레이션 (대량 실행)

- 무작위 선택으로 수백 번의 인생을 끝까지 돌려도 멈추지 않는다.
- 모든 인생 과업이 달성 가능하다.
- 사망 나이, 최종 전투력, 소지금의 분포가 의도한 범위에 있다.

### 레퍼런스 결함의 재발 여부

- 도착 직후 교전에서 물러나도 시간이 흐른다.
- 이야기를 끝낸 항구에 다시 들어가도 다음 항로를 고를 수 있다.
- 교전 기회가 만료되어도 항구 이야기가 이어진다.
- 과업을 어떤 순서로 바꿔도 과업 창이 열린다.
- 저장했다 불러와도 진행 상태가 이어진다.

### 브라우저 플레이

- 새 인생 생성부터 사망까지 한 번 이상 끝까지 플레이한다.
- PC 화면과 모바일 세로 화면(360px, 390px, 430px)에서 가로 넘침이 없다.
- 모든 모달이 열리고 닫히며, 열려 있는 동안 시간이 멈춘다.

## 완료 조건

- 검증 항목표의 모든 항목에 결과가 적혀 있다.
- 진행을 막는 문제가 없다.
- 남은 문제는 미해결 목록에 처리 방침과 함께 적혀 있다.
