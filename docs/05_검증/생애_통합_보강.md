2026-11-19. 대상은 [생애 보강안](../01_기획/v06_기획과_현행_플레이_통합_보강_제안서.md)의 첫 개발 범위다.

## 요구 대조

| 준비에 따른 다른 결판 | 기존 알라바스타 p7 뒤 호위/증거 조사/결투. 상대의 전력은 주인공 수치에 맞춰 바꾸지 않음 |

## 일반 새 게임 비교

명령: `npx vite-node tools/simulate-life-course.ts 16`. `--find`로 로그타운 마을 출생 시드를 찾을 수 있다. 도구는 `newLife5`와 정상 `apply5` 명령만 사용하며 나이, 능력치, 섬, 결과를 강제로 설정하지 않는다. 선택 정책은 위험한 일반 사건을 피하고 해당 코스의 수련/해결법을 고른다.

| 시기 | 공통 진행과 차이 |
|---|---|
| 8세 | 같은 출생에서 사람을 지킬 약속 / 직접 길을 확인할 결심 |
| 10세 이후 | 호위 검술 / 틈을 읽는 검술. 실제 연습 후 채택 |
| 16세 | 소개장과 기존 가뭄 장편. 호위 / 하잠 결투 / 증거 조사 |
| 조사 경로 | 조사 시작 다음 실제 토막에 증거 장면. 다른 두 경로의 장면 자체는 시간을 추가 진행하지 않음 |
| 약 18세 | 후일담에서 실제 여덟 토막 이상 지난 뒤 재회 기록 |
| 25세 이후 | 성공을 증명한 생애에 인정/전성기. 패배는 성공으로 꾸미지 않음 |
| 41세 | 세 경로 모두 전수/기록에 도달. 세 마지막 대답이 서로 다름 |

전투 결과는 현재 전투/무기술 수치에 따라 달라질 수 있다. 통합 테스트는 승리를 강제하지 않으며 실제 승리 또는 패배가 이후 기록에 일관되게 남는지 확인한다. 코스 전투 상대의 기본 전력 불변은 별도로 검사한다.

## 자동 검증

- `tests/game/life-story.test.ts`: 22개 통과. 일반 생애 비교, 실제 검술 기술, 중복·전투 전후 저장 왕복·옛 저장·깨진 저장·실제 시간·이탈/사망·지원병·꿈 증명·기존 군인·죽은 인연·늦은/중복 출항·동일한 페니 ID·전수받은 견습 ID 검사.
- 독립 코드 리뷰에서 발견한 늦은/중복 소개장의 끊긴 후속을 회귀 테스트로 재현하고 수정했다.
- 생애·항로·콘텐츠·후속 반응·저장·결산·v6.9 장편의 관련 7개 테스트 파일, 총 120개 통과. 중간 타입 검사와 프로덕션 빌드는 통과했다. 최종 공유 폴더 상태의 빌드는 아래 별도 한계를 따른다.
- 브라우저의 실제 화면 조작/가독성 검증과 배포는 이번 작업에서 수행하지 않았다.

### 공유 작업 폴더의 전체 테스트 결과

전체 `npm test -- --reporter=dot` 실행은 **644개 중 637개 통과, 7개 실패**였다. 생애 기능 테스트는 모두 통과했다. 실행 중 다른 무기술·콘텐츠 작업이 같은 폴더에서 함께 수정되고 있었으므로 이 결과는 해당 실행의 관측값이다. 실패를 이번 생애 코스 때문이라고 단정하거나 전체 통과로 표시하지 않는다.

- `sim.test.ts` 4개: 가치관별 성장 격차, 집안 형편별 상위 경지 도달률, 평균 선택 수, 탐욕 성향의 분포.
- `styles.test.ts` 2개: 스승 없는 유파 성장 상한과 같은 갈래의 새 유파 숙련.
- `island-voyage.test.ts` 1개: 창 무기를 기존 검술 갈래로 기대한 항목. 실행 중 해당 기대값이 새 창 갈래로 갱신되는 것도 확인했다.

이 전역 밸런스와 병행 무기술 검증까지 완료한 것으로 간주하지 않는다. 위의 코스 영향 비교와 기능별 회귀 결과를 별도 근거로 남긴다.

14:40 최종 재확인에서 관련 120개는 다시 통과했고 `git diff --check`도 통과했다. 그 사이 추가된 `tests/game/styles.test.ts` 213~216행의 `pending` 타입 추론(`never`) 및 콜백 타입 오류로 현재 `npm run build`는 실패했다. 이전 빌드 통과와 이 최종 관측을 구분하며, 현재 전체 소스가 빌드된다고 주장하지 않는다.

## 전역 시간 지표의 영향 비교

`npx vite-node tools/audit-life-impact.ts`는 같은 전체 소스의 시드 9000~9039를 두 번 실행한다. 비교군은 진단용으로 첫 약속 전환점만 닫으며, 제품에 비활성 옵션을 추가하지 않는다.

| 조건 | 인생 수 | 코스 진입 | 평균 예상 플레이 시간 | 평균 선택 | 끝까지 진행 |
|---|---:|---:|---:|---:|---:|
| 코스 활성 | 40 | 4 | 44.502분 | 95.4 | 40 |
| 최초 약속만 닫은 비교군 | 40 | 0 | 44.119분 | 94.625 | 40 |

해당 시드 묶음에서 첫 코스가 평균 약 0.383분과 선택 0.775회를 더한다. 두 군 모두 25~45분 범위다. 이는 자동 정책의 비교 지표이며 실제 플레이테스트의 시간 측정이 아니다.

## 남은 범위

이 첫 코스는 로그타운 마을 출생과 기존 알라바스타 가뭄 장편에 적용된다. 와노/하늘섬 첫 출항 및 다른 출생·성장 갈래로의 확장, 모든 섬 주차의 달력 연동, 플레이테스터의 이해도 평가, 전역 밸런스 조정은 후속 범위다. 현재 생애 시간 단위가 한 철이므로 이번 조사도 3개월 단위이며 주 단위 달력을 새로 만들지는 않았다.
