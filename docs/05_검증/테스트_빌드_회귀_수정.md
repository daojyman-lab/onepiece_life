# 테스트·빌드 회귀 수정

2026-11-19. 요청: 생애 통합 작업 뒤 남은 전체 테스트 실패와 빌드 오류를 모두 해결한다.

## 재현과 원인

시작 시점의 최신 공유 작업 폴더에서는 빌드 오류와 기존 무기 갈래·기술 숙련 오류 일부가 이미 수정되어 있었다. 전체 재실행은 648개 중 643개 통과, 5개 실패였다. 남은 것은 예상 플레이 시간과 대량 생애 시뮬레이션의 성장 격차·형편별 상위 경지·선택 수·성향 분포였다.

- 유파 입문을 채택하기만 해도 `tierCap`이 무조건 6이 되어, 기본 상한 3과 유료 스승 상한 4를 우회했다. 입문 자체의 상한 해제를 제거했다. 실제 고급 스승이나 자격을 갖춘 후속 수련은 계속 높은 경지를 연다.
- 주력 유파가 스승보다 먼저 검사되어 다른 갈래의 스승을 받아들여도 그 수련을 하지 않았다. 수련에는 현재 스승을 우선 적용하고, 전투 주력과 장비는 보존한다. 가르침이 끝나면 선택한 주력으로 돌아간다.
- 주력 채택을 미룬 제안은 `max: 1000` 때문에 같은 인생에 계속 나타났다. 전환점 공통 상한인 최대 3회를 적용했다.
- 21개 유파의 입문·채택·보류·동작 교정에 특정 가치관 점수가 반복해서 붙었다. 기술적인 선택은 중립으로 처리하고, 정점의 꿈이나 자기 길을 명시적으로 선택하는 문에는 해당 가치관을 유지한다.
- 연습 완료와 생애 후속 등 별도로 열리는 선택이 늘어 평균 선택 수와 예상 플레이 시간이 증가했다. 일반 청년기 사건 빈도를 연 2.1에서 1.9로 조정했다. 유년기·노년기 빈도, 줄 읽는 속도 및 테스트의 허용 범위는 바꾸지 않았다.

## 회귀 검증

새 테스트는 입문/유료 스승 상한 우회, 반복 제안, 기술 선택의 성향 강제, 주력 설정 후 패기 스승의 수련 누락을 먼저 실패로 확인하고 수정했다. 기존 극의 기술/꿈 테스트는 실제 고급 스승을 갖춘 상태를 사용하며 성공 조건은 유지한다.

`tools/audit-balance-regressions.ts`로 시드별 분포를 출력할 수 있다. 예: `npx vite-node tools/audit-balance-regressions.ts 100 random lean`.

## 추가 병합 뒤 확인한 통합 회귀

검증 중 특성·날씨·항해·서약·장편 페이싱이 합쳐졌다. 일시적으로 들어온 병합 충돌 표시는 현재 해소됐으며, 후속 반응 12개와 빌드가 다시 통과했다. 병합된 빠른 검사 51개 파일, 708개도 모두 통과했다.

- 생애 코스에서 기존 장편으로 돌아올 때에도 `storyPause`를 호출해 막 제목과 쉼을 보존한다. 호위 → 알라바스타 에필로그 회귀 검사로 확인했다.
- 새 특성/유파를 포함한 300 야망 인생의 이름 있는 상대 승률은 75.52%였다. 해역별로 이스트 블루 75%, 위대한 항로 전반 98.84%로 지나치게 높았다. 상대의 고정 해역 배율을 이스트 블루 0.4→0.46, 위대한 항로 전반 0.2→0.3으로 조정했다. 동일 300인생에서 584전, 승률 69.35%를 확인했다. 원래 20~70% 테스트 기준을 유지한다.
- 특별 선택지 탐색은 필요한 표시의 생산 장면과 선행 조건까지 추적한다. 티카의 피난처를 먼저 만든 뒤 하늘섬의 후속 선택을 노리고, 드레스로자의 명성 150 조건은 실제 보상과 전투로 준비한다. 제품의 잠금 조건을 변경하거나 값을 강제로 주입하지 않는다.
- 알라바스타의 오래된 고정 재현 시드는 변경된 무작위/전투 흐름에서 유효하지 않아 일반 새 게임의 검증 경로를 다시 찾았다. p4는 시드 52025의 하늘섬 출생, p6는 시드 134의 로그타운 출생에서 새 생애 코스의 약속·수련·소개장을 실제로 선택한다. 검증에서는 실제 열린 선택창의 잠금 여부를 그대로 확인한다. 평화를 노리는 정책은 불필요한 싸움에서 물러나며, 목표에 승리가 필요한 싸움은 진행한다.

최종 전체 테스트·빌드 결과는 실행 종료 후 기록한다.
