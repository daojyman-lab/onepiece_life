# 2026-11-19 main 통합·배포 검증

## 통합 범위

로컬의 부상·선의·휴식, 생애 코스, 무기 유파와 원격 main의 특성, 생애 서약, 빈사·퇴각 주사위, 해상 항해, 섬 기후 및 장편 막 진행을 함께 보존한다. 옛 경로를 현재 `src`와 `src/shared`로 대응시킨 공통 조상을 사용해 병합했다.

## 통합 중 수정

- 해상 항해를 끝낸 뒤 특수 섬 관문을 처리하고, 선택 전에는 위치와 항로 보상을 보류한다.
- 수동 휴식은 새 서약·특성 제안에 가로막히지 않고 한 토막만 진행한다. 이미 대기 중인 선택은 유지한다.
- 쓰러졌다가 살아남은 전투는 대표 무거운 상처를 남기며, 빈사 생존 상처를 중복 추가하지 않는다.
- 생애 코스에서 장편으로 복귀할 때도 막 사이의 쉼과 제목을 적용한다.
- 하늘섬 특별 선택의 생성되지 않는 과거 표시를 실제 앞 장편의 피난처 경험으로 대체했다.
- 도달성 검증은 실제 명성을 쌓고, 현재 이야기와 항해에 맞는 완주 기록을 재생한다.

## 전투 균형 검증 기준

서약의 실제 전투력 하한과 유파 무기, 부위별 상처·치료를 합친 뒤 전투 배율이 중복 적용되는 문제는 없었다. 최초 통합 표본의 승률은 기존 20~70% 기준을 초과했다. 검증 범위를 20~80%로 갱신하는 안도 검토했지만, 병행 중인 균형 수정이 이스트 블루와 위대한 항로 초반의 이름 있는 상대를 조정해 기존 기준을 충족했으므로 최종 배포는 20~70% 기준을 유지한다.

조정 전 고정 300개 야망 인생에서는 이름 있는 싸움 576회 중 435승(75.52%)이었다. 신세계 초입은 49전 24승(48.98%)으로, 모든 해역의 난도가 사라진 결과는 아니었다. 인생 종료 시 서약 이행 여부에 따른 집계는 인과관계의 증거로 해석하지 않았다. 병행 작업의 상대 배율 조정 뒤 300인생 재측정은 69.35%로 기존 기준을 만족했다. 서약·특성·무기 시스템의 의도된 보상은 유지한다.

## 웹 검증 범위

최종 빌드와 GitHub Pages 배포 실행의 커밋을 확인하고, 공개 HTML이 참조하는 JS·CSS 및 최신 기능 표식을 대조한다. 브라우저 제어 도구가 현재 URL을 검증하지 못해 중단되어, 실제 화면 클릭 검증은 완료했다고 주장하지 않는다.
