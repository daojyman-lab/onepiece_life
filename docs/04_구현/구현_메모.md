# 구현 메모

설계와 다르게 구현했거나, 설계에 없어서 구현에서 정한 것. 설계 문서를 고칠 때 함께 본다.

## 설계에서 정하지 않아 구현에서 정한 것

| 항목 | 정한 것 | 위치 |
|---|---|---|
| S6 위대한 항로 · 신세계 출생 | 정했다 (2026-11-14): 고향은 원작 초반의 이스트 블루 마을 8곳뿐이다. 이스트 블루와 연이 없는 희귀한 성씨(20개)와 사람이 아닌 종족은 고아로 태어나 마을 사람(보호자)이 거둔다. 포대기 속 쪽지와 물건으로 성씨를 안다 | `data/births.ts`, `core/state.ts` |
| 임무 | 길(해적 · 해군 · 공통)별 틀 14종. 항구는 임무를 뽑을 때 해역의 항구에서 고른다. 해역 단계 구분은 아직 없다 | `data/missions.ts` |
| 강적전 상대 | 임무 · 선택의 강적은 해역의 힘 범위에서 만든다(`gen:elite`, `gen:captain`). 보스만 고정 데이터 | `core/world/world.ts` |
| 열매 힌트 | 열매마다 문장을 쓰지 않고 계통 · 등급 범위 · 테마에서 만든다 | `data/fruits.ts` `fruitHints` |
| 동물계 열매 기술 | 틀의 바탕 능력치가 지능이면 힘으로 바꾼다 | `core/growth/skillbook.ts` |
| 패시브 기술 | 장착해야 효과가 있다. 숙련에 따라 0.7~1.3배 | `core/combat/units.ts` |
| 해적 수입 | 평소 교전 전리품만으로는 생활비를 못 대서, 달마다 벌이(`pirateIncome`)를 넣었다 | `data/balance.ts`, `core/sim/tick.ts` |
| 해군의 배 | 해군은 배를 사지 않는다. 동료 정원은 계급으로 정한다 (`2 + 계급/2`) | `core/effects.ts` `crewCapacity` |
| 도감 반영 | core는 `metaEvents`에 쌓기만 하고, app 층(`store.ts`)이 `MetaState`에 옮긴다 | `core/meta/meta.ts` |
| 정찰 오차 | 같은 달 · 같은 상대면 같은 오차가 나오게 씨앗에서 만든다 | `core/combat/battle.ts` `shownOdds` |
| 유년기 | 3 · 6 · 9세에 하나씩. 6세는 라이벌이 생기는 사건으로 고정 | `core/choice/choice.ts` `childhoodPick` |
