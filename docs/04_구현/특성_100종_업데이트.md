# 특성 100종 업데이트

2026-11-18. 신규 100종을 기존 출생 25종·후천 6종에 추가한다. 새 특성은 출생 60종, 후천 40종이다.

- 출생은 2개 15%, 3개 40%, 4개 35%, 5개 10%다. 적용은 출생·후천을 합쳐 최대 5개다.
- 인물창에서 적용할 특성을 골라 사건·항해가 없을 때 연 1회 정리한다. 슬롯이 차면 해금 기록에 남고 직접 선택할 수 있다.
- 같은 계열의 상위 특성을 얻으면 활성 하위 특성을 자동 교체한다. 하위·상위는 동시에 적용할 수 없다.
- 거래 할인의 가장 높은 값 하나와 비용 증가 디버프를 합산한다. 할인 최대 25%, 비용 증가 최대 25%다. 교습·구매처럼 거래로 표시한 선택의 보유금 조건과 지불액에 함께 적용한다. 세금·벌금·기부·도박 손실에는 적용하지 않는다.
- 협응은 건강하고 살아 있는 동료 전투력의 10%를 주인공에게 더한다. 개인전에도 적용하며 개인 전투력의 20%를 넘지 않는다. 통솔·제독술과 함께 있으면 가장 높은 지원 비율 하나를 사용한다.
- 같은 사건의 재열람은 후천 획득을 반복 진행시키지 않는다. 활동은 서로 다른 실제 나이, 전투는 서로 다른 상대, 영입은 서로 다른 인물로 센다.
- 기존 저장의 출생 특성과 획득 기록을 보존하고, 최대 5개를 우선 적용한다. 나머지는 인물창에서 고를 수 있다.
- 강골·약한 뼈의 새 부상 기간, 인망의 첫 영구 동료 영입, 물개·뱃멀미의 해상전 보정과 패기 입문도 연결했다. 패왕색 잠재가 있으면 패배·상실 뒤 별도의 발현 기회가 열린다.
- 이번 구현에서 조건형 특성의 수치는 초기 기획을 현재 게임의 계산식에 맞춰 조정했다. 실제 효과는 아래 표와 인물창에 표시한다.

## 검증 기록

- 신규 출생 60종은 자연 출생 20,000회에서 모두 발견했다. 출생 2·3·4·5개를 모두 확인했다.
- 신규 후천 40종은 각 행동 조건을 재현해 모두 해금·적용했다. 먹보는 실제 시장 식사 세 번으로 별도 확인했다.
- 자동 플레이 120회는 모두 엔딩까지 진행했고, 불변 조건 위반 0회·활성 특성 최대 5개였다. 달변가 등 드문 상위 특성은 조건 재현 테스트로 검증했다.
- 지식의 치명타, 협응의 개인전 지원과 사망·부상 동료 제외, 실제 도장비 할인 및 비용 증가 디버프, 상위 교체, 저장 복원과 비활성 효과 제거를 회귀 테스트로 확인했다.
- 전체 검사에서 발견한 항해·감옥·확률 보너스 회귀를 수정했다. 초기 알라바스타 특별 문 두 곳은 실제로 도달하는 완전한 인생의 시드로 재현해 확인했다.
- 로컬 브라우저에서 출생 특성 표시와 인물창 적용 변경, 연 1회 제한을 확인했다.
