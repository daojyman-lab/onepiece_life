# 꿈의 서약

서약은 **어릴 적 품은 꿈을 누군가에게 약속하고, 그 꿈으로 가는 길목을 지날 때마다 강해지는** 장치다. (원래 기획: v06_doc 4.2 "수련기에 유년기의 동경이 구체적인 목표와 서약으로 변한다")

2026-11-17에 들어간 생애 서약(10·22·36살에 가장 높은 가치관으로 제안, 체력 대가, 행동 증거, 거절·실패 시 끝, 전투력 하한 500·770·1500)은 꿈과 이어지지 않았고, 열두 살이 B급이 되는 문제가 있어 2026-11-20에 걷어 냈다. 옛 설계 문서(`docs/superpowers/specs/2026-11-17-생애-서약-시스템-design.md`)는 기록으로만 남긴다.

## 흐름

1. **약속**: 13~17살의 꿈 장면에서 꿈을 고르면, 그 자리에서 약속한다. 살아 있는 형제 → 어릴 적 동무 → 부모 → 스승 순으로 약속을 들어 줄 사람을 찾고, 아무도 없으면 스스로에게 약속한다.
   - 기록 예: `동생 하루에게 약속했다. 언젠가 해적왕이 되겠다고.`
2. **길목**: 꿈마다 6~9개의 길목이 있다. 해가 바뀔 때 다음 길목의 조건을 지금 상태로 본다. **한 해에 한 길목만** 지난다. 마지막 길목은 그 꿈을 이룬 것이다.
3. **강해짐**: 길목을 지날 때마다 꿈과 이어진 능력치 +1, 갈래 숙련 +30.
4. **연속 보너스**: 꿈을 바꾸지 않고 이어 지난 길목의 수(연속)가 쌓일수록 숙련이 길목마다 +10씩 더 붙는다(연속 n이면 +30+10×(n−1)). 연속 3·5·7에 닿으면 능력치를 하나 더 준다.
5. **끝까지 지킨 약속**: 꿈을 한 번도 바꾸지 않고 모든 길목을 지나면 그 갈래의 단계가 하나 오른다(스승 없는 한계도 넘는다, 최대 6).
6. **꿈이 바뀌면**: 벌은 없다. 이미 얻은 힘은 그대로 남고, 새 꿈의 길목을 처음부터 걷는다. 연속만 0으로 돌아간다. 예전 꿈으로 돌아가면 그 꿈에서 지난 길목은 다시 받지 않고 이어서 걷는다.

길목을 지난 해에는 장면 한 줄 끝에 실제 변화가 붙은 기록(`… 세상이 그 이름을 알기 시작했다. 꿈의 서약 3/9 · 의지 +1 · 검술 숙련 +50 · 꿈을 지킨 연속 3.`)이 남고, 연표에 `꿈의 서약 3/9: 수배서에 이름이 오른다`가 남는다. 인물 칸에는 `꿈의 서약 3/9 · 연속 3 · 동생 하루에게 한 약속 / 다음 길목: 위대한 항로에 들어선다`가 보인다.

## 꿈별 길목과 능력치

| 꿈 | 능력치 | 길목 (마지막은 꿈을 이룸) |
|---|---|---|
| 해적왕 | 의지 | 바다로 나선다 → 해적 깃발 아래 → 수배서(1천만) → 위대한 항로 → 제 배의 선장 → 현상금 1억 → 신세계 → 현상금 3억 → 해적왕 |
| 최강의 검객 · 무투가 · 병기가 · 저격수 | 근력 · 체력 · 근력 · 지능 | 그 갈래 1단계 → 2단계 → 2단계+이름(10) → 3단계 → 3단계+위대한 항로 → 4단계 → 5단계 → 정점 |
| 해군의 정점 | 의지 | 힘을 기름(무술 1단계 또는 입대) → 입대 → 첫 공 → 장교 → 위대한 항로 복무 → 본부가 기억(이름 60) → 장성 → 정점 |
| 세상을 바꾸는 것 | 의지 | 부당함에 맞섬 → 혁명군 → 정부의 적 → 이름 20 → 60 → 150 → 400 → 세상을 바꿈 |
| 세상의 끝 | 속도 | 고향을 떠남 → 위대한 항로 → 전반 → 샤본디 → 낯선 섬 3곳 → 신세계 → 신세계 후반 → 마지막 바다 |
| 세계의 진실 | 지능 | 지식 15 → 고향을 떠남 → 역사의 흔적이 남은 섬 1곳 → 지식 22 → 2곳 → 3곳 → 감춰진 역사를 읽음 |
| 바다의 보물 | 운 | 3만 → 10만 → 30만 → 100만 → 500만 → 보물(3천만) |
| 소중한 사람들과의 평온 | 체력 | 마음을 나눌 사람 둘 → 오래 곁에 두고 싶은 사람 → 마음을 나누는 사람 넷 → 결혼 → 정착 → 깊은 인연 셋 → 40살까지 정착 → 45살 이후의 평온 |

역사의 흔적이 남은 섬(원작): 알라바스타 · 스카이피아 · 어인섬 · 조우 · 와노쿠니 · 홀케이크 아일랜드 · 오하라 옛터 · 엘바프 · 에그헤드.

## 섬 서약 (하늘섬 티카)

티카의 피난길 서약은 꿈의 서약과 따로 가는 **섬 이야기**다. 하늘섬 장편 안에서 걸고, 장편의 표시로 판정하며, 지키면 지금 갈래 숙련 +25와 `티카의 피난길` 장면을 받는다. 단계나 능력치를 직접 올리지 않는다.

## 데이터와 연결

- `src/data/dream-vows.ts`: 꿈별 약속의 말 · 능력치 · 갈래 · 길목(이름 · 기록 · 조건), 보상 수치 `DREAM_VOW_REWARD`.
- `src/core/dream-vow.ts`: 약속(`promiseDream`), 해마다 판정(`dreamVowYear`), 인물 칸 자료(`dreamVowView`).
- `src/core/dreams.ts`: `setDream`이 꿈을 품거나 바꾸면 true를 돌려주고, `fx.ts`의 `dream`이 그때 약속한다. `year.ts`에서 `dreamYear` 다음에 `dreamVowYear`.
- `src/core/vow.ts`, `src/data/vows.ts`: 섬 서약.
- `src/core/load.ts`: 옛 저장에서 진행 중이던 생애 서약은 내려놓고, 지킨 기록은 읽기만 한다. 꿈의 서약 칸이 없으면 첫 길목부터 걷는다.
- `tests/game/dream-vow.test.ts`, `tests/game/vow.test.ts`.
