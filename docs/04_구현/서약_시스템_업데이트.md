# 서약 시스템 업데이트 파일

대상: 게임 v6.8 저장 형식(`schema: 5`). 첫 적용 콘텐츠: 하늘섬 원작 전 「번개 아래의 장부」.

## 플레이 규칙

- 서약은 신념이 깊고 대상과 앞선 인연이 있을 때만 선언한다. 선언은 위기의 결과를 알기 전에 한다.
- 현재 한 번에 하나의 서약만 진행한다. 같은 서약은 한 인생에서 다시 보상을 받지 못한다.
- 서약 자체는 전투의 힘을 올리지 않는다. 준비에서 다른 이득을 포기해야 하고, 실제 결말을 확인한다.
- 성공하면 주력 갈래 숙련을 25 얻는다. 기존 숙련·단계 상한을 그대로 따른다. 실패와 사망에는 성장 보상이 없다.
- 진행 중인 서약과 준비 단계는 인물 칸에 보이고, 결산은 인생 기록에 남는다.

## 첫 서약: 티카의 피난길

도란의 제안 직후 `ep_skypiea_b6v` 장면이 열린다. 의리가 깊고, 앞서 티카를 믿었으며, 장부의 단서를 모았고, 도란과 거래하지 않았을 때 서약 선택지가 열린다.

서약 목표는 티카가 이끄는 피난길을 끝까지 지키는 것이다. 성공에는 준비 장면에서 구름길을 닦아 `b_vow_prepared`를 남기고, 결전의 성공 장면에서 티카와 피난처를 열어 `b_vow_refuge`를 남겨야 한다. 다른 장면에서 일반 피난 표시만 얻어서는 준비 대가를 치른 것으로 보지 않는다. 결전에서 물러나거나 패배해 다른 결말로 가면 두 번째 표시를 얻지 못한다. 공통 코어가 작별 장면의 선택 결과를 받은 뒤 자동으로 결산한다. 도란과 거래하거나 장편을 떠나면 실패한다.

## 수정 파일과 확장 위치

| 파일 | 역할 |
|---|---|
| `src/v5/data/vows.ts` | 서약별 자격, 단계, 금지 조건, 종료 장면, 보상 정의 |
| `src/v5/core/vow.ts` | 공통 선언·진행·만료·결산 엔진 |
| `src/v5/core/types.ts`, `state.ts`, `load.ts` | 저장 상태와 옛 저장 호환 |
| `src/v5/core/turning.ts`, `year.ts` | 모든 장면 선택과 시간 진행을 서약 코어에 전달 |
| `src/v5/core/fx.ts` | 사건 데이터의 서약 시작 효과와 성장 지급 |
| `src/v5/data/episodes/skypiea.ts` | 선언, 준비, 결전 후 결과, 작별 장면 연결 |
| `src/v5/ui/screens/Main.tsx` | 활성 서약 표시 |
| `tests/v5/vow.test.ts` | 자격, 중복, 성공·실패, 사망, 저장 및 장편 연결 검증 |

다른 신념을 추가할 때에는 `data/vows.ts`에 서약 정의를 더하고, 해당 장편에 선언 효과와 대가·성공 표시를 연결한다. `closingTurning`을 적으면 마지막 문에서 공통 코어가 결산한다. 신념 이름이나 숨은 점수를 선택지 문구에 넣지 않는 기존 콘텐츠 규칙을 따른다. 각 서약은 구체적인 인물·대가·결과가 필요하므로, 다른 여덟 신념의 서약 콘텐츠는 아직 포함하지 않았다.

## 현재 게임에 반영하는 순서

이 저장소에서 새 파일 `src/v5/core/vow.ts`, `src/v5/data/vows.ts`를 포함해 위 수정 파일을 Git에 추가하고 빌드한다. `npm.cmd run build`가 통과하면 기존 배포 절차(`.github/workflows/deploy.yml`)에 따라 배포한다. 저장 데이터의 `schema: 5`는 유지하므로 v6.8 저장을 그대로 불러올 수 있다. 작업 폴더의 미추적 파일은 Git에 추가하기 전에는 GitHub Pages 배포에 포함되지 않는다.
