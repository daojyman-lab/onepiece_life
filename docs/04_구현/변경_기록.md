# 변경 기록

## v4.0.0 — 첫 마일스톤: 핵심 루프 (2026-11-14)

새로 만든 버전이다. v3.x 코드를 옮기지 않았다. 도트 그림(`v3.4.0/pixel-art.js`)과 픽셀 스킨의 색 · 형태 규칙만 가져왔다.

### 들어간 것

- **구조**: TypeScript + Vite + Preact + Vitest. 규칙(`src/core`)은 순수 함수이고, 상태는 값만 가져 그대로 JSON으로 저장된다. 씨앗 난수라 같은 씨앗이면 같은 인생이 나온다.
- **멈춤**: `pending` 하나로만 정한다 (선택 · 준비 · 전투 · 개입 · 결산). `pending`이 있으면 `tick`이 무시된다.
- **생애**: 3 · 6 · 9세 유년기 선택 → 10세 입문 → 수련기 → 16세 출항(해적 · 해군) → 해역 임무 3개 → 보스 → 다음 해역. 혁명군은 해적에서 전향.
- **성장**: 주력 · 보조 갈래에 따른 자동 성장, 숙련(`1.6 ÷ 단계`), 기술 트리 자동 습득, 큰 단계(스승 · 사건 · 죽을 고비).
- **기술**: 무술 3유파 · 패기 3색 36개, 열매 40종(등급 5단계, 트리 깊이 1~6).
- **열매**: 정체를 모르고 발견, 감정(힌트 3단계), 먹기 · 팔기 · 간직하기, 도감으로 알아보기.
- **전투**: 20합 자동 전투, 체력 · 기력, 발동 조건, 전법 4종, 자연계와 무장색, 회피 · 치명타, 소모품, 물러나기, 바다에 빠지기, 집단전(짝 짓기 · 합세 · 개입).
- **준비 화면**: 정찰 3단계, 200번 미리 돌린 승률과 위험도, 기술 6칸 · 전법 · 장비 · 소모품 · 동료 짝 짓기.
- **몸 · 돈**: 부상 3단계, 질병 3단계, 노화 · 노환, 자동 치료, 생활비 · 봉급 · 벌이, 상점, 배.
- **결산**: 결산 화면, 연표, 명예의 전당, 열매 · 인물 · 기술 도감.
- **저장**: 자동 저장, 파일 내보내기 · 가져오기, 불러올 때 불변 조건 검사. v3.x 저장은 읽지 않는다.
- **화면**: 시작 화면, 3단 메인 화면(모바일 1단), 도트 장면 · 얼굴, 전투 재생(속도 · 건너뛰기), 기술 트리, 편성, 상점, 도감.
