# 개발 안내 (v6.9)

## 실행과 검증

Node.js 22 이상에서 `npm ci`로 패키지를 설치한다.

| 명령 | 내용 |
|---|---|
| `npm run dev` | 로컬 개발 서버 (`127.0.0.1:5173`) |
| `npm run dev:lan` | 같은 네트워크의 휴대폰 접속용 서버 (`0.0.0.0:5174`) |
| `npm run build` | 타입 검사 후 `dist/` 빌드 |
| `npm test` | 전체 Vitest 테스트 |
| `npm run simulate5 -- 10 random` | 임의 정책으로 인생 10회 시뮬레이션 |

## 주요 수정 위치

| 작업 | 파일 또는 폴더 |
|---|---|
| 앱 시작, 상태, 저장, 진행 속도 | `src/app/main.tsx`, `store.ts`, `save.ts`, `flow.ts` |
| 생애 진행·성장 | `src/core/year.ts`, `state.ts`, `stages.ts` |
| 선택·효과·조건 | `src/core/turning.ts`, `fx.ts`, `cond.ts`, `types.ts` |
| 싸움과 결과 | `src/core/fight.ts`; 자동 전투 엔진은 `src/shared/core/combat/` |
| 게임 수치 | `src/data/balance.ts`; 전투 엔진 수치는 `src/shared/data/balance.ts` |
| 전환점·섬 이야기 | `src/data/turnings/`, `src/data/episodes/` |
| 일상 기록·고향 | `src/data/lines.ts`, `homes.ts` |
| 기술·열매·출생·보스 | `src/shared/data/` |
| 화면·모달·픽셀 그림 | `src/ui/` |

`src/core`는 현재 생애 상태를 다루고, `src/shared/core`는 전투와 난수 같은 재사용 기반을 제공한다. 테스트는 `tests/game/`, 점검 도구는 `tools/`에 있다.
