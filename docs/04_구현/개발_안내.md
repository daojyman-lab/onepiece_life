# 개발 안내 (v4)

소스는 프로젝트 루트의 `src/`, 테스트는 `tests/`, 도구는 `tools/`에 있다. 구조는 [../02_설계/01_아키텍처.md](../02_설계/01_아키텍처.md)를 따른다.

## 준비

Node 24 이상.

```bash
npm install
```

## 명령

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 (http://127.0.0.1:5173) |
| `npm run build` | 타입 검사 후 `dist/`에 정적 파일 |
| `npm test` | 단위 테스트와 생애 시뮬레이션 테스트 (Vitest) |
| `npm run simulate -- 300 smart` | 인생 300번을 돌려 지표 출력. 두 번째 인자는 `random` 또는 `smart` |

## 어디를 고치나

| 하고 싶은 것 | 파일 |
|---|---|
| 수치 (계수, 확률, 속도, 가격) | `src/data/balance.ts` |
| 기술 트리 | `src/data/skills.ts` |
| 열매 | `src/data/fruits.ts` (기술은 틀 `FRUIT_TEMPLATES`에서 만든다) |
| 중대한 선택 | `src/data/choices.ts` |
| 해역 · 배 / 임무 / 보스 / 스승 | `src/data/seas.ts`, `missions.ts`, `bosses.ts`, `masters.ts` |
| 한 달의 처리 순서 | `src/core/sim/tick.ts` |
| 선택이 뜨는 규칙 · 틀 선택지 | `src/core/choice/choice.ts` |
| 전투 규칙 | `src/core/combat/engine.ts` (피해 · 행동), `units.ts` (전투 값), `outcome.ts` (결과) |
| 효과(`op`) 추가 | `src/core/types.ts`의 `Effect`와 `src/core/effects.ts`의 `apply` |

`src/core/`는 화면 · 타이머 · `localStorage` · `Math.random`을 쓰지 않는다. 화면 없이 `src/core/autoplay.ts`로 인생을 끝까지 돌릴 수 있다.
