# 04 구현

상태: v4.0.0 첫 마일스톤 완료 (2026-11-14). [개발 안내](개발_안내.md) · [변경 기록](변경_기록.md) · [구현 메모](구현_메모.md)

## 입력

- [02_설계/](../02_설계/)
- [03_계획/](../03_계획/)

## 이 폴더에 둘 것

| 문서 | 내용 |
|---|---|
| 변경 기록 | 버전별로 추가·수정한 것, 알려진 문제 |
| 구현 메모 | 설계와 다르게 구현한 부분과 그 이유 |
| 개발 안내 | 실행·빌드·테스트 방법 |

소스 코드는 이 폴더가 아니라 프로젝트 루트의 소스 폴더에 둔다. 위치는 설계 단계에서 정한다.

## 규칙

- 기존 버전 폴더(`v2.0.1/` ~ `v3.3.4/`)는 수정하거나 삭제하지 않는다.
- 설계와 다르게 구현해야 하면 구현 메모에 남기고 설계 문서를 함께 고친다.
- 마일스톤 하나를 끝낼 때마다 검증 단계의 확인을 거친다.

## 완료 조건

- 계획의 모든 작업이 완료 기준을 충족한다.
- 빌드 결과물이 브라우저에서 실행된다.
