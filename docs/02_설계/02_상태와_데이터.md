# 02 상태와 데이터

형태는 TypeScript로 적는다. 이름은 구현 때 그대로 쓴다.

## 1. 상태

### 한 인생 — `LifeState`

```ts
interface LifeState {
  schema: 1;
  rng: { seed: number; cursor: number };
  time: { year: number; month: number };          // 해원력
  hero: Hero;
  growth: Growth;
  loadout: Loadout;                               // 평소 교전에 쓰는 편성
  people: Person[];                               // 가족, 스승, 동료, 라이벌, 원수
  world: WorldProgress;
  inventory: Inventory;
  choice: ChoiceTracker;
  log: LogEntry[];                                // 최근 300건
  timeline: TimelineEntry[];                      // 결산용. 중대한 선택과 강적전만
  pending: Pending;                               // 01 아키텍처 4장
  stats: LifeStats;                               // 결산용 누적값
}
```

### 주인공 — `Hero`

```ts
interface Hero {
  name: string; surname: string; gender: 'm' | 'f';
  species: 'human' | 'fishman' | 'mink' | 'giant' | 'longarm' | 'celestial';
  birth: { seaId: SeaId; place: string; household: string };
  age: number;
  route: 'none' | 'pirate' | 'marine' | 'revolution';   // revolution은 pirate에서만 전향
  rank: number;                                          // 길 안의 단계 (계급 · 지위)
  fame: number;                                          // 해적은 현상금, 해군은 공적
  money: number;
  base: { str: number; spd: number; vit: number; int: number; wil: number; luk: number };
  hp: number;                                            // 현재 건강 (0~maxHp)
  injuries: Injury[];
  illness: Illness | null;
  traits: string[];                                      // 성향, 패왕색 소질 등
  fruit: { id: FruitId; eatenAt: number } | null;
  alive: boolean;
}
interface Injury { severity: 'light' | 'heavy' | 'scar'; monthsLeft: number; penalty: Partial<Hero['base']> }
interface Illness { id: string; stage: 1 | 2 | 3; months: number }
```

능력치 여섯 개의 뜻:

| 키 | 이름 | 쓰이는 곳 |
|---|---|---|
| `str` | 힘 | 체술·검술 피해 |
| `spd` | 속도 | 행동 순서, 회피, 사격 피해 |
| `vit` | 체력 | 최대 체력, 방어 |
| `int` | 지능 | 열매 기술 피해, 정찰 정확도, 감정 힌트의 질 |
| `wil` | 정신 | 최대 기력, 패기, 죽을 고비에서 버티기 |
| `luk` | 운 | 발견, 치명타, 사망 판정 |

### 성장 — `Growth`

```ts
interface Growth {
  focus: BranchId | null;                 // 지금 저절로 느는 갈래. 선택으로만 바뀐다
  secondary: BranchId | null;             // 절반 속도로 느는 갈래
  skills: Record<SkillId, { mastery: number }>;   // 배운 기술과 숙련 0~100
  gates: string[];                        // 연 큰 단계 (예: 'haki.armament.flow')
  master: { personId: string; branch: BranchId; monthsLeft: number } | null;
}
type BranchId =
  | 'martial.fist' | 'martial.sword' | 'martial.gun'
  | 'haki.observation' | 'haki.armament' | 'haki.conqueror'
  | 'fruit';
```

### 편성 — `Loadout`

```ts
interface Loadout {
  skills: SkillId[];                      // 최대 6
  tactic: 'offense' | 'defense' | 'counter' | 'endurance';
  retreatAt: 0 | 0.3 | 0.5;               // 체력이 이 비율 아래면 물러난다. 0은 끝까지
  weapon: ItemId | null; armor: ItemId | null; charm: ItemId | null;
  consumables: ItemId[];                  // 최대 3
  crew: { personId: string; role: 'vanguard' | 'support' | 'medic' }[];   // 최대 = 배의 정원
}
```

### 사람 — `Person`

```ts
interface Person {
  id: string; name: string; gender: 'm' | 'f'; age: number;
  kind: 'family' | 'master' | 'crew' | 'rival' | 'enemy' | 'ally';
  canon: string | null;                   // 원작 인물이면 그 id
  bond: number;                           // 0~100
  // 동료만
  crew?: { role: 'vanguard' | 'support' | 'medic' | 'navigator' | 'cook' | 'shipwright';
           level: number; power: number; skills: SkillId[]; hp: number; injuredMonths: number };
  alive: boolean;
}
```

동료는 `level`만 오른다. 함께한 달 수와 함께 이긴 강적전으로 오른다. 기술은 영입 때 정해진 2~3개다.

### 세계 진행 — `WorldProgress`

```ts
interface WorldProgress {
  stage: 1 | 2 | 3 | 4 | 5 | 6;
  seaId: SeaId;
  missions: { id: MissionId; state: 'open' | 'active' | 'done' | 'failed'; step: number }[];   // 해역마다 3개
  boss: { id: BossId; state: 'hidden' | 'revealed' | 'defeated'; attempts: number };
  ship: ShipId | null;
  defeated: BossId[];
  news: NewsEntry[];
}
```

### 물건 — `Inventory`

```ts
interface Inventory {
  items: { id: ItemId; count: number }[];
  unknownFruits: { uid: string; fruitId: FruitId; hints: string[]; foundAt: number }[];   // fruitId는 화면에 내보내지 않는다
}
```

### 선택 추적 — `ChoiceTracker`

```ts
interface ChoiceTracker {
  nextAt: { year: number; month: number };   // 다음 선택이 뜰 수 있는 가장 이른 때
  thisYear: number;                          // 올해 뜬 수
  seen: Record<ChoiceId, number>;            // 본 횟수
  flags: string[];                           // 선택이 남긴 표시 (후속 선택의 조건)
  queue: ChoiceId[];                         // 예약된 후속 선택
}
```

## 2. 인생 밖의 기록 — `MetaState`

인생이 끝나도 남는다. 따로 저장한다.

```ts
interface MetaState {
  schema: 1;
  fruitCodex: Record<FruitId, { eaten: number; bestTier: number }>;
  peopleCodex: Record<string, { met: number; taughtBy: boolean; defeated: boolean; where: SeaId }>;
  skillCodex: SkillId[];                     // 한 번이라도 연 기술
  hall: HallEntry[];                         // 명예의 전당
  lives: number;
}
interface HallEntry {
  name: string; route: Hero['route']; ageAtEnd: number; cause: string;
  stage: number; fame: number; fruit: FruitId | null; topSkills: SkillId[];
  endedAt: string;                           // 실제 날짜. app 층에서 채운다
}
```

## 3. 정적 데이터

### 기술 — `Skill`

```ts
interface Skill {
  id: SkillId; name: string; branch: BranchId; tier: 1 | 2 | 3 | 4 | 5;
  kind: 'attack' | 'guard' | 'support' | 'passive';
  stat: 'str' | 'spd' | 'int' | 'wil';       // 위력의 바탕
  power: number;                             // 기본 공격 = 1.0
  cost: number;                              // 기력
  cooldown: number;                          // 합
  when: 'always' | 'hpBelow50' | 'enemyHpBelow30' | 'afterEnemyBig' | 'opening' | 'allyDown';
  tags: ('armament' | 'area' | 'pierce' | 'heal' | 'bind' | 'transform' | 'awaken')[];
  effect?: { type: 'guard' | 'dodge' | 'heal' | 'buff' | 'debuff' | 'bind'; value: number; turns: number };
  requires: { skills?: { id: SkillId; mastery: number }[]; base?: Partial<Hero['base']>; gate?: string };
  text: string;
}
```

### 열매 — `Fruit`

```ts
interface Fruit {
  id: FruitId; name: string;
  class: 'paramecia' | 'zoan' | 'logia';
  grade: 1 | 2 | 3 | 4 | 5;                  // 쓰레기, 평범, 우수, 희귀, 전설
  theme: string;                             // 힌트와 연출에 쓴다
  skills: { template: FruitTemplateId; name: string; text: string }[];   // 길이 = 등급별 트리 깊이
  hints: [string, string, string];           // 감정 1·2·3회째에 나오는 힌트
  canonUser: string | null;                  // 원작 사용자. 그 인물이 살아 있는 한 발견되지 않는다
}
```

열매 기술은 틀(`FruitTemplate`)에서 만든다. 틀은 위력·기력·발동 조건을 갖고, 열매는 이름과 설명만 갖는다. 05 문서 3장.

### 스승 — `Master`

```ts
interface Master {
  id: string; name: string; canon: string | null;
  sea: SeaId[]; route: ('pirate' | 'marine' | 'any')[];
  teaches: { branch: BranchId; gate: string; months: number }[];
  accepts: Condition[];                      // 받아 주는 조건
  fee: number;                               // 0이면 무료
}
```

### 해역, 임무, 보스

```ts
interface Sea { id: SeaId; stage: 1|2|3|4|5|6; name: string; ports: PortId[]; enemyPower: [number, number]; shipRequired: number }
interface Mission {
  id: MissionId; sea: SeaId | 'home'; route: 'pirate' | 'marine' | 'any';
  title: string; port: PortId | null;
  steps: MissionStep[];                      // 2~3단계. 마지막은 강적전
  reward: Effect[];
}
type MissionStep =
  | { kind: 'story'; months: number; text: string; effects: Effect[] }
  | { kind: 'choice'; choiceId: ChoiceId }
  | { kind: 'battle'; enemy: EnemyId; elite: boolean };
interface Boss extends Enemy { sea: SeaId; route: 'pirate' | 'marine' | 'any'; birthSea?: SeaId; drops: Effect[] }
interface Enemy {
  id: EnemyId; name: string; canon: string | null;
  base: Hero['base']; fruitClass: Fruit['class'] | null; armament: 0|1|2|3;
  skills: SkillId[]; tactic: Loadout['tactic']; officers: EnemyId[];
}
```

### 중대한 선택 — `Choice`

```ts
interface Choice {
  id: ChoiceId;
  category: 'entry' | 'master' | 'fruit' | 'career' | 'challenge' | 'bond' | 'crisis';
  when: Condition[];                         // 모두 맞아야 후보가 된다
  weight: number; repeat: 'once' | 'cooldown'; cooldownYears?: number;
  speaker: 'hero' | { person: string } | { canon: string };   // 사건 창에 붙일 얼굴
  title: string; body: string;               // {name}, {place} 같은 자리표시를 쓴다
  options: { label: string; hint: string; when?: Condition[]; effects: Effect[]; next?: ChoiceId }[];
}
```

### 조건과 효과

조건과 효과는 값이다. 함수를 쓰지 않는다.

```ts
type Condition =
  | { c: 'age'; min?: number; max?: number }
  | { c: 'route'; is: Hero['route'][] }
  | { c: 'stage'; min?: number; max?: number }
  | { c: 'base'; key: keyof Hero['base']; min: number }
  | { c: 'skill'; id: SkillId; mastery?: number }
  | { c: 'gate'; id: string; has: boolean }
  | { c: 'fruit'; has: boolean }
  | { c: 'flag'; id: string; has: boolean }
  | { c: 'trait'; id: string; has: boolean }
  | { c: 'money'; min: number }
  | { c: 'crew'; min?: number; max?: number }
  | { c: 'injured'; is: boolean }
  | { c: 'birthSea'; is: SeaId[] };

type Effect =
  | { op: 'base'; key: keyof Hero['base']; add: number }
  | { op: 'hp'; add: number }
  | { op: 'money'; add: number }
  | { op: 'fame'; add: number }
  | { op: 'focus'; branch: BranchId; slot: 'focus' | 'secondary' }
  | { op: 'learn'; skill: SkillId }
  | { op: 'mastery'; skill: SkillId | 'focus'; add: number }
  | { op: 'gate'; id: string }
  | { op: 'apprentice'; master: string; branch: BranchId; months: number }
  | { op: 'route'; to: Hero['route'] }
  | { op: 'rank'; add: number }
  | { op: 'flag'; id: string }
  | { op: 'trait'; id: string }
  | { op: 'person'; add: PersonSeed } | { op: 'bond'; who: string; add: number }
  | { op: 'recruit'; crew: CrewSeed }
  | { op: 'item'; id: ItemId; count: number }
  | { op: 'findFruit'; pool: 'any' | 'gradeMin3' | FruitId }
  | { op: 'eatFruit'; uid: string }
  | { op: 'injury'; severity: Injury['severity'] }
  | { op: 'illness'; id: string }
  | { op: 'battle'; enemy: EnemyId; elite: boolean; lethal: boolean }
  | { op: 'log'; text: string; type: LogEntry['type'] }
  | { op: 'chance'; p: number; then: Effect[]; else?: Effect[] };
```

## 4. 저장

| 키 | 내용 | 저장 시점 |
|---|---|---|
| `gt4.life` | `LifeState` | 해가 바뀔 때, 선택에 답한 뒤, 전투가 끝난 뒤, 수동 저장 |
| `gt4.meta` | `MetaState` | 열매를 먹었을 때, 인물을 만났을 때, 인생이 끝났을 때 |
| `gt4.settings` | 배속, 효과음 | 바뀔 때 |

- 내보내기와 가져오기를 둔다. 파일(`.json`)로 저장하고 파일을 골라 불러온다. v3.3.3에는 가져오기가 없었다.
- 불러올 때 `schema`를 확인한다. 낮으면 차례로 올리는 변환을 거친다. 높으면 거절한다.
- 불러온 뒤 불변 조건을 검사한다. 깨져 있으면 불러오지 않고 알린다.
- v3.x의 저장 데이터는 읽지 않는다. 규칙이 달라 옮길 수 없다.
- 인생이 끝나면 `gt4.life`를 지우고 `gt4.meta`에 기록한다. 죽은 인생을 불러와 되돌릴 수 없다.
