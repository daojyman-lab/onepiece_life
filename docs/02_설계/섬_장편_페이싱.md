# 섬 장편 페이싱 (v6.9)

## 문제
섬 장편의 다음 장면은 문을 고르는 즉시 줄(queue)에 서고, 다음 토막에서 곧장 열렸다.
10장면 안팎이 클릭마다 연달아 나와서 "두 달의 이야기"가 아니라 긴 글 한 편을 읽는 느낌이었다.
제목의 「N주차」만으로는 시간을 판단할 수 없다. 같은 주라도 며칠 뒤의 장면(제안 → 결전 준비)이 있고,
주가 바뀌어도 실시간으로 이어지는 장면(어인섬 반란 → 멈춰 선 노아)이 있다.

## 막 구성 (`src/v5/data/episodes/pacing.ts`)
18개 시나리오를 장면 단위로 점검해 **1~4막 + 에필로그**로 나누고, 실시간으로 이어지는 장면에 `!`를 붙였다.

| 막 | 대체로 | 내용 |
|---|---|---|
| 1막 | 1~2주차 | 발단, 안내자 · 기록자와 만남 |
| 2막 | 3~4주차 | 흔적을 쫓음, 주민 회의, 원작 인물의 판단 |
| 3막 | 5~6주차 | 거점 습격, 악당의 제안, 준비 |
| 4막 | 7~8주차 | 전야, 결전, 그 결과 |
| 에필로그 | 9~10주차 | 두 달 뒤, 작별 |

실시간 장면(`!`)의 기준: 싸움 바로 뒤의 장면(○○r · ○○w · win · lose · fall), 같은 자리에서 이어지는 장면(회의가 흩어진 뒤 · 순찰표 발견),
원작 사건의 한복판(어인섬 반란 → 노아, 아르바나 결전, 드레스로자 새장 → 새장이 걷힌 아침, 와노 불의 축제 밤 → 카이도가 진 순간, 하늘섬 신의 놀이 → 종소리).

## 규칙
| 앞 장면 → 다음 장면 | 쉼 | 기록 |
|---|---|---|
| 다음 장면이 실시간 | 0 | — |
| 같은 막 | `V.story.beat` = 1~2토막 | 섬의 일상 한 줄씩 |
| 막이 바뀜 | `V.story.act` = 3~4토막 | `── 3막 · 기억의 방 ──` + 섬의 일상 한 줄씩 |

- 장편의 첫 장면이 뜰 때 `── 1막 · … ──`을 남긴다.
- 쉬는 토막에는 나이 · 성장 · 위험 · 항해 · 다른 전환점이 흐르지 않는다. 장편 전체가 두 달 남짓이기 때문이다.
- 쉼 도중 끼어든 계기(부상 등)를 고른 뒤에는 쉼을 다시 세지 않는다.
- 일상 줄은 최근 기록 `V.story.memory`(150)줄 안에 나온 것을 다시 내지 않는다. 섬 줄 → 공용 줄 → 다 떨어지면 최근 몇 줄만 피한다.
- 쉼의 길이와 일상 줄 고르기는 곁 난수(`storyRng`)를 써서, 인생의 다른 주사위를 바꾸지 않는다.

## 구현
| 자리 | 내용 |
|---|---|
| `data/episodes/pacing.ts` | 18개 시나리오의 막 제목과 실시간 장면 |
| `core/turning.ts` `storyPause` | 장편 문을 고른 뒤 · 이야기가 이어지는 싸움이 끝난 뒤, 막 구성으로 `s.storyRest` · `s.storyNote`를 정한다 |
| `core/year.ts` `storyInterlude` | `stepPart` 맨 앞에서, 쉼이 남았으면 막 제목(있으면)과 섬의 하루 한 줄을 내고 끝 |
| `data/storyLines.ts` | 6섬의 일상 줄(섬마다 18~19줄) + 공용 줄 12개 |
| `tests/v5/story-pace.test.ts` | 모든 장편 장면이 막 구성표에 있음, 실시간 0 · 같은 막 1~2 · 막 전환 3~4 + 막 제목, 쉼에 나이를 먹지 않음 |

## 새 장편을 쓸 때
`pacing.ts`에 막을 적는다. 빠지면 테스트가 실패한다.

## 다음에 볼 것

- 앞 장면의 선택이 남긴 **여운 줄**(예: 구한 아이가 찾아온다)을 장면별로 붙이기.
- 막 사이 쉼에 가벼운 선택(수련 · 휴식 · 인연)을 넣어 결전 준비가 체감되게 하기.
