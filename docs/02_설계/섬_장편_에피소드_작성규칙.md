# 섬 장편 에피소드 작성 규칙 (v6.9)

주요 섬 6곳(로그타운 · 알라바스타 · 스카이피아 · 어인섬 · 드레스로자 · 와노쿠니)에 원작의 사건과 나란히 흐르는 오리지널 장편을 넣는다. 섬별 시나리오 기준은 `docs/01_기획/v06.9_doc.md`를 따른다.
섬 하나에 파일 하나: `src/data/episodes/<섬>.ts`. **자기 파일만 고친다.** 다른 파일(코어, 다른 섬, index.ts, 테스트)은 건드리지 않는다.

## 1. 큰 원칙 (통합 기획에서)

- 주인공은 루피와 같은 세대다. **주인공이 열일곱 살 무렵 원작이 시작된다.** 원작 시점(주인공 나이): 로그타운 17, 알라바스타 17~18, 스카이피아 18, 에니에스 로비 18, 샤본디 18~19, 마린포드 19, (2년 뒤) 어인섬 21, 드레스로자 21, 홀케이크 21~22, 와노쿠니 22.
- **밀짚모자 해적단의 역할과 원작의 승패를 대신하지 않는다.** 원작 아크의 그 순간(주인공 나이가 그 아크와 같을 때)에는 다른 전선 · 주민의 처지 · 별동 임무를 겪는다. 결말을 정하는 판가름은 원작 주역이 한다.
- 원작 보스전은 의무 장면이 아니다. 넣으려면 해당 시기의 소재지와 행적을 공식 자료로 확인하고, 원작의 패배·체포·생사를 바꾸지 않는 결과만 허용한다. 현재 6섬의 지역 사건은 오리지널 적대자와 주민 갈등으로 해결한다.
- **원작 인물의 힘은 플레이어에 맞춰 낮추지 않는다.** 약할 때는 목격 · 간접 대립(부하 · 조직) · 일시 협력, 강해지면(경지 조건) 직접 대결이 열린다. 직접 대결 문에는 `when: [ready(n)]`(어느 갈래든 n단계 이상)과 `danger: true`.
- 치명적인 강적전(`lethal: true`)은 큰 보스에만. 지면 죽을 수 있다. 언제나 물러날 문 · 싸우지 않는 길이 있어야 한다.
- 오리지널 인물(이름 없는 주민, 상인, 아이, 병사 등)은 지역 이야기와 개인적 관계를 맡는다. 원작 빌런을 대체하지 않는다.

## 2. 에피소드의 짜임 (v6.8: 2~3달짜리 시나리오)

**본보기: `docs/01_기획/08_하늘섬_시나리오_SKY_B_01.md`** (하늘섬 시나리오: 잊힌 황금의 수호자). 모든 장편은 이 결로 쓴다. 먼저 끝까지 읽는다.

- 섬마다 **시나리오 셋**: 원작 전 / 원작 그 무렵 / 원작 뒤. 방문할 때는 해당 시점의 시나리오 하나만 연다. 시나리오의 **극중 체류 기간**은 2~3달(8~12주)이다.
- 현재 엔진은 줄 선 장면을 바로 연다. 장면 제목의 주차는 이야기 속 경과를 표시하며, 게임 달력에는 그 기간이 아직 반영되지 않는다. 달력과 동기화하는 기능을 구현하기 전까지 실제 체류 기간이라고 UI에서 단정하지 않는다.
- 시나리오 하나에 장면 **9~12개**. 주차별 뼈대 (본보기 4장을 따른다):
  1. **도착과 첫 사건** — 지역 소개, 오리지널 인물 둘 소개, 가벼운 첫 싸움(지면 다치거나 상대가 달아날 뿐, `lethal: false`).
  2. **조사** — 방법을 고른다(무력 · 협상 · 관찰 · 무관심). 고른 길이 표시로 남아 뒤의 반응을 바꾼다.
  3. **추적 · 잠입** — 추적 / 잠입 / 정면 돌파. 결과에 따라 표시(예: 보급 창고 위치, 적 구성).
  4. **양쪽의 입장 차이** — 주민 회의 같은 갈등. 어느 쪽도 단순한 악으로 그리지 않는다. **원작 인물이 등장해 플레이어가 지금까지 실제로 한 일(표시)을 보고** 협력하거나 경계한다. 원작 인물은 문제를 대신 풀지 않는다.
  5. **발견 · 중간 저항** — 싸움, 숨겨진 서류, 실종자, 주민의 불신 중 섬의 문제에 맞게 고른다.
  6. **대립하는 이해관계** — 적대자의 거래 제안, 주민 회의, 관청의 결정 등으로 선택의 대가를 드러낸다.
  7. **해결 준비** — 피난로, 증거, 보급, 증인, 우회 항로 등에서 선택한다. 준비 표시는 마지막 장면의 비전투 길이나 전투 난도에 반영한다.
  8. **지역 사건의 결판** — 싸움만 정답으로 두지 않는다. 서류 공개, 협상, 운송 중단, 주민의 집단 행동으로도 해결할 수 있다. 위험한 전투에는 물러날 문을 둔다.
  9. **결말** — 섬 주제에 맞는 결과 **2~5개**를 쓴다. 결과마다 구한 사람, 공개한 기록, 잃은 신뢰, 남은 생계가 달라야 한다. 조건 없는 기본 길을 하나 두고, 결말마다 `time('…')`으로 인생 기록을 남긴다.
  10. **출항** — 오리지널 인물들과의 마지막 대화. 신뢰가 쌓였으면 작은 물건(표시)을 건넨다. 동행은 신뢰가 충분할 때만 따로 연다(`{ op: 'person', kind: 'crew', relation: '…', years: 1~2 }` 임시 동행).
- 오리지널 인물은 사건에 필요한 만큼 둔다. 안내자와 기록자 둘의 조합은 유용한 기본형이지만 모든 편의 필수 배역은 아니다. 신뢰 표시는 행동 기록과 함께 결말에 쓴다.
- 적대 세력의 형태는 섬에 맞춘다. 상단·관청·밀수단·사기단·주민 사이의 이해관계가 가능하다. 정찰병→간부→두목 3인조와 연속 전투는 필수가 아니다.
- 시나리오의 **시작 장면**만 가중치 > 0 (그 섬에 있을 때 · 그 시기의 나이일 때). 나머지는 가중치 0으로 앞 장면의 `next('id')`로만 온다. 시나리오가 끝나면 `flag('ep_<섬>_<시기>_done')`, 시작 장면은 `not(…_done)`.
- 표시를 너무 잘게 쪼개지 않는다: 시나리오마다 열 개 안팎. 모든 선택에 별도 이야기를 만들지 말고, 표시로 대사 · 상대 변형 · 지원 · 결말만 바꾼다(본보기 10장).
- 원작 그 순간에는 다른 전선을 택한다. 원작 보스의 행적이 확인되지 않는 빈 구간을 임의로 채우지 않는다.
- **하늘섬의 원작 뒤 시나리오는 본보기(SKY_B_01)를 그대로 옮긴다.**

## 3. 데이터 꼴 (src/core/types.ts의 Turning · Door · Cond · Fx)

```ts
import type { Turning } from '../../core/types';
import { D, on, flag, has, not, next, log, time, fight, ready, type FoeDef } from './kit';
import { age, at, st, ACTIVE, GROWN } from '../turnings/paths';   // age(min,max), at(...conds) 조건 배열, st(...처지)

export const FOES_ALABASTA: FoeDef[] = [
  { id: 'b_mr2', name: '봉쿠레', title: '바로크 워크스 미스터 2', canon: 'bonclay', p: 40, sea: 'gl_first', skills: ['fist_combo', 'fist_counter', 'fruit:mane:0'], tactic: 'counter' },
];
export const EP_ALABASTA: Turning[] = [
  {
    id: 'ep_alabasta_1', kind: 'door', when: at(on('알라바스타 왕국'), age(14, 16), not('ep_alabasta_done')), weight: 30, repeat: 'once', speaker: 'hero',
    title: '...', body: '... {name}은(는) ...',
    doors: [
      { label: '...', hint: '...', values: { justice: D }, fx: [next('ep_alabasta_2')] },
      { label: '...', hint: '...', values: { greed: D }, fx: [flag('ep_alabasta_bw'), next('ep_alabasta_3')] },
      { label: '...', hint: '...', values: { peace: D }, fx: [log('...'), flag('ep_alabasta_done')] },
    ],
  },
  { id: 'ep_alabasta_2', kind: 'door', when: [], weight: 0, repeat: 'once', speaker: { canon: 'vivi' }, title: '...', body: '...', doors: [...] },
];
```

- **id**: `ep_<섬>_<번호 또는 낱말>`. **표시(flag)**: `ep_<섬>_...`. 다른 섬과 겹치지 않게.
- **speaker**: `'hero'` · `{ canon: '<id>' }`(아래 목록의 원작 인물) · `{ relation: '...' }`(곁의 사람의 관계 글).
- **조건(Cond)** 자주 쓰는 것: `age(min,max)`, `st('pirate','marine',...)` 처지, `on('섬')`, `{ c: 'tier', branch: 'any', min: n }`(= `ready(n)`), `{ c: 'fame', min }`, `has/not('표시')`, `{ c: 'sea', is: [...] }`, `{ c: 'standing', is: [...] }`, `{ c: 'species', is: ['fishman','merfolk',...] }`, `{ c: 'home', is: ['wano'] }`, `{ c: 'dream', has: true, is: ['bestSword'] }`, `{ c: 'value', id: 'justice', deep: true }`.
  - 처지(Standing): child civil pirate marine revolution bountyHunter cp warlord shipwright settled retired prisoner
  - ACTIVE = 활동하는 처지들, GROWN = 어른 처지들 (paths.ts 참조)
  - 경지(tier) 기준: 1 입문 · 2 수련 · 3 숙련 · 4 달인 · 5 경지 · 6 극의. 간부급 직접 대결은 3~4, 칠무해 · 대장급은 5, 사황급은 6.
- **효과(Fx)** 자주 쓰는 것: `next(id)`, `flag(id)`, `log(text)`, `time(text, canonId?)`(연표 · 엔딩의 겹친 원작 순간), `fight(...)`, `{ op: 'hp', add }`, `{ op: 'money', add }`, `{ op: 'fame', add }`, `{ op: 'hardship', add }`, `{ op: 'base', key: 'str'|'spd'|'vit'|'int'|'wil'|'luk', add }`, `{ op: 'mastery', branch: 'sword'|'fist'|'gun'|'fruit'|'armament'|'observation'|'conqueror', add }`, `{ op: 'person', kind: 'ally'|'rival'|'crew'|'lover', relation: '...', canon?: '<id>', years?: n(임시 동행) }`, `{ op: 'injury', severity: 'light'|'heavy' }`, `{ op: 'standing', to: '...' }`(처지를 바꾸는 큰 일에만), `{ op: 'die', cause: '...' }`(드물게).
  - `person`의 `kind: 'family'`는 쓰지 않는다. 원작 인물을 동료(crew)로 들이는 일은 이미 다른 곳에 있으니 여기서는 ally · rival · 임시 동행(`kind: 'crew', years: 1~2`) 정도로.
- **상대(foe)**: 이미 있는 이름 있는 상대 id: b_alvida 알비다(20), b_buggy 버기(24), b_kuro 쿠로(27), b_krieg 크리크(28), b_morgan 모건(26), b_arlong 아론(28), b_smoker 스모커(44), b_mr1 미스터 1(44), b_lucci 루치(66), b_crocodile 크로커다일(68), b_darc 키자루(94), b_hody 호디 존스(90), b_fujitora 후지토라(128), b_doflamingo 도플라밍고(130), b_akainu 아카이누(178), b_kaido 카이도(182). 괄호는 힘(p).
  새 상대는 자기 파일의 `FOES_<섬>`에 `FoeDef`로 넣는다(id는 `b_` + 이름). 힘(p)은 위 숫자와 바다를 기준으로 맞춘다: 이스트 블루 20~30, 위대한 항로 전반 35~75, 어인섬 60~90, 신세계 90~180. `sea`: east, gl_first(알라바스타 · 스카이피아), sabaody(어인섬), nw_first(드레스로자), nw_late(와노쿠니).
  기술(skills) id: fist_jab fist_combo fist_counter fist_guard fist_iron fist_quake fist_secret fist_final / sword_cut sword_draw sword_flash sword_parry sword_wave sword_secret sword_finish sword_final / gun_shot gun_quick gun_snipe gun_volley gun_smoke gun_bind gun_secret gun_final / arm_hard arm_coat arm_guard arm_strike arm_flow / obs_sense obs_read obs_strike obs_future / con_burst con_coat con_wave / 열매 `fruit:<열매 id>:<0~3>`(열매 id: gura magu yami mera goro hie pika ope ito suna moku gomu hana bari doku numa bara bomu supa doru awa sube buki setsu kusu musu kan hyo zan kame beta ...). tactic: offense defense counter endurance. 열매가 있으면 `fruitClass: 'logia'|'paramecia'|'zoan'`, 패기는 `armament`/`observation` 0~3.

- 싸움으로 갈래를 가르려면 `fight('b_xxx', lethal, { win: 'id', lose: 'id', back: 'id' })`. 이기면 win, 지거나 간신히 빠져나오면 lose, 맞서지 않고 물러나면 back 장면이 줄 선다. **시나리오의 싸움은 세 갈래를 모두 이어 둔다**(지면 다음 주차로 넘어가되 표시가 다르게).
- 운에 맡기는 갈래: `{ op: 'chance', p: 0.5, then: [...], else: [...] }`.

## 4. 반드시 지킬 데이터 규칙 (테스트가 잡는다)

1. 문은 **보통 문 2~3개**, 특별한 문(`special: '<가치관>'`)은 **많아야 1개 더**.
2. 문마다 **조건(`when`) · special이 없는 문이 적어도 하나**.
3. 문의 label · hint에 **가치관 이름(정의 · 탐욕 · 야망 · 낭만 · 탐구 · 의리 · 자유 · 패도 · 평온)과 숫자(0-9)를 쓰지 않는다.** (자유롭게, 평온한 같은 낱말도 걸린다)
4. 가족 · 동료 · 헤엄을 전제하는 낱말(아내 · 남편 · 아들 · 딸 · 자식 · 동생 · 누이 · 형제 · 동료 · 바다에 뛰어든다 · 헤엄 · 물에 뛰어들어 · 바다 밑으로)을 본문이나 문에 쓰면 그 전환점/문에 `needs: ['spouse'|'child'|'sibling'|'crew'|'swim']`를 단다. 되도록 이런 낱말은 피한다.
5. 가치관 표시(values)는 아홉 가지(justice greed ambition romance inquiry loyalty freedom dominion peace)를 **고르게** 쓴다. 문 하나에 보통 하나, 값은 `D`.
6. 본문의 자리표시: `{name}`(이름만), `{island}`(지금 섬), `{town}`(태어난 마을). 조사는 `은(는) 이(가) 을(를) 과(와) (으)로`처럼 괄호로 쓰면 저절로 고른다.
7. 줄 세우는(next) id는 모두 같은 파일 안에 있어야 한다. 쓰는 표시는 다른 장면에서 실제로 쓰여야 한다.

## 5. 글의 결

- 한국어, 현재형 서술. 본문 2~4문장, 원작의 장면이 떠오르게 구체적으로(소리 · 냄새 · 인물의 말투). 문 label은 한 줄 행동, hint는 그 결과의 예감 한 줄.
- 기존 전환점(src/data/turnings/canon.ts, islands.ts, bonds.ts)의 말투를 따른다. 반말 서술체(~다).
- 원작 설정(인물의 시기 · 생존 · 소속 · 능력)과 어긋나지 않게. 모르면 얼버무리기보다 그 인물을 쓰지 않는다.
