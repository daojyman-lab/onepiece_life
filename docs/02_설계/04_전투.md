# 04 전투

수치는 모두 출발값이다. `data/balance.ts`에 두고 대량 시뮬레이션으로 맞춘다.

## 1. 전투에 서는 사람 — `Combatant`

주인공, 동료, 적을 같은 형태로 바꿔서 싸운다.

| 값 | 식 |
|---|---|
| 최대 체력 | `80 + 체력 × 8` (주인공은 현재 건강 비율을 곱한다) |
| 최대 기력 | `40 + 정신 × 4` |
| 방어 | `체력 × 0.6 + 방어구` |
| 속도 | `속도` (행동 순서와 회피에 쓴다) |
| 무장색 단계 | 0~3 (연 큰 단계로 정해진다) |
| 견문색 단계 | 0~3 |
| 열매 계통 | 없음, 초인계, 동물계, 자연계 |

부상은 능력치를 줄인 뒤 위 식에 넣는다.

## 2. 합

- 전투는 최대 20합이다.
- 한 합에 양쪽이 한 번씩 행동한다. `속도 + 0~10의 난수`가 큰 쪽이 먼저다.
- 20합이 지나면 남은 체력 비율이 높은 쪽이 이긴다.

### 한 번의 행동

1. 물러날 조건이면 물러나기를 시도한다. 6장.
2. 장착한 기술을 전법이 정한 순서로 훑는다. 다음을 모두 만족하는 첫 기술을 쓴다.
   - 재사용 대기가 끝났다.
   - 기력이 충분하다.
   - 발동 조건(`when`)이 맞다.
3. 쓸 기술이 없으면 기본 공격을 한다. 위력 1.0, 기력을 5 되찾는다.

### 발동 조건

| `when` | 뜻 |
|---|---|
| `always` | 언제나 |
| `opening` | 첫 2합 |
| `hpBelow50` | 내 체력이 절반 아래 |
| `enemyHpBelow30` | 상대 체력이 30% 아래 (마무리) |
| `afterEnemyBig` | 상대가 직전에 위력 2.0 이상의 기술을 썼다 (받아치기) |
| `allyDown` | 집단전에서 우리 편이 쓰러졌다 |

## 3. 피해

```
피해 = 능력치 × 위력 × 숙련 × 무기 × 전법 × 난수(0.9~1.1)
       × 100 ÷ (100 + 상대 방어 × 2)
       × 치명타 × 자연계 × 방어 효과
```

| 항 | 값 |
|---|---|
| 능력치 | 기술의 `stat` (힘, 속도, 지능, 정신 중 하나) |
| 숙련 | `0.7 + 0.6 × 숙련 ÷ 100` → 0.7~1.3 |
| 무기 | 등급에 따라 1.0~1.5. 무기가 그 기술의 갈래와 맞아야 한다 |
| 치명타 | 확률 `5% + 운 × 0.1%`, 1.5배 |
| 자연계 | 아래 |
| 방어 효과 | 상대가 방어 기술을 쓴 합이면 그 기술의 값만큼 준다 |

### 회피

- 확률 `3% + (맞는 쪽 속도 − 때리는 쪽 속도) × 0.3%`, 0~25%로 자른다.
- 견문색 단계마다 +5%.
- `area` 기술은 회피 확률이 절반이다.

### 자연계

맞는 쪽이 자연계면 피해에 다음을 곱한다.

단계 = 무장색 + 관통 기술 + 해루석 무기(같은 갈래 기술) + 해루석 탄환, 최대 3. 다만 맞는 쪽이 해루석에 닿아 있거나(3합) 묶여 있으면 단계와 상관없이 1.00이다. 규칙은 `logiaMult` 한 곳에 있다 (2026-11-14 추가).

| 단계 | 곱 |
|---|---|
| 0 | 0.25 |
| 1 | 0.50 |
| 2 | 0.75 |
| 3 | 1.00 |

- 무장색 단계가 1 이상이면 모든 공격에 무장색이 실린 것으로 본다.
- `pierce` 기술과 해루석 소모품은 한 단계 높은 것으로 친다.
- 주인공이 자연계를 먹었을 때도 같은 규칙으로 적의 공격이 준다. 해역이 높아질수록 적의 무장색 단계가 오른다.

### 열매의 대가

- 열매를 먹은 사람은 바다 위 전투(해상 임무의 강적전)에서 물에 빠질 수 있다. 체력이 30% 아래일 때 큰 기술을 맞으면 20%로 빠지고, 빠지면 진다. 항해사 동료가 있으면 10%다.
- 해루석 소모품을 맞으면 2합 동안 열매 기술을 못 쓴다.

## 4. 전법

| 전법 | 피해 | 받는 피해 | 기술을 고르는 순서 | 특징 |
|---|---|---|---|---|
| 공세 | +15% | +15% | 위력이 큰 기술부터 | 빨리 끝낸다. 기력이 먼저 떨어진다 |
| 수비 | −10% | −20% | 방어·회복 기술부터 | 오래 버틴다 |
| 반격 | 평소 −5%, 받아치기 +40% | 0 | `afterEnemyBig` 기술부터 | 큰 기술을 쓰는 상대에게 강하다 |
| 지구전 | −5% | −5% | 기력이 적게 드는 기술부터 | 기력 소모 −30%. 10합 뒤부터 피해 +20% |

전법에 정해진 상성표는 없다. 상대의 기술 구성과 맞물려 유불리가 생긴다. 공세로 나오는 상대에게 반격이 잘 통하고, 기력이 적은 상대에게 지구전이 잘 통한다.

## 5. 정찰과 준비

강적전 앞에서 `pending = prep`이 된다.

### 정찰이 보여 주는 것

| 조건 | 보이는 것 |
|---|---|
| 언제나 | 이름, 얼굴, 열매 계통, 간부 수 |
| 지능 30 이상 또는 항해사 동료 | 전법, 주력 기술 2개 |
| 지능 60 이상, 또는 인물 도감에 있음 | 능력치, 무장색 단계, 기술 전부 |

### 위험도

지금 편성으로 전투를 200번 미리 돌려 승률을 낸다. 보이는 승률에는 `±(15 − 지능 × 0.1)%`의 오차가 섞인다.

| 승률 | 위험도 | 졌을 때 죽을 확률 |
|---|---|---|
| 70% 이상 | 안전 | 0 |
| 35~70% | 위험 | 5% |
| 35% 미만 | 치명 | 25% |

편성을 바꾸면 승률을 다시 낸다. 준비 화면에서 편성을 바꾸며 승률이 오르내리는 것을 본다. 이것이 준비의 재미다.

### 준비 화면에서 정하는 것

| 항목 | 내용 |
|---|---|
| 기술 | 6칸 |
| 전법 | 넷 중 하나 |
| 물러날 기준 | 끝까지, 체력 30%, 체력 50% |
| 장비 | 무기, 방어구, 장신구 |
| 소모품 | 3칸 |
| 동료 | 누가 누구를 맡을지 (집단전) |
| 물리기 | 도전을 미룬다. 임무의 강적전이면 그 임무는 실패한다. 보스면 불이익이 없다 |

준비를 마치면 그 편성이 `loadout`에 저장되어 평소 교전에 쓰인다.

## 6. 물러나기

- 합이 시작될 때 체력 비율이 기준 아래면 시도한다.
- 성공 확률 `50% + (내 속도 − 상대 속도) × 1%`, 20~90%로 자른다.
- 성공하면 전투가 끝난다. 죽지 않는다. 가벼운 부상 30%.
- 실패하면 그 합은 그대로 싸우고 다음 합에 다시 시도한다.

## 7. 결과

| 결과 | 부상 | 죽음 | 그 밖 |
|---|---|---|---|
| 승리 | 가벼움 10% | 없음 | 보상, 명성, 숙련 |
| 물러남 | 가벼움 30% | 없음 | 임무 강적전이면 임무 실패 |
| 패배 | 가벼움 50%, 무거움 35%, 후유증 15% | 위험도에 따라 0, 5%, 25% | 돈의 일부를 잃음. 임무 실패 |

- 죽을 확률은 운으로 조금 준다: `× (1 − 운 × 0.003)`.
- 죽을 고비를 넘기면(패배했고 죽음 판정을 받았으나 살았다) 패기의 큰 단계가 열릴 수 있다. 확률 15%.
- 대련(라이벌, 스승, 동료)은 죽음도 무거운 부상도 없다.

## 8. 실전 숙련

- 전투에서 쓴 기술은 쓴 횟수마다 숙련이 오른다. 평소 교전 +0.5, 강적전 +2.
- 이긴 전투는 1.5배다.
- 강적전에서 이기면 능력치도 오른다. 상대가 강할수록 크다.

## 9. 평소 교전

- 달마다 발생을 판정한다. 해적 12%, 해군 15%, 길이 없으면 3%. 임무 중이면 +5%.
- 상대는 지금 해역의 전투력 범위에서 뽑는다.
- 저장된 편성으로 같은 전투 규칙을 화면 없이 돌린다.
- 죽지 않는다. 지면 가벼운 부상 40%.
- 기록에 한 줄 남는다. 누구와 싸워 이겼는지 졌는지.

## 10. 집단전

강적에게 간부가 있으면 집단전이다.

### 짝 짓기

- 준비 화면에서 누가 누구를 맡을지 정한다. 주인공이 우두머리를 맡아도 되고, 동료에게 우두머리를 맡기고 간부부터 쓰러뜨려도 된다.
- 우리 편이 모자라면 남는 적은 주인공의 싸움에 붙는다. 우리 편이 남으면 남는 동료는 주인공의 싸움을 돕는다.
- 치료 역할의 동료는 싸우지 않고, 3합마다 우리 편 한 명의 체력을 되찾아 준다.

### 진행

- 모든 교전이 같은 합에 맞춰 함께 흐른다.
- 한 교전이 끝나면 이긴 쪽은 손이 빈다.
  - 손이 빈 적은 주인공의 싸움에 붙는다. 붙은 사람은 합마다 절반 위력으로 한 번 공격한다.
  - 손이 빈 동료는 주인공의 싸움에 붙는다. 같은 식으로 돕는다.
  - 주인공의 손이 비면 `pending = intervene`이 된다.

### 개입

주인공이 자기 상대를 쓰러뜨렸고 적이 남아 있으면 고른다.

| 선택지 | 내용 |
|---|---|
| 진행 중인 교전 하나 | 그 교전에 주인공이 들어간다. 남은 체력과 기력 그대로다. 그 동료는 돕는 쪽으로 물러난다 |
| 숨 고르기 | 한 합 쉬며 기력의 20%를 되찾는다. 그동안 다른 교전은 흐른다 |

### 승패

- 상대 우두머리가 쓰러지면 이긴다. 남은 간부는 달아난다.
- 주인공이 쓰러지면 진다. 동료가 남아 있어도 진다.
- 쓰러진 동료는 몇 달 동안 부상이다. 위험도가 치명인 전투에서는 5%로 죽는다.

### 동료의 전투 값

동료는 `power`(레벨에 비례)에서 능력치를 만든다. 역할에 따라 나뉜다.

| 역할 | 능력치 | 전투 |
|---|---|---|
| 전위 | 힘·체력에 치우침 | 적을 맡아 싸운다 |
| 지원 | 속도·지능에 치우침 | 적을 맡아 싸운다. 돕는 쪽일 때 위력이 절반이 아니라 70% |
| 치료 | 정신에 치우침 | 싸우지 않고 회복시킨다 |
| 항해사, 요리사, 목수 | 낮음 | 싸우지 않는다. 항해·생활·배에 효과 |

## 11. 화면에 내보내는 것

전투 규칙은 한 번에 끝까지 계산하고, 그 과정을 기록(`BattleLog`)으로 내놓는다. 화면은 그 기록을 차례로 재생한다.

```ts
interface BattleLog {
  duels: { id: number; left: string; right: string }[];
  events: BattleEvent[];          // 합, 누가, 무슨 기술, 피해, 회피, 치명타, 쓰러짐, 합류
  intervenePoints: number[];      // 주인공의 손이 비는 지점. 여기서 계산을 멈추고 답을 기다린다
  result: 'win' | 'lose' | 'retreat';
  summary: { skill: SkillId; uses: number; damage: number }[];   // 끝난 뒤 보여 주는 표
}
```

- 재생 속도는 조절할 수 있고 건너뛸 수 있다.
- 끝난 뒤 "어느 기술이 얼마나 통했는지"를 표로 보여 준다. 다음 준비의 근거가 된다.
- 개입이 있는 전투는 개입 지점까지만 계산하고, 답을 받은 뒤 이어서 계산한다.
