## 단계별 진행 규칙

각 단계는 앞 단계의 산출물을 입력으로 받고, 완료 조건을 채운 뒤 다음으로 넘어간다. 단계별 입력·산출물·완료 조건은 각 폴더의 README에 있다.

| 단계 | 답하는 질문 | 주요 산출물 |
|---|---|---|
| 기획 | 무엇을 만드는가 | 기획서, 데이터 명세, 과제 목록 |
| 설계 | 어떤 구조로 만드는가 | 아키텍처, 모듈 경계, 상태·데이터 스키마, 화면 설계 |
| 계획 | 어떤 순서로 만드는가 | 작업 분해, 마일스톤, 단계별 완료 기준 |
| 구현 | 만든다 | 소스, 빌드 결과물, 변경 기록 |
| 검증 | 기획대로 만들어졌는가 | 테스트 결과, 플레이 확인 기록, 미해결 목록 |
