# 그랜드 트레저 — 엑스트라 캐릭터 이름 500선

버전: 1.0  
용도: 랜덤 출생 인물, 부모·형제·스승·라이벌, 해적·해군·상인·지역 주민·엑스트라 NPC 이름 풀

## 작명 방향

- 원피스 세계의 다문화적 작명 감각과 과장된 캐릭터 이름의 리듬을 참고해 만든 신규 이름이다.
- 단일 이름으로 바로 사용할 수 있게 구성했으며, 성씨나 별칭이 필요한 인물은 별도 항목을 조합할 수 있다.
- 지역별 발음 분위기를 나눴다. 실제 출생지에 강제 배정하기보다는 랜덤 이름 풀을 고르는 기준으로 사용한다.
- 유명 원작 인물의 이름을 그대로 쓰거나 한두 글자만 바꾸는 방식은 피했다.
- 영문 표기는 기준 데이터, 한글은 게임 화면용 표기다.
- 원작의 모든 단역·언급 인물과 완전 대조한 목록은 아니다. 최종 적용 전 기존 캐릭터 DB와 전체 중복 검사를 권장한다.

## 이름 풀 사용법

1. 엑스트라 NPC는 전체 500개에서 무작위 추첨한다.
2. 지역의 문화적 분위기를 반영하고 싶으면 해당 분류에서 추첨한다.
3. 가족 인물은 같은 성씨를 공유할 수 있도록 별도 성씨 풀 또는 `family_id`를 사용한다.
4. 해적·현상금 사냥꾼·유명 인물의 별칭은 기본 이름과 분리해 저장한다.
5. 장기 등장 인물의 이름은 최초 생성 후 고정한다. 재등장할 때 이름이 바뀌면 안 된다.
