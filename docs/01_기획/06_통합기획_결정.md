## Claude가 정한 것 (사용자가 바꿀 수 있음)

- 생애 단계 나이: 유년기 0~9, 수련기 10~15, 청년기 16~24, 장년기 25~40, 황혼기 41~. 멈춤 수는 단계에 맞춰 다시 조정한다.
- 전성기 진입: 기획서 5.2대로 "잠재력의 실현 + 결정적 사건" 두 조건. 처음 진입은 40세까지.
- 잠재력 유형(천재·균형·대기만성·특화)은 출생의 "타고난 몸"에 붙인다.
- 전투 팝업: 지금의 등급(F~SSS)과 위험 표시 옆에 우세/위험/절박/압도적 열세 말을 더한다. 전투 공식은 바꾸지 않는다.
- 원작 보스 전투력은 고정. 약할 때는 목격·간접 대립·협력, 강해지면 직접 대결이 열린다(기획서 8.2~8.3).
