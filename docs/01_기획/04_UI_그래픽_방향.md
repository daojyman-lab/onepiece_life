# UI · 그래픽 방향

작성일: 2026-11-14. 레퍼런스 이미지는 [refer/](../../refer/)에 있다. 시안은 [v3.4.0/그랜드_트레저_v3.4.0.html](../../v3.4.0/그랜드_트레저_v3.4.0.html)이다.

## 1. 확정한 것

| 항목 | 결정 | 근거 레퍼런스 |
|---|---|---|
| 전체 톤 | 나무 프레임과 양피지로 통일한다. 녹색 창·분홍 테두리는 쓰지 않는다. | `refer/character graphic`의 두루마리 대화창, `refer/uiux/utsy8suqmfy31.png`의 나무 인벤토리, 수배서 카드 모음 |
| 화면 구성 | 지금의 3단 구성(좌 프로필, 중앙 모험, 우 관계도)을 유지한다. 모바일은 세로 한 줄로 쌓는다. | — |
| 캐릭터 도트 | 코드로 그린다. 이미지 파일을 쓰지 않는다. | `refer/avatar`는 화풍 참고용 |
| 컷씬 | 큰 그림은 넣지 않는다. 모든 사건 창에 말하는 인물의 얼굴을 붙인다. | `refer/character graphic`의 얼굴 아이콘 |

`refer/avatar`와 카드 모음은 시판 게임에서 추출한 그림이다. 게임에 그대로 넣지 않고 비율, 외곽선, 색 수를 참고하는 데만 쓴다.

## 2. 디자인 규칙

### 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 짙은 나무 | `#2c170b`, `#4b2a17` | 외곽선, 머리글, 팻말 |
| 나무 | `#9c5f33`, `#d99a5b` | 프레임, 프레임 하이라이트 |
| 황토 | `#f0c88f`, `#dba968` | 패널 바탕, 기본 버튼 |
| 양피지 | `#f8e8b8`, `#e9d090`, `#fff6d6` | 칸, 사건 창, 선택지 |
| 먹 | `#3a2414`, `#6b5136` | 글자 |
| 금 | `#f6c744`, `#c98a1e` | 주 버튼, 제목, 현재 위치 |
| 빨강 | `#d8483c` | 경고, 선택 커서, 사건 꼬리표 |
| 바다 | `#3a8ec6`, `#58a8dc` | 페이지 바탕 |

### 형태

- 모서리는 모두 직각이다. 둥근 모서리를 쓰지 않는다.
- 패널 테두리는 4px 단위로 쌓는다(외곽선, 프레임, 하이라이트). 네 귀퉁이는 한 칸 비워 계단 모양으로 만든다. 600px 이하에서는 3px 단위다.
- 그림자는 번지지 않는 단색 띠다.
- 버튼은 2px 외곽선에 아래쪽 4px 음영을 두고, 누르면 2px 내려간다.
- 게이지는 6~8px 간격으로 칸을 나눈다.
- 움직임은 단계적으로 끊는다. 부드러운 전환을 쓰지 않는다.

### 글꼴

| 글꼴 | 크기 | 쓰는 곳 |
|---|---|---|
| Galmuri14 | 15px, 30px | 제목, 사건 본문 |
| Galmuri11 | 12px | 본문, 버튼 |
| Galmuri9 | 10px | 꼬리표, 보조 설명 |
| Press Start 2P | 8~11px | 영문 표지(WANTED, 숫자 강조) |

도트 글꼴은 정해진 크기에서만 또렷하다. 위 크기 밖의 값을 쓰지 않는다.

## 3. 도트 캐릭터

인물 한 명의 정보에서 그림을 만든다. 같은 인물은 언제나 같은 모습이다.

| 입력 | 반영되는 것 |
|---|---|
| 이름·고유 번호 | 피부색, 머리색, 머리 모양, 표정, 민간인 옷 색 (고정된 무작위) |
| 성별 | 머리 모양 후보, 속눈썹 |
| 나이 | 14세 이하 아이(작은 몸, 큰 눈, 볼터치), 55세 이상 노인(흰머리, 남성은 수염) |
| 종족 | 어인족·인어족은 푸른 피부와 지느러미, 밍크족은 귀 |
| 소속 | 해군은 흰 모자와 제복, 해적은 붉은 두건과 조끼, 혁명군은 녹색 두건 |

| 종류 | 크기 | 쓰는 곳 |
|---|---|---|
| 얼굴 | 24×24 | 수배서, 사건 창, 관계도 목록 |
| 전신 | 20×24, 2프레임 + 공격 자세 | 장면 캔버스 |

장면 캔버스는 실제 크기의 1/3(좁은 화면은 1/2) 해상도로 그린 뒤 정수 배율로 키운다.

## 4. 시안(v3.4.0)에 들어간 것

- v3.3.3을 복사한 뒤 스킨과 도트 그림만 얹었다. 게임 규칙은 건드리지 않았다.
- `pixel-skin.css`와 `pixel-art.js`가 원본이고, `python inline.py`로 HTML 안에 넣는다.
- 기존 초상화 일러스트 4장은 화면에 쓰이지 않지만 파일에는 남아 있다.
- 확인한 것: 시작 화면, 메인 화면(1360px, 375px), 사건 창, 관리 모달, 교전 창. 콘솔 오류 없음. 375px에서 가로 넘침 없음.
- 확인하지 않은 것: 항해 중 장면, 뉴스·인물 상세·저장 모달, 태블릿 폭.
