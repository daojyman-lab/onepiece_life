# 그랜드 트레저 — 엑스트라 캐릭터 성씨 300선

버전: 1.0  
용도: 랜덤 출생 인물, 부모·형제·스승·라이벌, 해적·해군·상인·지역 주민·엑스트라 NPC의 가족명

## 작명 방향

- 원피스 세계의 다문화적 작명 감각과 과장된 캐릭터 이름의 리듬을 참고해 만든 신규 성씨 후보다.
- 기존 원작의 유명 가문명과 대표 성씨를 그대로 재사용하지 않는 방향으로 구성했다.
- 지역별 분류는 분위기 참고용이며, 출생지에 엄격하게 고정할 필요는 없다.
- 영문 표기는 데이터 저장용 기준값, 한글은 게임 화면용 표기다.
- 실제 원작의 모든 단역·언급 인물과 완전 대조한 목록은 아니다. 적용 전 기존 캐릭터 DB와 원작 인물 DB에 대해 추가 중복 검사를 권장한다.

## 사용 규칙

1. 성씨는 가족 단위로 공유한다. 부모·형제·자녀가 같은 `family_id`를 가지도록 관리한다.
2. 이름과 성씨는 별도 필드로 저장한다. 예: `given_name = Ivenna`, `family_name = Bellcroft`.
3. 와노쿠니풍 성씨는 일본식 이름 순서를 적용할 수 있지만, 내부 데이터에서는 성씨와 이름 필드를 분리해 표기 순서를 렌더링 단계에서 처리한다.
4. 귀족·왕족·유력 가문 성씨는 일반 주민에게 지나치게 자주 배정하지 않는다.
5. 장기 등장 인물의 성씨는 최초 생성 후 고정한다.
