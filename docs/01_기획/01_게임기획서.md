## 0. 이 문서를 읽는 법

레퍼런스 v3.3.3은 v3.0.0 본체 위에 확장 스크립트 4개가 함수를 덮어쓰며 쌓인 구조다. 그래서 "코드에 있는 것"과 "실제로 동작하는 것"이 다르다. 이 기획서는 **실제로 동작하는 규칙**을 기준으로 쓰고, 각 기능에 아래 상태 표시를 붙인다.

| 표시 | 뜻 |
|---|---|
| **[동작]** | 레퍼런스에서 실제로 동작한다. 그대로 계승한다. |
| **[표시만]** | 화면과 저장 데이터에는 있으나 게임 규칙에 반영되지 않는다. |
| **[미동작]** | 코드는 있으나 호출 경로가 끊겨 플레이 중 발생하지 않는다. |
| **[결함]** | 동작은 하지만 의도와 다르게 동작한다. |

[표시만]·[미동작]·[결함] 항목을 새 버전에서 어떻게 처리할지는 [03_레퍼런스_현황과_과제.md](03_레퍼런스_현황과_과제.md)에 모았다. 수치와 문구의 전체 목록은 [02_데이터_명세.md](02_데이터_명세.md)에 있다.

분석은 코드를 읽어서 한 것이고, 게임을 실행해 확인한 것은 아니다. 실행 확인은 검증 단계에서 한다.

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 제목 | 그랜드 트레저 |
| 부제 | 대해적 시대의 항로 |
| 장르 | 텍스트 인생 시뮬레이션 RPG |
| 세계관 | 원피스 세계관 기반 (원작 지역·인물·사건을 배경으로 사용) |
| 플랫폼 | 웹 브라우저. PC와 모바일 세로 화면 |
| 플레이 인원 | 1인 |
| 한 판의 길이 | 한 인물의 일생 (1세 ~ 사망). 75세까지 산다면 1배속 기준 시간이 흐르는 데만 약 7~8분, 사건을 읽고 고르는 시간은 별도 |
| 언어 | 한국어 |

### 1.1 한 줄 소개

원피스 세계의 어느 항구에서 태어난 한 사람의 일생을, 시간이 흐르는 대로 지켜보다가 중요한 순간에만 선택하는 게임.

### 1.2 핵심 경험

1. **시간은 저절로 흐른다.** 플레이어가 버튼을 누르지 않아도 나이를 먹고 로그가 쌓인다.
2. **중요한 사건에서만 멈춘다.** 사건 카드가 뜨면 시간이 정지하고, 선택지를 골라야 다시 흐른다.
3. **원작의 섬을 순서대로 지나간다.** 후샤 마을에서 와노쿠니까지 21개 항구에서 각각 3단계의 이야기를 겪는다.
4. **주인공은 원작 주역의 싸움을 대신하지 않는다.** 루피 일행이 본대와 싸우는 동안 플레이어는 외곽에서 주민을 구하고 별동대를 막는다.
5. **전투는 숫자를 보고 결정한다.** 양쪽 전투력과 승률을 먼저 보여 주고, 그 확률 그대로 한 번 판정한다.

### 1.3 디자인 원칙

| 원칙 | 내용 |
|---|---|
| 자동 진행 우선 | 평범한 생활은 로그로만 기록한다. 선택지는 가치관이 갈리거나 위험한 순간에만 낸다. |
| 원작 파워밸런스 존중 | 플레이어가 사황·대장급을 단독으로 쓰러뜨리는 전개를 만들지 않는다. 지역 전투는 "원작 주역의 결전을 대체하지 않는 외곽 전투"로 설계한다. |
| 정보 공개 후 판정 | 전투 승률과 득실을 판정 전에 공개한다. 표시한 확률과 실제 판정이 같아야 한다. |
| 팝업 중 시간 정지 | 사건 카드나 모달이 열려 있는 동안 시간이 흐르지 않는다. |
| 한 화면 완결 | 관리·관계·뉴스는 페이지 이동 없이 메인 화면 위 모달로 처리한다. |
| 문체 | 소년만화식 모험담. 구체적인 장소·인물·행동·결과를 쓴다. 처음 등장하는 인물은 플레이어와의 관계부터 설명한다. |

### 2.2 항구 한 곳의 사이클 (게임의 주 루프)

```
입항
 └ 도착 직후 교전 (처음 온 항구일 때)
     ├ 싸운다 → 능력치 비교 → 판정 → 승패와 무관하게 이야기 1단계 완료
     └ 물러난다 → 체력 -4
 └ 이야기 2단계 (구조 / 조사 / 지역 적과 교전)
 └ 이야기 3단계 (구조 / 조사 / 현장 지원) → 완료 보상
 └ 다음 항로 후보 3곳 개방 → 목적지 선택
 └ 항해 3~6개월 (해상 교전 발생 가능)
입항 …
```

## 3. 캐릭터 생성

### 3.1 입력

| 단계 | 내용 |
|---|---|
| 이름 | 직접 입력, 최대 12자, 필수. "이름 추천" 버튼은 8개 중 하나를 넣어 준다. |
| 성별 | 남성 / 여성 |
| 성향 문답 | 10문항 3지선다. 건너뛸 수 있다. |

성씨·종족·출생지·가정환경은 플레이어가 고르지 않고 무작위로 정해진다.

### 3.2 성향 문답 [동작]

- 풀 60문항에서 중복 없이 10문항을 뽑는다. 최근에 나온 문항은 제외한다.
- 선택지 순서는 매번 섞는다.
- 선택지마다 **성향 1개**와 **능력치 보너스**(대개 합계 3점)가 붙어 있다.
- 가장 많이 고른 성향이 대표 성향이 된다. 문답을 건너뛰면 "모험형"이다.
- 성향 9종: 모험형, 분석형, 중재형, 돌파형, 수호형, 야망형, 독립형, 자유추구형, 충성형.

대표 성향은 프로필에 표시될 뿐 이후 규칙에 영향을 주지 않는다 **[표시만]**. 문답의 실질 효과는 능력치 보너스(10문항 합계 약 30점)다.

풀 60문항 중 40문항은 템플릿 10종을 4번 복제한 것이다 **[결함]**. 문항 전문은 데이터 명세 2장 참조.

### 3.3 출생 결정 [동작]

1. **성씨**: 성별에 허용된 성씨 18종 중 균등 추첨. 성씨가 종족·출생지 후보·가정환경 후보·능력치 보정·확정 재능을 정한다.
   - 예: "보아"는 여성 전용, 출생지는 여인섬 아마존 릴리, 아버지 없음.
   - "몽키·골·트라팔가·재규어"는 이름에 "D."가 들어간다.
2. **종족**: 성씨가 정한 종족(7종). 인간이면서 특정 성씨가 아니면 42% 확률로 8종 가중 재추첨.
3. **초기 능력치**: `기본값 + 0~4 무작위 + 성씨 보정 + 문답 보너스`.
4. **재능 또는 악마의 열매**: 22% 확률로 열매 1개(어인족 제외), 아니면 재능 1개.
5. **소지금**: 기본 15,000베리. 해군 집안 35,000. 천룡인 250,000.
6. **가족**: 어머니, 아버지(여인섬 출생이면 없음), 형제자매 0~3명(35/40/20/5%).
7. **고향 인물**: 소꿉친구 겸 라이벌 1명, 고향 스승 1명.

### 3.4 출생 프로필

생성이 끝나면 출생 프로필 모달이 뜬다. 이름, 종족·성별, 성씨 로어, 출생지, 가정환경, 초기 성향, 보유 재능, 부모와 형제자매 목록을 보여 준다. 게임 중에도 다시 열 수 있다.

## 4. 능력치

### 4.1 공개 능력치 10종

| 키 | 이름 | 기본값 | 주 용도 |
|---|---|---|---|
| str | 힘 | 10 | 전투력 (×2.6) |
| spd | 스피드 | 10 | 전투력 (×2.4) |
| int | 지능 | 10 | 전투력 (×2.0) |
| vit | 체력(내구) | 12 | 전투력 (×1.5) |
| haki | 패기 | 8 | 전투력 (×3.0), 패기 종류 습득 기준 |
| exp | 실전 경험 | 5 | 전투력 (×1.8), 인생 과업 조건 |
| dfMastery | 열매 숙련 | 0 | 전투력 (열매 보유 시 75 + ×2.2) |
| lead | 통솔 | 10 | 필수 위기 성공률, 최종 계급 조건 |
| sense | 감각 | 10 | 필수 위기 성공률 |
| luck | 운 | 10 | 전투력 보정 (최대 +10%) |

- 능력치에 상한이 없다.
- 메인 화면 능력치 바에는 lead·vit·sense가 표시되지 않는다 **[결함]**.

### 4.2 그 밖의 수치

| 수치 | 내용 |
|---|---|
| 건강 | 0~100. 0이 되면 사망. 전투력에 반영 |
| 소지금 | 베리(฿) |
| 현상금 | 해적·혁명군일 때 교전 승리로 오른다. 해군 입대 시 0 |
| 숨은 수치 | 명성, 가족 신뢰, 동료 신뢰, 생존력, 정부 위협도, 세계 영향력, 질병 저항 |

숨은 수치 중 명성(자유 항해자 과업 4단계)만 규칙에 쓰이고 나머지는 **[표시만]**이다.

### 4.3 성장 경로

| 경로 | 효과 | 비고 |
|---|---|---|
| 상시 훈련 | 분기마다 지정 능력치 +1 | 무료. 균형 훈련은 6종 중 무작위 +1 |
| 즉시 특훈 | 3,000~6,000베리로 능력치 +3 | 횟수·나이 제한 없음 **[결함]** |
| 사건 선택지 | 선택지마다 고정 수치 | |
| 교전 승리 | 힘 +3, 속도 +2, 경험, (16세 이상) 패기 +3, 열매 숙련 +4 | |
| 생활 에피소드 | 능력치 +1 | 16~25세 |

### 4.4 패기와 악마의 열매

- **패기 종류**: 무장색(패기 수치 18 또는 20 도달 시), 견문색(교전 승리 시 32 이상). 패왕색은 얻는 경로가 없다 **[미동작]**.
- **악마의 열매**: 출생 시 22%, 또는 4세 사건에서 선택. 플레이어용 8종은 원작 열매, 주변 인물용 8종은 창작 열매다.
- 보유 효과는 전투력 가산뿐이다. 열매 종류에 따른 차이나 수영 불가 규칙은 없다.

## 5. 시간 시스템

### 5.1 달력

- 시작: 해원력 1505년 1월, 1세.
- 12월을 넘기면 나이와 연도가 함께 오른다(생일 = 새해).

### 5.2 진행 단위 [동작]

| 나이 | 1틱에 흐르는 시간 | 화면 라벨 |
|---|---|---|
| 1~15세 | 6개월 | 유년기 · 빠른 성장 |
| 16~25세 | 1개월 | 모험의 전성기 · 월별 진행 |
| 26~59세 | 3개월 | 성년기 · 분기 진행 |
| 60세 이상 | 6개월 | 노년기 · 빠른 회고 |

생일과 사건 발생 시점에는 반드시 멈춘다.

### 5.3 속도 조절

| 버튼 | 틱 간격 |
|---|---|
| 정지 | — |
| 1배속 | 1.4초 |
| 2배속 | 0.75초 |
| 4배속 | 0.38초 |
| +진행 | 수동으로 1틱 |

사건 카드가 떠 있거나 모달이 열려 있으면 틱이 실행되지 않는다. 키보드 단축키는 없다.

### 5.4 정산 주기

| 주기 | 처리 |
|---|---|
| 매 틱 | 항해 진행, 성인 사건 판정, 교전 기회 만료 정리 |
| 분기(달력 3개월) | 상시 훈련 +1, 투자 배당, 해군·혁명군 복무 +1과 진급 심사 |
| 매년(생일) | 주변 인물 나이 +1, 뉴스 1건, 현상금 랭킹 갱신, 직함 갱신, 정기 임무 배정, 생활 로그 1건, 질병·노환 판정 |

월 단위로 진행되는 구간에서도 훈련·배당·복무는 분기마다 한 번만 정산한다.

## 6. 사건 시스템

### 6.1 구조

사건은 메인 화면 중앙의 카드로 표시된다. 분류 태그, 제목, 장소·나이, 관련 인물 설명, 본문, 선택지 1~4개로 이루어진다. 선택지에는 라벨과 한 줄 예상 효과가 붙는다. 선택하면 효과가 즉시 적용되고 결과가 로그에 남는다. 닫기 버튼은 없다.

### 6.2 사건 종류

| 종류 | 발생 조건 | 선택지 | 상태 |
|---|---|---|---|
| 유년기 사건 3종 | 4·9·14세 생일 | 3~4 | [동작] |
| 부모 사건 | 6·10·13세 생일 | 3 | [동작] |
| 라이벌 대련 | 6·10·13세, 부모 사건 직후 | 2 | [동작] |
| 도착 직후 교전 | 처음 입항한 항구 | 2 | [동작] |
| 지역 이야기 | 항구 정박 중, 단계별 대기 시간 경과 | 3 | [동작] (1단계는 사실상 건너뜀) |
| 해상 교전 | 항해 중 확률 판정 | 2 | [동작] |
| 생활 에피소드 12종 | 16~25세, 2개월 간격 | 2 | [동작] |
| 정기 임무 14종 | 16세 이상, 연 1회 배정 | 3 | [동작] |
| 필수 위기 | 18세 이후 1회 | 3 | [동작] |
| 은퇴 제안 | 50세 이상 + 건강 악화 또는 62세 이상 | 3 | [동작] |
| 후학 양성 | 은퇴 후 8분기마다 | 2 | [동작] |
| 사망 | 건강 0 또는 노환 | 1 | [동작] |
| 첫 진로 선택 "어떤 깃발 아래에서 떠날까" | 16세 이상, 소속이 "민간인"일 때 | 4 | [미동작] 14세 사건이 먼저 소속을 정함 |
| 전향 제안 | 20분기 간격 + 0.8% × 0.8% | 2 | [미동작] 사실상 0% |
| 원작 인물 조우 8종 | 특정 항구·조건 | 3~4 | [미동작] |
| 깜짝 조우 4종 (에이스·티치·봉쿠레·하치) | 특정 항구, 24% | 3 | [미동작] |

### 6.3 우선순위

같은 틱에 여러 사건이 겹치면 다음 순서로 하나만 뜬다: 은퇴 → 도착 직후 교전·지역 이야기 → 정기 임무 → 해상 교전 → 생활 에피소드.

## 7. 유년기 (1~15세)

### 7.1 생활 로그

매년 6문장 중 하나가 "[n세 생활]" 로그로 기록된다. 능력치 변화는 없다.

### 7.2 유년기 사건

**4세 — 해안가 동굴에 떠밀려온 수상한 나무 상자**

| 선택지 | 효과 |
|---|---|
| 상자를 부수고 보물과 나침반을 챙긴다 | 소지금 +18,000, "구형 기록지침", 운 +3 |
| 이상한 열매를 베어 문다 | 악마의 열매 획득, 힘 +5, 속도 +4 (이미 능력자면 체력 +4, 소지금 +25,000) |
| 스승에게 가져가 감정받는다 | 지능 +3, 패기 +3, 스승 신뢰 +15 |

**9세 — 항구를 덮친 약탈 해적단**

| 선택지 | 효과 |
|---|---|
| 단검을 쥐고 정면 돌격 | 힘 +5, 패기 +5, 건강 −18(하한 35), 형제 신뢰 +20 |
| 라이벌과 협공해 유인 | 속도 +4, 통솔 +4, 소지금 +12,000, 라이벌 신뢰 +18 |
| 해군 순찰대와 어른들을 지휘 | 지능 +5, 통솔 +3, 명성 +10 |

**14세 — 언덕 위의 맹세와 소속 제안** (진로 결정)

| 선택지 | 소속 / 직함 | 효과 | 지급 선박 |
|---|---|---|---|
| 내 해적기를 걸고 출항 준비 | 해적 / 신출내기 해적 선장 | 통솔 +5, 패기 +4 | 새벽의 범선호 |
| 해군 장교 후보생으로 입대 | 해군 / (다음 분기부터) 해군 이병 | 힘 +4, 체력 +4, 소지금 +30,000 | 해군 연안 순찰함 |
| 혁명군 비밀 행동대원으로 합류 | 혁명군 / (다음 분기부터) 혁명군 일반 병사 | 지능 +5, 감각 +5, "암호 전보벌레" | 혁명군 위장 쾌속선 |
| 현상금 사냥꾼 겸 자유 모험가 | 현상금 사냥꾼 / 독립 항해자 | 속도 +5, 운 +4 | 바람길 캐러벨 |

### 7.3 부모 사건 (6·10·13세)

"{부모 이름}의 이름이 항구에 퍼진 날". 아버지 또는 어머니가 무작위로 선정된다.

| 선택지 | 효과 |
|---|---|
| 현장에 따라가 배운다 | 부모의 전투 스타일에 따라 지능·힘·감각 상승, 해당 부모 신뢰 +10·친밀 +8 |
| 내 힘으로 집안을 돕는다 | 통솔 +3, 체력 +2, 가족 신뢰 +8 |
| 형제(또는 마을 사람들)와 함께 안전한 방법을 찾는다 | 지능 +3, 통솔 +2, 첫째 형제 신뢰 +12·친밀 +10 |

### 7.4 라이벌 대련 (6·10·13세)

부모 사건 뒤에 이어진다. "대련을 시작한다"를 고르면 전투 화면(대련 모드)이 열린다. "오늘은 쉬고 약점을 짚어본다"는 지능 +1, 라이벌 신뢰 +3.

- 대련에서는 패기·열매 점수를 0으로 계산한다.
- 라이벌 전투력: 6세 214 / 10세 275 / 13세 321.
- 승리: 힘 +2, 속도 +1, 경험 +4. 패배: 건강 −3, 경험 +2. 공통: 라이벌 신뢰 +4.

### 8.3 지역 이야기 3단계 [동작]

항구마다 `[제목, 본문, 선택지 3개]`로 된 단계가 3개 있다. 선택지의 성격은 모든 항구에서 같다.

| 선택지 | 성격 | 효과 |
|---|---|---|
| 1 | 구조·협력 | 건강 −4, 소지금 +6,000, 통솔 +2, 체력 +1 |
| 2 | 조사·전술 | 지능 +3, 감각 +2, 소지금 +3,000 |
| 3 (1·3단계) | 현장 지원 | 경험 +3, 건강 −8, 힘 +2 |
| 3 (2단계) | 지역 적과 교전 | 전투 화면으로 진입 |

단계를 마칠 때마다:

- 그 항구의 등장 인물 한 명이 "지역 협력자"로 관계 목록에 등록되고 신뢰 +8·친밀 +10씩 오른다.
- 해군·혁명군이면 공적 +12.

3단계를 마치면 소지금 +12,000, 명성 +5, "{항구명} 항구 협력증" 아이템, 뉴스 1건을 받고 **다음 항로 후보가 열린다.**

**도착 직후 교전**: 처음 온 항구에서는 이야기보다 먼저 지역 적의 선발대와 교전 사건이 뜬다. 싸우면 승패와 관계없이 1단계가 완료된다. 이 때문에 1단계 본문 사건은 정상 흐름에서 거의 표시되지 않는다 **[결함]**.

### 8.4 목적지 선택 [동작]

- 현재 항구의 이야기 3단계를 끝내야 목적지 창이 열린다.
- 후보는 항로 순서상 **다음 3곳**이다. 끝에 가까워 후보가 2곳 미만이면 앞쪽 항구로 채운다.
- 나이·전투력·비용 조건은 없다.
- 선택하면 표의 개월 수만큼 항해가 시작된다.

### 8.5 항해 [동작]

- 매 틱 남은 개월이 줄고 "항해 중..." 로그가 쌓인다.
- **해상 교전**: 분기당 한 번, 20세 미만 30% / 20세 이상 42%. 실패하면 같은 분기 안의 다음 틱에 다시 굴린다. 여기에 12% 추가 판정이 더 있다.
  - "동료들과 구조선의 퇴로를 확보한다" → 목적지 항구의 지역 적과 교전.
  - "안전한 수로로 우회한다" → 교전 없이 항해 +3개월.
- **항해 계기판**: 항해사 동료나 기록지침·영구지침 아이템이 있어야 도착 예상 시간과 날씨가 표시된다. 표시 여부만 달라지고 항해 자체는 같다.

## 9. 전투

### 9.1 진입

전투는 **사건이 만든 교전 기회**가 있을 때만 할 수 있다. 플레이어가 상대를 자유롭게 고를 수 없다. 교전 기회를 만드는 사건은 도착 직후 교전, 지역 이야기 2단계의 3번 선택지, 해상 교전, 라이벌 대련이다.

교전 창을 "접어두기"로 닫으면 기회가 남아 있는 동안 메인 화면의 교전 버튼으로 다시 열 수 있다. 기회는 나이를 기준으로 만료되며, 생긴 뒤 두 번째 생일에 사라진다.

### 9.2 전투력

**개인 전투력**

```
힘 점수     = 힘 × 2.6
속도 점수   = 스피드 × 2.4
전술 점수   = 지능 × 2.0
체력 점수   = 체력(vit) × 1.5 + 현재 건강 × 0.45
패기 점수   = 패기 × 3.0 + 보유 패기 종류 수 × 55
열매 점수   = 열매 보유 시 75 + 열매 숙련 × 2.2
경험 점수   = 실전 경험 × 1.8
개인 전투력 = 7개 점수 합 × (0.7 + 0.3 × 건강 비율)     ※ 건강 비율 하한 0.4
```

출생 직후 기본값으로 계산하면 166이다.

**동료 지원** (동료 1명당): 역할별 기본값(전투원 12, 저격 10, 요리 8, 항해 7, 의사 5) + 신뢰÷20 + 친밀÷25, 부상 중이면 −5, 최소 3.

**유효 전투력**

```
운 보정       = (운 − 10) × 0.2%, 0% ~ 10%
내 유효 전투력 = (개인 전투력 + 동료 지원 합) × (1 + 운 보정)
```

### 9.3 승률과 판정 [동작]

```
승률 = 내 전투력² ÷ (내 전투력² + 상대 전투력²)      범위 0.1% ~ 99.9%
```

동급이면 50%, 상대의 두 배면 80%다. 판정은 0~100 난수 한 번이고, 난수가 승률보다 작으면 승리다. 화면에 보여 준 승률을 그대로 쓴다.

### 9.4 전투 화면

- 제목: "교전 발생 · 능력치 비교" (대련이면 "라이벌 대련 · 능력치 비교")
- 상단: 교전이 벌어진 이유
- 양측 이름과 상태
- 7개 항목 비교표 (우세한 쪽 강조)
- 내 유효 전투력(개인 + 동료, 운 보정), 상대 유효 전투력
- 동료별 지원 수치
- 승률과 패배 확률, 승률 막대, 공식 설명
- 승패 시 득실
- "이 확률로 교전 시작" 버튼 → 0.65초 뒤 결과 표시 → "결과 확인 · 모험으로"

상대의 항목별 수치는 총 전투력을 유형별 비율로 나눈 환산치다. 화면에 "원작 공식 능력치가 아닙니다"라고 표기한다.

| | 드롭 아이템(처음 한 번) |
| 교전 패배 | 건강 −22(하한 15), 경험 일부, 동료 전원 신뢰 −2. 건강 45 미만이면 "교전 부상" 상태 |
| 공통 | 이야기 교전이었다면 승패와 무관하게 해당 단계 완료. 전투 기록 저장 |

교전 패배로는 죽지 않는다.

## 10. 소속과 경력

### 10.1 소속

| 소속 | 얻는 방법 | 특징 |
|---|---|---|
| 민간인 | 출생 시 기본 | |
| 해군 | 14세 맹세 | 18계급. 현상금 0. 공적·복무로 진급 |
| 혁명군 | 14세 맹세 | 8계급. 공적·복무로 진급. 교전 승리 시 현상금 상승 |
| 해적 | 14세 맹세 | 현상금에 따라 직함 변화. 교전 승리 시 현상금 상승 |
| 현상금 사냥꾼 | 14세 맹세 | 계급·직함 변화 없음 |
| 세계귀족(천룡인) | 천룡인으로 출생 | 14세 맹세에서 바뀐다 |

### 10.2 해군·혁명군 진급 [동작]

**해군 18계급**: 이병 → 일병 → 상병 → 병장 → 하사 → 중사 → 상사 → 준위 → 소위 → 중위 → 대위 → 소령 → 중령 → 대령 → 준장 → 소장 → 중장 → 대장

**혁명군 8계급**: 일반 병사 → 연락원 → 분대장 → 작전대원 → 지역 책임자 → 작전대장 → 군대장 보좌 → 군대장

| 조건 | 해군 | 혁명군 |
|---|---|---|
| 누적 공적 | 8 / 20 / 36 / 58 / 86 / 120 / 160 / 210 / 270 / 340 / 420 / 520 / 640 / 800 / 990 / 1,240 / 1,600 | 20 / 65 / 150 / 310 / 560 / 950 / 1,500 |
| 최소 복무 | 다음 계급 순번 × 2분기 | 다음 계급 순번 × 4분기 |
| 진급 간격 | 직전 진급 후 2분기 | 같음 |
| 최종 계급 추가 조건 | 전투력 400, 통솔 60, 복무 20년 | 같음 |

**공적을 얻는 곳**: 교전 승리 +20, 지역 이야기 단계 완료 +12, 정기 임무 +10~32.

진급하면 "[진급]" 로그와 토스트가 뜬다. 관리 모달의 "소속/선박" 탭에서 복무 수첩(현재 계급, 다음 계급 조건, 계급 트랙, 최근 기록 5건)을 볼 수 있다.

### 10.3 해적 직함

| 직함 | 조건 | 상태 |
|---|---|---|
| 최악의 세대 선장 | 현상금 1억 이상 | [동작] |
| 신세계 대선단장 | 사황 간부급 격파 + 현상금 3.5억 | [미동작] 해당 상대가 등장하지 않음 |
| 신세계 사황 | 사황 격파 + 현상금 12억 + 동료 3명 | [미동작] |
| 해적왕 | 최종 결전 승리 | [미동작] |

### 10.4 정기 임무 [동작]

16세 이상이면 매년 1건이 배정되고, 다음 사건 기회에 3지선다로 나타난다. 소속·종족·나이·위치에 따라 14종 중 하나가 정해진다(목록은 데이터 명세 6장).

| 선택지 | 효과 |
|---|---|
| 정석대로 수행하고 보고서를 남긴다 | 통솔 +2, 지능 +1, 공적 +기본 |
| 동료에게 구역을 나눠 맡기고 현장에 들어간다 | 동료 신뢰 +3, 경험 +3, 22% 확률로 건강 −10, 공적 +기본+4 |
| 명령의 빈틈을 이용해 주민과 선원을 먼저 구한다 | 통솔 +4, 명성 +5, 공적 +max(10, 기본−3) |

공적은 해군·혁명군만 실제로 쌓인다.

### 10.5 은퇴 [동작]

50세 이상이고 (건강 45 미만, 또는 부상·질병 상태, 또는 62세 이상)이면 은퇴 제안 사건이 뜬다.

| 선택지 | 효과 |
|---|---|
| 현역에서 물러나 후학을 키운다 | 은퇴. 건강 +18, 통솔 +8. 정기 임무 중단, 이후 "후학 양성" 사건 |
| 현장 지휘는 줄이고 조언자로 남는다 | 직함에 "고문" 추가. 건강 +8, 통솔 +4 |
| 아직 물러날 수 없다 | 경험 +4, 건강 −6 |

은퇴해도 게임은 계속된다.

## 11. 인생 과업

### 11.1 개요

플레이어가 인생의 목표를 하나 고르면 메인 화면에 5단계 진행률이 표시된다. 달성해도 보상이나 엔딩은 없다 **[표시만]**.

### 11.2 과업 5종

| 과업 | 고를 수 있는 소속 |
|---|---|
| 👑 해적왕 되기 | 해적 |
| ⚔️ 세계 최강의 대검호 되기 | 해적, 그 외 |
| ⚖️ 해군 원수 & 정의의 정점 | 해군 |
| 🔥 세계 혁명 & 신시대 개창 | 혁명군 |
| ⚓ 자유 항해자 · 항구의 길 | 그 외 |

각 과업의 5단계와 판정식은 데이터 명세 5장 참조.

### 11.3 선택과 변경

- 과업을 고르기 전에는 배너에 "소속 이후에 정하는 인생 과업"이 표시된다.
- 메인 화면의 "루트 로드맵 & 과업 변경" 버튼으로 소목표 선택 창을 연다. 소속에 맞는 과업만 나온다.
- 고른 뒤에는 같은 버튼으로 로드맵(5단계 달성 현황)을 보고 다른 과업으로 바꿀 수 있다(12세 이상).

### 11.4 달성 가능성

레퍼런스에서는 어떤 과업도 5단계까지 달성할 수 없다 **[미동작]**. 네 과업의 5단계가 요구하는 상대(미호크, 사황, 최종 결전)가 등장하지 않고, 자유 항해자는 동료 2명 조건(3단계)에서 막힌다.

## 12. 인물과 관계

### 12.1 관계 목록

메인 화면 우측에 인물 카드가 나열된다. 탭: 전체 / 가족·형제 / 동료 / 스승·친구 / 라이벌·앙숙. 카드를 누르면 인물 상세 모달이 열린다.

인물 상세는 열람 전용이다. 이름·나이, 관계, 소속, 주특기, 신뢰도, 친밀도, 꿈, 약점, 첫 만남, 최근 기록, (있으면) 악마의 열매 설명을 보여 준다.

### 12.2 인물 유형

| 유형 | 생성 시점 | 초기 신뢰 / 친밀 |
|---|---|---|
| 아버지 | 출생 (여인섬 출생이면 없음) | 85 / 85 |
| 어머니 | 출생 | 90 / 92 |
| 형제자매 0~3명 | 출생 | 80 / 82 |
| 소꿉친구 겸 라이벌 | 출생 | 55 / 60 |
| 고향 스승 | 출생 | 65 / 50 |
| 지역 협력자 | 항구 이야기 단계 완료 | 45 / 20에서 시작 |
| 동료 | (영입 경로 없음) | 80 / 75 |

- 부모는 소속, 과거 소속, 전투 스타일, 인생 기록, 비밀을 가진다.
- 형제는 꿈 5종 중 하나를 가진다.
- 창작 인물은 원작 성씨 풀에서 성씨를 받는다. 가족은 플레이어와 같은 성씨를 쓴다.

### 12.3 동료 [미동작]

동료의 역할 6종(항해사, 선의, 조선공, 전투원, 요리사, 저격수), 전투 지원, 임무 교대, 의사의 건강 회복, 합류 팝업이 모두 구현되어 있다. 그러나 **동료를 영입하는 사건이 실행되지 않아** 새 게임에서는 동료가 0명으로 유지된다. 그 결과 아래 기능이 모두 쓰이지 않는다.

- 전투의 동료 지원
- 관리 모달의 동료 임무 교대
- 의사 동료의 분기당 건강 +8
- 필수 위기의 "동료에게 맡긴다" 선택지(동료 지원 0으로 계산)
- 항해사 동료에 의한 항해 계기판 관측
- 동료 2명을 요구하는 과업 단계

### 12.4 필수 위기 — 불길이 항구를 덮었다 [동작]

18세 이후 한 번 발생한다. 가족·동료와 쌓은 관계가 성공률이 된다.

| 선택지 | 성공률 | 성공 | 실패 |
|---|---|---|---|
| 가족에게 구조 신호를 보낸다 | min(92, 35 + 가족 지원 + 감각÷3)% | 건강 +8, 통솔 +5, 가족 신뢰 +12 | 건강 −28, 중상 |
| 동료들에게 구역을 맡기고 출항시킨다 | min(95, 32 + 동료 지원 + 통솔÷3)% | 통솔 +6, 경험 +6, 동료 신뢰 +8 | 건강 −22, 부상, 동료 신뢰 −5 |
| 아무에게도 기대지 않고 뛰어든다 | min(78, 25 + 힘 + 속도 + 체력)% | 힘 +7, 경험 +10, 생존력 +10 | 건강 −70, 0 이하면 **사망** |

가족 지원 = 부모·형제 1인당 (신뢰+친밀)의 평균 ÷ 4, 최대 80. 출생 직후 수치로는 약 43이다. 동료 지원은 같은 식에 동료 수 × 4를 더하며, 동료가 없으면 0이다.

## 13. 경제와 관리

관리 모달은 탭 4개로 이루어진다. 열려 있는 동안 시간이 멈춘다. 나이 제한 없이 1세부터 쓸 수 있다.

### 13.1 집중 훈련 탭

| 훈련 | 상시 훈련(분기) | 즉시 특훈 |
|---|---|---|
| 균형 종합 단련 | 6종 중 무작위 +1 | 3,000베리, 체력 +3 |
| 고중량 근력 & 무술 수련 | 힘 +1 | 4,000베리, 힘 +3 |
| 육식 체술 & 고속 기동 훈련 | 속도 +1 | 4,000베리, 속도 +3 |
| 해도 분석 & 전술 병법 연구 | 지능 +1 | 4,000베리, 지능 +3 |
| 패기 명상 & 실전 극한 대련 | 패기 +1 | 6,000베리, 패기 +3 |

### 13.2 선장 방침 탭

- **선장 방침 4종**: 균형 항해 / 보물 우선 탐색 / 안전 우선 / 호전적 진격. 선택은 캔버스 캡션에만 반영된다 **[표시만]**.
- **정밀 치료 및 식량 보급**: 5,000베리로 건강 완전 회복 **[동작]**.
- **동료 임무 교대**: 4개 임무 중 무작위 배정, 신뢰 +3. 임무는 규칙에 영향이 없다 **[표시만]**.

### 13.3 항구 투자 탭

| 상품 | 연 수익률 | 표기 위험 |
|---|---|---|
| 고향 조선소 지분 투자 | 8% | 낮음 |
| 블루해 정기 교역단 | 12% | 보통 |
| 심해 보물 인양대 후원 | 20% | 높음 |
| 항구 의약품 상단 | 9% | 낮음 |
| 지하 세계 정보망 | 14% | 보통 |

- 10,000베리 단위로 투자하고, 언제든 원금 전액을 회수할 수 있다.
- 분기마다 `원금 × 연 수익률 ÷ 4`를 받는다.
- 손실이 없다. 위험 표기와 상품 설명의 부가 효과는 **[표시만]**.

### 13.4 소속/선박 탭

- 복무 수첩 (10.2절)
- 선박 개조: 25,000베리로 등급 +1, 최대 내구도 +50. 선박 등급과 내구도는 규칙에 쓰이지 않는다 **[표시만]**.

### 13.5 돈의 흐름

| 수입 | 지출 |
|---|---|
| 초기 자금 15,000 ~ 250,000 | 즉시 특훈 3,000 ~ 6,000 |
| 유년기 사건 보상 | 치료 5,000 |
| 지역 이야기 선택지 3,000 ~ 6,000, 완료 12,000 | 선박 개조 25,000 |
| 교전 승리 12,000 ~ 44,000 | 투자 (회수 가능) |
| 투자 배당 | |

정기 지출(식비, 봉급, 유지비)은 없다.

## 14. 건강, 사망

### 14.1 건강을 깎는 것

| 원인 | 변화 |
|---|---|
| 연례 질병·풍랑 (18세 이상, 매년 14%) | −16 (의사 동료 있으면 −6) |
| 교전 패배 | −22 (하한 15) |
| 지역 이야기 선택지 | −4 / −8 |
| 필수 위기 실패 | −22 / −28 / −70 |
| 정기 임무 현장 투입 (22%) | −10 |

### 14.2 건강을 회복하는 것

| 수단 | 변화 |
|---|---|
| 관리 모달의 정밀 치료 | 5,000베리, 완전 회복 |
| 생활 에피소드 "휴식" | +4 |
| 필수 위기 성공, 은퇴 선택 | +8 ~ +18 |
| 의사 동료 | 분기 +8 [미동작] |

자연 회복은 없다.

### 14.3 사망

| 원인 | 조건 |
|---|---|
| 질병·풍랑 | 연례 판정으로 건강이 0 |
| 필수 위기 | "홀로 뛰어든다" 실패로 건강이 0 이하 |
| 노환 | 72세 이상, 매년 25% |

사망하면 "생애 마감 · 최종 항해 기록" 카드가 뜬다. 향년, 마지막 장소, 사망 경위, 최종 소속과 현상금, 함께한 동료를 보여 준다. 버튼은 "새로운 시대의 새 인생 시작하기" 하나다. 점수 집계나 계승 요소는 없다.

## 15. 세계 뉴스와 현상금 랭킹

### 15.1 뉴스 [동작]

| 종류 | 시점 | 내용 |
|---|---|---|
| 일반 소식 | 출생 | 출생지 인근 순찰 강화 1건 |
| 항구 통신 | 매년 | 6종 기사가 순서대로 순환 |
| 지역 사건 | 항구 이야기 3단계 완료 | 해당 항구의 결말 |

최신 기사 제목이 메인 화면 뉴스 띠에 표시된다. 최대 80건 보관.

위 표는 초기 버전의 동작 기록이다. 현재 생애 모드에서는 뉴스 쿠가 원작 대사건의 호외, 세계 정세, 현상수배지, 지역 단신을 배달한다. 기사와 같은 시간표를 섬의 날씨와 사건에도 적용한다. 구체적인 발행·보관 규칙과 섬별 변화는 [성장과 콘텐츠 §10](../02_설계/05_성장과_콘텐츠.md#10-항해에서-만나는-원작의-사람과-물건)에 정리했다.

### 15.2 현상금 랭킹 [동작]

- 원작 인물 20명(흰수염 50억 4,600만 ~ 알비다 500만)의 고정 현상금.
- 여기에 플레이어(현상금이 있을 때)가 끼어 순위가 매겨진다.
- 매년 갱신된다. 원작 인물의 현상금은 변하지 않는다.

## 16. 화면

### 16.1 화면 구성

| 화면 | 내용 |
|---|---|
| 시작 화면 | 이름·성별 입력 → 성향 문답 |
| 메인 화면 | 3열 구성. 모든 플레이가 여기서 이루어진다 |
| 모달 8종 | 출생 프로필, 관리, 목적지, 세계 뉴스, 인물 상세, 저장, 전투, 과업 로드맵 |

### 16.2 메인 화면

**상단 헤더**: 제목, 버전, 상태 칩(이름, 나이, 종족, 소속, 위치, 건강, 소지금, 현상금), 효과음·저장·새 인생 버튼.

**좌측 — 프로필**

- 현상수배서 카드: 초상화, 나이대 배지, 성향 배지, 이름, 종족·성별·직함, 현상금
- 신상 정보: 출생지, 가정환경, 소속/직위, 능력/재능, 건강 상태
- 능력치 현황: 종합 전투력, 능력치 바 8개
- 보유 보물 & 항해 도구

**중앙 — 모험**

- 항로 대시보드: 현재 장 제목, 진행 상황(이야기 n/3 또는 남은 항해), 21개 항구 번호 트레일, 다음 추천 항구, 진행 속도 안내
- 날짜·나이, 속도 버튼
- 도트 캔버스: 정박 중에는 항구와 집·부두, 항해 중에는 배. 플레이어와 동료 최대 3명, 전투 시 적
- 인생 과업 배너와 진행률
- 액션 버튼 5개: 교전, 관리·훈련·투자, 항해·목적지, 세계정세·현상금, 출생·가문 기록
- 사건 카드 (사건이 있을 때만)
- 뉴스 띠
- 인생 타임로그: 필터 전체 / 중요사건 / 관계·동료 / 세계뉴스. 최대 160건

**우측 — 항해와 관계**

- 항해 계기판: 현재 섬, 목적지, 도착 예상, 기상, 보유 선박
- 관계도 현황 (12.1절)

### 16.3 모바일 (폭 1023px 이하)

- 세로로 중앙 → 좌측 → 우측 순서로 쌓인다.
- 하단 고정 내비 5버튼: 프로필 / 타임로그 / 관리·훈련 / 항해·목적지 / 관계·뉴스. 스크롤 이동 또는 모달 열기다.
- 헤더 상태 칩이 숨겨진다. 이때 메인 화면에는 소지금 표시가 없고 관리 모달의 투자 탭에서만 볼 수 있다 **[결함]**.

### 16.4 비주얼

- 컨셉: "항구 이야기 · 도트 RPG판". 휴대용 게임기풍 레트로 UI.
- 양피지색 패널(`#fcf1cd`), 네이비 프레임(`#244979`), 하늘색 배경(`#8dbbc8`), 금색 강조(`#e4b85d`).
- 2px 각진 모서리, 이중선 테두리, 번지지 않는 드롭 섀도.
- 본문 글꼴 Noto Sans KR.
- 초상화 4장: 14세 이하 공용, 15~49세 남성, 15~49세 여성, 50세 이상 공용.

### 16.5 나이대 표기

| 나이 | 표기 |
|---|---|
| 4세 이하 | 영유아기 |
| 5~11세 | 유년기 |
| 12~15세 | 소년/소녀기 |
| 16~34세 | 청년기 |
| 35~49세 | 중년기 |
| 50세 이상 | 노년기 베테랑 |

## 17. 사운드

Web Audio로 합성하는 효과음 4종. 배경 음악은 없다.

| 효과음 | 용도 |
|---|---|
| tick | 문답 선택, 해가 바뀔 때 |
| event | 사건 발생, 시작 버튼 |
| treasure | 보물·아이템 획득, 특훈 완료, 선박 개조, 교전 승리 |
| danger | 사망, 교전 패배 |

헤더 버튼으로 켜고 끈다. 설정은 저장되지 않는다.
