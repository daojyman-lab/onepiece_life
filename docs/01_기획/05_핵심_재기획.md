# 핵심 재기획 — 인생은 흘러가고, 갈림길에서 내가 고르고, 강적 앞에서 준비한다

작성일: 2026-11-14. 상태: 기획 확정. 수치와 목록은 설계 단계에서 정한다.

v3.3.3은 교전이 확률 한 번으로 끝나고, 열매와 패기는 전투력에 더해지는 숫자일 뿐이다. 그래서 하고 싶은 이유가 약하고 키우는 재미가 없다. 이 문서는 그것을 바꾼다.

이 문서는 [03_레퍼런스_현황과_과제.md](03_레퍼런스_현황과_과제.md) 8장의 "범위: 동작 복제" 결정을 대체하고, [01_게임기획서.md](01_게임기획서.md)의 전투·성장·항로 규칙을 대체한다.

## 1. 확정한 것

| 항목 | 결정 |
|---|---|
| 핵심 동기 | 강해지는 성장. 약한 아이에서 시작해 예전에 못 이기던 상대를 쓰러뜨린다 |
| 진행 | 인생은 자동으로 흘러간다. 중대한 선택만 1년에 2~3번 뜬다 |
| 성장 방향 | 중대한 선택에서만 정한다. 상시 방침 설정은 없다 |
| 유년기 | 1~9세는 짧은 사건 묶음으로 지나가고, 10~15세 수련기부터 성장이 시작된다 |
| 성장 구조 | 기술은 트리로 열리고, 위력은 숙련으로 오르고, 큰 단계는 스승이나 사건으로 열린다 |
| 기술 규모 | 무술 3유파, 패기 3색, 악마의 열매 100여 종 |
| 열매 | 모험 중에 발견한다. 무엇인지 모르고 먹는 도박이다. 한 인생에 하나만 먹는다 |
| 자연계 | 무장색 없는 공격은 피해가 크게 준다. 0이 되지는 않는다 |
| 교전 | 자동 전투. 강적 앞에서만 준비 화면이 뜬다 |
| 준비 요소 | 기술 장착, 전법, 동료 편성, 아이템 |
| 집단전 | 각자 상대를 맡아 따로 싸운다. 주인공은 체력이 남으면 진 교전에 끼어든다 |
| 아이템 | 무기·장비는 등급이 있다. 소모품이 있다. 강화는 없다 |
| 목표 | 태어난 해역에서 임무를 마치고 해역 보스를 넘으면 더 강한 해역으로 간다 |
| 길 | 해적과 해군 두 가지를 제대로 만든다. 혁명군은 해적에서 갈라지는 길이다 |
| 위험 | 병과 부상이 있고, 강한 상대와 싸우다 죽을 수 있다 |
| 한 인생의 길이 | 끝까지 살면 1~2시간. 배속 조절이 있다 |
| 해역 | 6단계. 해역마다 임무 3개와 보스 1명 |
| 다음 인생 | 열매 도감, 인물·기술 도감이 남는다. 능력치나 물건은 남지 않는다 |
| 돈 | 장비, 소모품, 치료, 감정, 배에 쓴다. 투자는 없다 |
| 밸런스 | 공식과 대략의 값을 정하고, 구현 뒤 대량 시뮬레이션으로 맞춘다 |

## 2. 한 바퀴

```
        인생이 자동으로 흐름 (수련 · 임무 · 평소 교전은 알아서 처리)
                              │
              ┌───────────────┼────────────────┐
              ▼               ▼                ▼
        중대한 선택        열매 · 장비 발견      강적 등장
     (스승, 유파, 진로)    (먹을까, 바꿀까)    (정찰 → 준비 → 관전)
              │               │                │
              └───────────────┴────────────────┘
                              ▼
                 성장 방향이 바뀌고 다음 벽이 보임
```

플레이어가 손대는 순간은 셋이다. 갈림길, 손에 넣은 것을 어떻게 할지, 강적과의 싸움.

## 3. 진행

- 시간은 자동으로 흐른다. 수련, 임무, 평소 교전, 돈벌이는 인물이 알아서 한다.
- 중대한 선택은 1년에 2~3번 뜬다. 뜨는 시점과 종류는 무작위이되, 나이·해역·소속·지금의 성장 상태에 맞는 것이 뜬다.
- 선택이 뜨면 시간이 멈춘다. 고르면 그 결과가 이후 자동 성장의 방향이 된다.

### 중대한 선택의 종류

| 종류 | 예 | 정해지는 것 |
|---|---|---|
| 입문 | 검술 도장에 들어갈지, 체술 사범을 따를지 | 무술 유파 |
| 스승 | 지나가던 강자가 제자로 받아 주겠다고 한다 | 큰 단계의 해금, 몇 년의 수련 |
| 열매 | 정체 모를 열매를 손에 넣었다 | 먹을지, 팔지, 간직할지 |
| 진로 | 해군에 지원할지, 배를 타고 나갈지 | 길(해적·해군), 혁명군 전향 |
| 도전 | 해역 보스에게 지금 갈지, 더 기다릴지 | 강적과의 교전 시점 |
| 인연 | 동료로 받아들일지, 원수를 살려 둘지 | 동료, 적대 관계 |
| 위기 | 가족의 빚, 동료의 배신, 큰 부상 | 돈, 관계, 건강 |

성장 방향은 이 선택들이 쌓여서 정해진다. 검술 도장에 들어가면 그 뒤로는 검술이 저절로 는다. 다른 것을 키우려면 다음 갈림길에서 바꿔야 한다.

### 나이대

| 시기 | 나이 | 내용 |
|---|---|---|
| 유년기 | 1~9세 | 출생, 가족, 라이벌 사건 몇 개로 빠르게 지나간다. 기본 성향과 초기 능력치가 정해진다 |
| 수련기 | 10~15세 | 선택 6~8번. 어느 무술에 입문할지, 누구를 따를지, 라이벌과 어떻게 지낼지 정한다. 라이벌 대련이 첫 강적전이다. 죽지 않으며, 준비와 관전을 여기서 배운다 |
| 출항 | 16세~ | 태어난 해역의 임무부터 시작한다 |

## 4. 성장

### 세 갈래

| 갈래 | 내용 | 큰 단계를 여는 것 |
|---|---|---|
| 무술 | 3유파(체술, 검술, 사격). 유파마다 기술 트리 | 유파의 스승 |
| 패기 | 3색(견문색, 무장색, 패왕색). 패왕색은 소질이 있어야 한다 | 스승, 죽을 고비 |
| 악마의 열매 | 100여 종. 열매마다 트리의 깊이가 다르다 | 숙련, 극한의 실전 |

### 세 겹

1. **트리**: 선행 기술의 숙련과 능력치 조건을 채우면 다음 기술이 열린다. 열릴 기술은 미리 보인다.
2. **숙련**: 기술마다 숙련도가 있다. 자동 수련과 실전으로 오른다. 숙련이 오르면 위력과 발동률이 오른다.
3. **스승과 사건**: 큰 단계(무장색 유동, 열매 각성 등)는 스승에게 배우거나 특정 사건을 겪어야 열린다.

### 악마의 열매 — 도박

- 원작에 나오는 열매를 100여 종 넣는다.
- 열매마다 등급이 다르다. 높은 등급은 트리가 깊고 각성까지 간다. 쓰레기급은 기술 한두 개에서 끝난다.
- 등급은 5단계다(쓰레기, 평범, 우수, 희귀, 전설). 쓰레기와 평범이 절반을 넘는다.
- 발견한 열매는 무엇인지 모른다. 감정을 맡기면 계통이나 등급의 범위 같은 힌트만 나온다. 정확히 알려 주는 감정은 없다.
- 예외는 도감이다. 지난 인생에서 먹어 본 열매는 도감에 남아, 다시 발견하면 알아본다.
- 한 인생에 하나만 먹는다. 지금 먹을지, 더 좋은 것을 기다릴지가 결단이다.
- 먹으면 헤엄칠 수 없고 해루석에 약해진다. 쓰레기급을 먹어도 이 대가는 같다.
- 먹지 않은 열매는 팔 수 있다.
- 열매를 먹지 않으면 그 자리만큼 무술과 패기를 더 깊이 올릴 수 있다.

## 5. 교전

### 평소 교전과 강적

| 구분 | 상대 | 처리 |
|---|---|---|
| 평소 교전 | 잡졸, 임무 중 마주치는 상대 | 저장해 둔 편성으로 자동 처리. 결과만 기록에 남는다 |
| 강적 | 해역 보스, 임무의 우두머리, 위험한 상대 | 정찰과 준비 화면이 뜨고 전투를 지켜본다 |

### 준비

| 준비 | 내용 |
|---|---|
| 기술 장착 | 배운 기술 중 정해진 칸 수만큼 고른다. 전투 중 자동으로 발동한다 |
| 전법 | 공세, 수비, 반격, 지구전 중 하나. 기술 발동 순서와 기력 쓰는 방식이 달라진다 |
| 동료 편성 | 누가 누구를 맡을지, 역할을 무엇으로 할지 정한다 |
| 아이템 | 무기·장비를 고르고 소모품을 정해진 칸 수만큼 챙긴다 |

정찰로 상대의 전투력, 주력 기술, 전법을 본다. 위험도(안전, 위험, 치명)가 표시된다. 준비한 편성은 저장되어 평소 교전에 쓰인다.

### 전투

- 여러 합에 걸쳐 자동으로 진행된다. 체력과 기력이 있고, 장착한 기술이 조건에 따라 발동한다.
- 도트 장면과 전투 기록으로 지켜본다. 끝난 뒤 어느 기술이 얼마나 통했는지 볼 수 있다.
- 자연계 상대에게 무장색 없는 공격은 피해가 크게 준다. 무장색 단계가 높을수록 감소를 무시한다.

### 집단전 — 각개 격파

- 무리끼리 붙으면 각자 상대를 하나씩 맡아 따로 싸운다. 주인공은 우두머리를, 동료는 간부를 맡는 식이다.
- 교전 하나하나가 따로 결판난다.
- 승패는 우두머리가 정한다. 상대 우두머리를 쓰러뜨리면 이기고, 주인공이 쓰러지면 진다.
- 동료가 지면 그 동료를 이긴 간부가 우두머리 싸움에 합세한다. 동료가 이기면 그 동료가 주인공을 돕는다.
- 주인공이 자기 교전을 먼저 끝내고 체력이 남았으면, 누구를 도우러 갈지 내가 고른다. 남은 체력 그대로 싸운다.
- 동료는 역할(전위, 지원, 치료, 항해사 등)을 갖는다. 동료를 직접 육성하지는 않는다.

### 결과

| 결과 | 내용 |
|---|---|
| 승리 | 보상, 쓴 기술의 숙련 상승, 해역 보스이면 다음 해역이 열림 |
| 패배 | 부상(가벼움, 무거움, 후유증), 돈과 시간 손실, 동료의 부상·이탈 |
| 사망 | 위험도가 치명인 상대에게 크게 지면 죽을 수 있다. 도전 전에 경고한다 |

## 6. 해역과 벽

| 단계 | 해역 |
|---|---|
| 1 | 태어난 바다 (동·서·남·북 중 하나) |
| 2 | 위대한 항로 입구 |
| 3 | 위대한 항로 전반 |
| 4 | 샤본디 제도 · 어인섬 |
| 5 | 신세계 전반 |
| 6 | 신세계 후반 (사황·대장급) |

- 인물마다 태어나는 곳이 다르다. 태어난 바다가 1단계다. 위대한 항로나 신세계에서 태어난 인물의 출발점은 설계에서 정한다.
- 한 해역에서 임무 3개를 마치면 그 해역의 보스가 나타난다. 임무는 출생지와 길(해적·해군)에 맞춰 만들어진다.
- 해역 보스를 넘으면 더 강한 해역으로 넘어간다.
- 해역 보스를 넘으면 기술서, 장비, 스승의 소개, 드물게 열매를 얻는다.
- 21개 항구와 지역 이야기는 해역 안의 임무와 무대로 다시 배치한다.

## 7. 길 — 해적과 해군

| 길 | 내용 |
|---|---|
| 해적 | 현상금이 명성이다. 해역 보스는 그 바다의 악당이나 해군이다. 동료를 모아 해적단을 꾸린다 |
| 해군 | 공적과 계급이 명성이다. 해역 보스는 그 바다의 해적이다. 상관이 스승이 되고 부하가 동료가 된다 |
| 혁명군 | 해적의 길에서 갈라진다. 특정 선택을 거쳐 전향한다. 따로 처음부터 만들지 않는다 |

## 8. 아이템

| 종류 | 내용 |
|---|---|
| 무기·장비 | 등급이 있다(검이면 양업물, 대업물, 최상대업물 식). 모험과 보상으로 얻는다. 강화는 없다 |
| 소모품 | 회복약, 특수 탄환, 식량 등. 강적 앞에서 정해진 칸 수만큼 챙긴다 |
| 열매 | 4장 참고 |
| 배 | 돈으로 사고 더 좋은 배로 바꾼다. 다음 해역으로 넘어가는 조건이고, 태울 수 있는 동료 수를 정한다 |

돈은 장비, 소모품, 치료, 열매 감정, 배에 쓴다. v3.3.3의 항구 투자는 넣지 않는다.

## 9. 위험

| 위험 | 생기는 때 | 결과 |
|---|---|---|
| 부상 | 임무, 교전 | 능력치 일시 감소. 낫지 않으면 후유증 |
| 질병 | 지역, 나이, 무리한 수련 | 성장이 멈춤. 방치하면 악화 |
| 노화 | 나이 | 전성기 이후 능력치 감소 |
| 사망 | 치명 위험도의 교전, 악화한 병, 노환 | 인생 종료 → 결산 화면, 명예의 전당 |

## 10. 인생이 끝나면

| 남는 것 | 내용 |
|---|---|
| 결산 화면 | 최종 직위, 현상금·계급, 넘은 해역, 주요 선택의 연표 |
| 명예의 전당 | 지난 인생들의 기록을 모아 비교한다 |
| 열매 도감 | 먹어 본 열매가 기록된다. 다음 인생에서 같은 열매를 알아본다 |
| 인물·기술 도감 | 만난 스승, 쓰러뜨린 강적, 열어 본 기술 트리가 기록된다. 다음 인생에서 누가 어디에 있는지, 트리 끝에 무엇이 있는지 미리 본다 |

능력치, 돈, 물건은 남지 않는다. 판을 거듭할수록 강해지는 것이 아니라 아는 것이 늘어난다.

## 11. v3.3.3에서 가져오는 것과 바꾸는 것

| 구분 | 항목 |
|---|---|
| 그대로 | 세계관, 출생과 가문, 종족, 자동으로 흐르는 시간, 가족·관계, 뉴스 |
| 다시 배치 | 21개 항구와 지역 이야기(해역별 임무로), 소속과 계급(해적·해군 두 길로), 인생 과업 |

## 12. 설계 단계로 넘기는 것

기획에서 정할 것은 모두 정했다. 아래는 설계에서 값과 목록을 만든다.

| # | 항목 |
|---|---|
| S1 | 중대한 선택의 목록과 발생 조건 (한 인생에 100~150번이 겹치지 않게) |
| S2 | 무술 3유파와 패기 3색의 기술 트리 |
| S3 | 열매 100여 종의 목록, 등급 배정, 등급별 트리 깊이 |
| S4 | 자동 전투의 규칙 (합, 체력·기력, 기술 발동 조건, 전법의 효과) |
| S5 | 해역 6단계의 임무와 보스, 해적·해군 길에 따른 차이 |
| S6 | 위대한 항로·신세계 출생 인물의 출발점 |
| S7 | 장비 등급표와 소모품 목록, 배의 종류 |
| S8 | 스승 목록과 가르치는 조건 |
| S9 | 자동 진행의 속도 (1~2시간에 맞춘 시간 단위와 배속) |
| S10 | 대량 시뮬레이션으로 볼 지표 (사망 나이, 해역 도달률, 빌드별 승률, 열매 유무의 차이) |
