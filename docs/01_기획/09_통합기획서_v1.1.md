# 1. 프로젝트 비전 (v1.0 유지)

**원피스 세계에서 한 인물의 일생을 살아가며, 자신만의 꿈을 품고 바다를 여행하고, 전성기를 누린 뒤, 마지막에 "너에게 원피스는 무엇이었나?"라는 질문에 답하는 인생 시뮬레이터.**

핵심 감정: 동경 → 결심 → 도전 → 성취 → 향유 → 회고 → 대답.

설계 원칙(v1.0 유지): 자동 진행 + 중대한 선택 / 전투는 필요한 순간의 인생 사건 / 급격하지 않은 성장 / 패배를 보상으로 바꾸지 않음 / 원작 보스의 힘을 낮추지 않음 / 출생지가 실제로 작용 / 조연도 나이를 먹음 / 원작 인물은 무게감, 오리지널 인물은 개인적 관계 / 기존 기능 재활용.

**v1.1 추가 원칙**
- 원작의 역사는 흐른다. 플레이어는 원작의 판가름을 대신하지 않고, **그 옆의 전선 · 그 앞뒤의 시간**을 산다.
- 섬 하나에 머무는 시간은 하나의 "장"이다. 두 달 남짓의 사건이 인생 기록에 한 줄로 남는다.
- 모든 선택에 따로 이야기를 만들지 않는다. **표시(flag)** 로 대사 · 상대 · 지원 · 결말만 바꿔 제작 규모를 통제한다.

# 2. 꿈과 신념

## 2.1 신념 = 가치관 9종

| 가치관 | 대표 인물 | 성격 |
|---|---|---|
| 정의 | 코비, 스모커 | 옳은 것을 지킨다 |
| 탐욕 | 크로커다일 | 부와 보물 |
| 야망 | 도플라밍고 | 높이 오른다 |
| 낭만 | 우솝, 브룩 | 꿈과 이야기 |
| 탐구 | 로빈 | 진실과 역사 |
| 의리 | 조로, 징베 | 내 사람을 지킨다 (= v1.0의 동료) |
| 자유 | 루피, 에이스 | 누구에게도 매이지 않는다 |
| 패도 | 카이도 | 강함 (= v1.0의 강함) |
| 평온 | 마키노 | 조용한 삶 |

선택지마다 가치관이 붙는다. 쌓인 정도가 특별한 선택지(문)를 열고, 칭호 · 엔딩 대답에 반영된다. 문 글에는 가치관 이름을 쓰지 않는다.

## 2.2 꿈 8종 (인생 과업)

| 꿈 | 이룬 조건 | 이룬 말 / 못 이룬 말 |
|---|---|---|
| 해적왕 | 해적왕 표시 | 바다의 정점에 섰다 / 끝내 닿지 못했다 |
| 세계 최강의 검객 | 검술 최고 경지 | 검의 끝에 닿았다 / 보이지 않았다 |
| 정의의 정점 | 해군 · 정부로 정점 | 가장 높은 자리에 섰다 / 닿지 못했다 |
| 세상을 바꾸는 것 | 혁명군 + 큰 이름 | 세상이 조금은 달라졌다 / 세상은 단단했다 |
| 세상의 끝을 보는 것 | 마지막 바다를 봄 | 마지막 바다를 보았다 / 수평선 너머에 남았다 |
| 세계의 진실을 아는 것 | 역사의 돌 · 금서 · 학자 | 역사의 한 조각을 읽었다 / 문이 열리지 않았다 |
| 바다의 보물 | 큰 재산 | 평생 쓰고도 남을 보물 / 늘 한 발 앞에 |
| 소중한 사람들과의 평온 | 45세 이상 + 깊은 인연 + 정착 | 곁에서 늙어 갔다 / 생각보다 멀었다 |

- **품는 때:** 13~17세. 장면 넷 중 하나("수평선 너머" · "무엇이 되고 싶은가" · "검 끝의 약속"(검술가) · "불공평한 세상")에서 셋 중 하나를 고른다.
- **흔들림:** 28~42세, 꿈을 품은 지 12년 넘게 못 이뤘으면 가끔 "흔들리는 꿈"(붙들기 / 평온으로 / 세상의 끝으로).
- **닿지 못한 꿈:** 55세 이후 "마지막 도전 / 다음 사람에게 넘기기 / 받아들이기".
- 섬 장편과 항로 선택이 꿈과 이어진다(꿈과 이어진 섬 · 시나리오의 의미).

# 4. 잠재력 · 전성기 · 노화

## 4.1 잠재력 4유형 (출생 때 정해짐)

| 유형 | 비율 | 수련 배율 |
|---|---|---|
| 천재형 | 15% | 24세까지 ×1.3, 35세 이후 ×0.8 |
| 균형형 | 45% | ×1.0 |
| 대기만성형 | 20% | 24세까지 ×0.8, 25~45세 ×1.35 |
| 특화형 | 20% | 지금 걷는 갈래만 ×1.25 |

## 4.2 전성기
- **진입 조건 = 잠재력의 실현 + 결정적 사건.** 22~40세, 어느 갈래든 숙련 단계 이상 + (이름값 60 이상 → "가장 빛나는 때") 또는 (시련 30 이상 → "견뎌 낸 끝에서").
- 장면에서 전성기를 무엇에 쓸지 고른다(강자를 찾아 / 곁의 사람들의 꿈 / 미지의 바다 / 되갚기 / 끌어올리기 / 누리기).
- 5년 동안 한 살에 두 바퀴. 약 3명 중 1명이 전성기를 맞는다.

## 4.3 노화
- 50세부터 해마다 근력 · 속도 · 체력 중 하나가 확률로 1씩 내려간다(잃은 부위 · 부상이 많으면 더 자주). 숙련 · 패기 · 지식 · 명성은 남는다.
- 성장 배율: 40세까지 1.0 → 50세 0.6 → 59세 0.25 → 이후 0.

# 5. 가족과 관계 서사

## 5.1 배정 규칙

| 출생 환경 | 중심 서사 |
|---|---|
| 부모 + 형제 | 부모 서사 + 형제 서사 (맞수 없음) |
| 부모만 | 부모 서사 + 어릴 적 맞수 |
| 고아 · 조부모 손 (고아의 35%) | 조부모 서사 (스승 대신) |
| 고아 · 부모 행방불명 (30%) | 스승 서사 + 훗날 바다에서 재회 가능 |
| 고아 · 그 밖 | 스승 서사 |
| 고아 · 아무 인연 없음 (6%, 전체의 약 2%) | 맞수도 스승도 없음. 20세부터 쓸쓸한 끝(평균 24세 사망) — 다음 인생을 부른다 |

## 5.2 서사의 수미상관
- **형제:** 빵 반쪽 · 언덕 · 지붕 → 어른이 되어 같은 장면이 뒤집혀 돌아온다.
- **부모:** 어깨 · 손 · 밥상 · 유품 → 자식에게 물려주는 장면.
- **스승:** 밥 한 그릇 → 물음 → 대신 막아서는 등 → 닳은 목검 → 그 자리에 서다.
- **조부모(v6.7):** 아궁이 앞의 옛이야기 → 거친 손 → 떠나는 날의 부적 → 마지막 편지("부모는 살아 있을지도 모른다") → 늙어서 같은 이야기를 아이에게.
- **행방불명된 부모(v6.7):** 돌아오지 않는 배(가난한 집에서 드물게) → 낯선 항구의 노인(붙잡는다 / 이유를 묻는다 / 돌아선다) → 함께 보는 수평선.

## 5.3 동료
- 완전 동료(원작 인물 111명) / 임시 동행(사보 · 에이스 · 로우 등 14명). 거인은 평범한 배에 탈 수 없어 제외.
- 섬 장편의 오리지널 인물은 신뢰가 충분하면 1~2년 임시 동행.
- 전투 등급 F~SSS를 플레이어 · 동료 · 적에게 표시.

## 5.4 이름
- 엑스트라 이름 500선을 지역별 풀로(이스트 블루 · 해적 · 해군 귀족 · 와노 · 어인 · 하늘섬 · 북해 · 괴짜).
- 곁의 인물은 3명 중 1명꼴로 처지에 맞는 성이 붙는다. 원작과 맞지 않는 한국식 이름은 뺐다.
- 주인공은 가족이 있으면 성이 있고, 고아면 성을 모른다.

# 6. 출생지와 항로

- 고향 여섯: 로그타운 · 워터 세븐 · 와노쿠니 · 어인섬 · 하늘섬 · 조우. 바다에 닿지 않는 고향은 떠나기 전까지 바다 · 해군 사건이 오지 않는다.
- 인물 칸에 큰 지명과 함께 표시(예: 와노쿠니 - 쿠리).
- **항로 고르기(v6.4):** 해적 · 혁명군 · 현상금 사냥꾼 · 칠무해는 섬을 옮길 때가 되면(해마다 45%) 다음 멈춤에 고른다.
  - 잔잔한 뱃길(체력 회복) / 꿈과 이어진 섬 또는 소문의 섬(의지) / 험한 바다(다치지만 이름이 난다).
  - 섬마다 위험도(잔잔 · 보통 · 험함)와 꿈과 이어진 섬을 정해 두었다.
- **해군 · 정부 요원:** 고르지 않는다. 본부의 전근 명령으로 배속된다.

# 7. 원작 인물 · 보스의 원칙

1. **원작 시간표(주인공 나이 기준):** 원작 시작 17 · 로그타운 17 · 알라바스타 17~18 · 스카이피아 18 · 에니에스 로비 18 · 샤본디 18~19 · 마린포드 19 · (2년 뒤) 어인섬 21 · 드레스로자 21 · 홀케이크 21~22 · 와노 22.
2. **원작 아크의 그 순간:** 플레이어는 다른 전선에 있다(피난 · 간부 · 다른 구역). 판가름은 밀짚모자가 한다. 그 결과는 연표(`time`)로 남는다.
3. **원작 보스 직접 대결:** 다른 때 · 다른 곳에서만, 충분한 경지(크로커다일 · 에넬 · 도플라밍고 5단계, 호디 4단계, 카이도 6단계)가 있을 때만 열린다. 치명적이며 물러날 문이 있다. **이겨도 보스는 물러나거나 달아날 뿐**이라 원작이 깨지지 않는다.
4. **원작 인물은 판단자:** 플레이어가 실제로 한 일(표시)을 보고 협력하거나 경계한다. 문제를 대신 풀지 않는다.
5. **힘은 고정:** 원작 · 오리지널 모두 바다에 맞춘 힘. 플레이어에 맞춰 낮추지 않는다.

# 8. 섬 장편 시나리오의 공통 설계

## 8.1 짜임 (SKY_B_01 본보기)

| 주차 | 장면 | 기능 |
|---|---|---|
| 1 | 도착과 첫 사건 | 지역 · 오리지널 인물 소개, 가벼운 첫 싸움(지면 다침 · 도주) |
| 2 | 조사 | 무력 · 협상 · 관찰 · 무관심. 접근 방식이 표시로 남는다 |
| 3 | 추적 · 잠입 | 추적 / 잠입 / 정면 돌파 → 보급처 · 적 구성 표시 |
| 4 | 양쪽의 입장 차이 | 주민 회의, 원작 인물 등장(행적으로 판단) |
| 5 | 발견 · 중간 보스 | 탐색과 중간 보스(치명적이지 않음) |
| 6 | 적대자의 제안 | 거절 / 받아들이는 척 / 조건부 / 실제 거래(돈 ↔ 인연 악화) |
| 7 | 결전 준비 | 보급 습격 · 피난로 · 진입로 · 약점 조사 · 준비 없이 |
| 8 | 결전 | **보급을 끊었으면 약해진 변형 상대**. 위험 경고와 물러날 문 |
| 9 | 결말 A~E | 표시 조합으로 갈림. 조건 없는 기본 결말(E) 하나 |
| 10 | 출항 | 증표, 신뢰가 높으면 임시 동행 |

- 섬마다 **시나리오 셋**: 원작 전 / 원작 그 무렵 / 원작 뒤. 각 9~15장면.
- 섬마다 **오리지널 인물 둘**(안내자형 · 기록 · 지원형)과 신뢰 표시, **오리지널 적대 조직 하나**(정찰병 · 현장 책임자 · 두목 + 약해진 변형).
- **증표의 이어짐:** 앞 시나리오의 증표가 뒤 시나리오에서 새 선택지를 연다.
- **결말의 기본형**
  - A: 현지 안내자 쪽의 결말(지키다 · 닫다)
  - B: 기록자 쪽의 결말(함께 기록하다 · 공유하다)
  - C: 열린 결말 · 해군 · 왕정에 넘기기 등

# 10. 엔딩과 인생 기록

## 10.1 장면이 넘어가는 엔딩 (v6.5)
마지막 모습 → 한 줄 인생 → 어떤 사람이었나 · 꿈과 그 결말 → 세계가 기억하는 나(신문) → 원작 인물의 한마디 · 겹친 원작 순간 → 가지 않은 길 · 도감 → 기록 → **"너에게 원피스는 무엇이었나?"**

## 10.2 마지막 대답의 조합

| 인생 | 대답 |
|---|---|
| 꿈을 이룸 | 나에게 원피스란, 평생 꿈꾸었던 ○○ 그 끝이었다. |
| 꿈이 평온으로 바뀜 | 처음에는 가장 높은 곳이었다. 하지만 마지막에는, 지켜야 할 삶이 있었다. |
| 깊은 인연이 셋 이상 · 의리 | 나에게 원피스란, 함께 바다를 건넜던 사람들이었다. |
| 꿈을 못 이룸 | 끝내 닿지 못했다. 그래도 그곳을 향해 떠났던 순간만큼은 후회하지 않는다. |
| 꿈이 없음 | 가장 깊은 가치관에 따라 (자유: 바람처럼 산 날들, 낭만: 모험 그 자체, 탐구: 감춘 이야기를 알아 가는 기쁨 …) |

섬 장편의 결말 문장, 전성기, 꿈, 가족 서사가 연표에 남아 엔딩의 "기록"과 "겹친 원작 순간"을 채운다.

# 14. 최종 요약

「그랜드 트레저」는 원피스 세계에서 한 인물의 인생을 살아가는 시뮬레이터다. 동경에서 꿈을 품고, 바다로 나가 섬마다 두 달 남짓의 장을 살며, 전성기를 누리고, 늙어 무엇을 남길지 정한다. 원작의 역사는 그대로 흐르고, 플레이어는 그 옆의 전선과 그 앞뒤의 시간에서 자기만의 이야기를 만든다.

> **너에게 원피스는 무엇이었나?**

그 대답은 모든 캐릭터에게 다르고, 어떤 대답도 다른 대답보다 더 옳지 않다.
