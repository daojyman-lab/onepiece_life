## 2. 성향 문답

### 2.1 구조

```
문항 = { 번호, 분야, 지문, 선택지 3개 }
선택지 = { 문구, 성향, 능력치 보너스 }
```

### 2.2 수기 20문항의 분야

위험 감수, 가족과 친구, 돈과 보물, 권력자와 법, 자유와 안전, 명예와 생존, 복수와 용서, 지식과 힘, 동료와 고독, 실패에 대한 반응, 낯선 사람, 약자를 대하는 태도, 명령과 양심, 동료의 실수, 전투 방식, 위험한 능력, 스승과 가르침, 정보의 가치, 선박의 의미, 라이벌과의 경쟁.

보너스는 대개 2+1점 조합이고, 성향 9종이 고르게 쓰이지는 않는다(분석형 12, 야망형 9, 돌파형 8, 수호형 7, 모험형 7, 자유추구형 6, 독립형 5, 중재형 3, 충성형 3).

### 2.3 템플릿 10종 (각 4회 복제되어 40문항)

해왕류 조우, 천룡인의 행차, 악마의 열매 각성, 동료의 과거, 해군 대장의 포위, 비블카드 반응, 고대병기 단서, 식량 위기, 현상금 급등, 전설의 대장장이.

복제본은 지문 끝에 "(상황 2)" ~ "(상황 4)"만 붙는다. 선택지의 성향과 보너스는 내용이 아니라 **위치**로 고정되어 있다.

| 위치 | 보너스 | 성향 (짝수 번째 / 홀수 번째 템플릿) |
|---|---|---|
| 1 | 힘 2, 패기 1 | 돌파형 / 모험형 |
| 2 | 지능 2, 속도 1 | 분석형 / 자유추구형 |
| 3 | 통솔 2, 체력 1 | 수호형 / 야망형 |

문항 전문은 분석 노트 B의 4.4절과 4.5절에 있다.

## 3. 항구

### 3.1 항구 21곳

기획서 8.2절의 표가 항로 순서 전체다. 항구 데이터의 필드는 다음과 같다.

| 필드 | 뜻 | 규칙 반영 |
|---|---|---|
| id | 항구 식별자 (`east_`, `gl_`, `nw_` 접두) | 사용 |
| name | 표시 이름 | 사용 |
| region | 해역 | 표시 |
| danger | 위험도 1~9 | 지역 적 전투력과 보상 계산 |
| travelMonths | 항해 기간 (3개월 단위로 올림) | 사용 |
| weather | 기후 설명 | 계기판 표시 |
| navyRisk | 해군 감시 라벨 | 표시뿐 |
| canonPool | 등장 인물 | 카드 표시, 지역 협력자 이름 |
| minAge | 최소 나이 | 미사용 |

### 3.2 출생지와 시작 항구

출생지는 자유 문자열이고 항구 id와 직접 연결되지 않는다. 첫 틱에 출생지 문자열에 다음 단어가 있으면 해당 항구로 맞춘다: 모코모, 조(Zou), 아마존, 어인섬, 드럼, 코코야시, 발라티에, 로그타운, 시럽, 셸즈, 오렌지, 알라바스타, 워터 세븐, 샤본디, 와노, 드레스로자.

일치하는 단어가 없는 출생지(예: 성지 마리조아, 엘바프, 노스 블루 상업 도시)는 화면에는 출생지가 표시되지만 이야기는 후샤 마을의 것으로 진행된다.

### 4.3 서사 규칙

이야기 본문은 공통된 틀을 따른다.

- 1단계: 섬에 도착해 불안한 조짐을 본다.
- 2단계: 원작의 큰 싸움이 벌어진다. 원작 주역이 본대를 맡고, 플레이어는 주민 구조·정보 전달·별동대 저지 중 하나를 고른다.
- 3단계: 싸움이 끝난 뒤의 복구와 교류. 다음 항해 준비.

### 4.4 지역 적 이름

지역 적의 이름은 2단계 3번 선택지 문구에서 정규식으로 잘라 만든다. 잘못 잘린 결과가 여러 개 있다(예: "연기가 자욱한 골목으로 구조에 나선다"가 통째로 적 이름이 됨). 새 버전에서는 항구마다 이름을 직접 지정해야 한다. 레퍼런스가 만들어 내는 이름 전체는 분석 노트 D의 3.4절 표에 있다.

## 9. 게임 상태 구조

저장 데이터는 하나의 객체다. 최상위 키는 7개다.

```

  신상: name, gender, surname, hasD, fullName, species, birthplace, household, surnameLore

  상태: health, maxHealth, condition, isAlive, retired
  자산: money, bounty, items[]
  소속: affiliation, roleTitle, career{faction, rank, merit, service, lastPromotion, ...}
  위치: location, locationId, destination, sailingMonthsLeft, hasSailed
  목표: lifeGoal, defeatedBosses[]

family
  parents[], siblings[], householdHistory

relationships
  list[] — 인물 객체. category: family / crew / mentor / rival

world
  era, newspapers[], bountyRankings[]

management
  trainingFocus, captainOrder, investments[5], ship{owned, name, tier, hull, maxHull}

log
  entries[] — 최대 160건. type: auto / event / relation / world

meta
  진행: speed, pausedForPopup, activeEvent, battleModalActive, seasonSerial
  이야기: storyProgress{항구: 0~3}, storyHistory[], portVisits{}, pendingStoryBattle, routeChoiceReady
```
